## 指针的创建与使用

指针是保存变量地址的变量，如：

```c

printf("%p", p); // 地址使用%p表示
printf("内存%p上存储的值为: %d", p, *p); // *号来获取对应地址的值
*p = 666; // 也可以修改指针对应的值
```

```c
int *p = NULL;
```

    *b = tmp;

}
