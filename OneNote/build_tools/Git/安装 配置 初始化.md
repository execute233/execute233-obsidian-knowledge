# 安装 配置 初始化

## 全局配置

```bash
git config --global user.name "名字"
git config --global user.email "邮箱"
git config --global http.proxy "http://127.0.0.1:8080"
git config --global https.proxy "http://127.0.0.1:8080"
```

## 创建 Git 仓库

```bash
git init
git clone <url>
```

仓库创建后的日常操作（提交、分支、远程等）见 [[build_tools/Git/使用]]。

## Token 鉴权（作为密码输入）

GitHub → Setting → Developer settings → Personal access tokens → Classic 令牌

## SSH 鉴权

```bash
cd ~/.ssh
ssh-keygen -t rsa -b 4096 -C "个人邮箱"
```

生成对应的 `.pub` 公钥。

GitHub → SSH and GPG keys 配置公钥
