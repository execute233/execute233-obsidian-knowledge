# 使用

Git 的安装、配置与仓库初始化见 [[build_tools/Git/安装 配置 初始化]]。

## 初始化与基本操作

初始未跟踪，使用（可使用通配符）

```bash
git add <name>
```

删除（添加 `--cached` 可保留在目录里）

```bash
git rm --cached <name>
```

设置缓存状态

```bash
git add <file-name>
```

取消缓存状态

```bash
git restore --staged <name>
```

## 提交

提交

```bash
git commit -m "提交内容"
```

没暂存的文件也提交

```bash
git commit -am "提交内容"
```

修改最近的一次提交

```bash
git commit --amend -m "新的提交信息"
```

## 文件状态与历史

文件状态

```bash
git status
```

文件具体哪里修改了

```bash
git diff
```

历史提交

```bash
git log --oneline
```

## 远程仓库

链接远程仓库

```bash
git remote add <name> <url>
```

查看远程仓库

```bash
git remote
```

重命名远程仓库

```bash
git remote rename <old-name> <new-name>
```

推送

```bash
git push origin <本地分支>
```

可以使用 `-u` 参数，后面推送只要 `git push` 就是这个分支了

## 分支

查看当前分支

```bash
git status
```

创建分支

```bash
git branch <branch-name>
```

查看已有的分支

```bash
git branch --list
```

切换分支

```bash
git checkout <branch-name>
```

新建分支，并切换到新建的分支

```bash
git checkout -b <branch-name>
```

查看多个分支提交

```bash
git log --all --graph
```

强制让分支指向另一个提交

```bash
git branch -f main HEAD~3
```

合并其它分支到当前分支

```bash
git merge <branch-name>
```

### 解决合并冲突

```bash
vi <冲突文件>
git commit -m "xxx"
```

## 拉取远程分支

拉取远程分支

```bash
git fetch
```

将远程的分支变为本地分支

```bash
git checkout -b <branch-name> origin/<branch-name>
# 或
git checkout --track origin/<branch-name>
```

## 储藏功能

储藏当前跑去另一个分支

```bash
git stash
```

恢复刚刚存储的分支

```bash
git stash apply
```

多次存储

```bash
git stash push
```

查看存储列表

```bash
git stash list
```

## 重置

`HEAD` 是当前提交，`HEAD~` 是上次提交，也可以 `HEAD~数字`

```bash
# --soft 暂存区还有,内容也有,--hard 全都没了,回到上一次 commit 后
git reset HEAD~ --soft
# 注意撤销的如果是远程存在的话是无效的
```

也可以建立新的记录来记录撤销的提交

```bash
git revert HEAD
```

## 变基

让记录更好看？

将当前分支变基到指定分支

```bash
git rebase <branch-name>
```

将指定分支变基到目标分支

```bash
git rebase <target-branch> <source-branch>
```

交互式编辑前几次 commit

```bash
git rebase -i HEAD~num
```

## 自由修改提交树

复制一个/多个提交到当前 HEAD 位置

```bash
git cherry-pick commit1 commit2 ...
```

交互式调整之前提交的顺序

```bash
git rebase HEAD~num -i
```

## 标签

给一个记录打上标签

```bash
git tag 标签名 <commit>
```

描述离你最近的标签

```bash
git describe <ref>
# 输出结果类似于 <tag>-<numCommits>-g<hash>
# <tag> 是离 <ref> 最近的标签, <numCommits> 表示相差多少个提交, <hash> 是 <ref> 的 hash 前几位
```
