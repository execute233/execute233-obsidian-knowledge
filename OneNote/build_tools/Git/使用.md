初始未跟踪，使用(可使用通配符)
git add <name>
删除（添加--cache可保留在目录里）
git rm <name>
设置缓存状态
git add <file-name>
取消缓存状态
git reset HEAD <name>
提交
git commit -m '提交内容'
没暂存的文件也提交
git commit -am '提交内容'
修改最近的一次提交
git commit --amend -m "新的提交信息"
文件状态
git status
文件具体哪里修改了
git diff
历史提交
git log --pretty
远程仓库
链接远程仓库
git remote add <name> …
查看远程仓库
git remote
重命名远程仓库
git remote rename <old-name> <new-name>
推送
git push origin <本地分支>
可以使用-u参数，后面推送只要git push就是这个分支了
分支
查看当前分支
git status
创建分支
git branch <branch-name>
查看已有的分支
git branch --list
切换分支
git checkout <branch-name>
新建分支，并切换到新建的分支
git checkout -b <branch-name>
查看多个分支提交
git log --all --graph

**强制让分支指向另一个提交
git branch -f main HEAD~3
合并其它分支到当前分支
git merge <branch-name>
解决合并冲突
vi <冲突文件>
git commit -m 'xxx'

拉取远程分支
git fetch
将远程的分支变为本地分支
git checkout -b <branch-name> origin/<branch-name>
或 git checkout --track origin/<branch-name>
储藏功能，储藏当前跑去另一个分支
git stash
恢复刚刚存储的分支
git stash apply
多次存储
git stash push
查看存储列表
git stash list
恢复
重置
head是当前提交，head~是上次提交,也可以head~数字,
--soft 暂存区还有，内容也有，--hard全都没了，回到上一次commit后
git reset head~ --soft # 注意撤销的如果是远程存在的话是无效的
也可以建立新的记录来记录撤销的提交
git revert HEAD
变基: 让记录更好看？
将当前分支变基到指定分支
git rebase <branch-name>
将指定分支变基到目标分支
git rebase <target-branch> <source-branch>
交互式编辑前几次commit
git rebase -i head~num
自由修改提交树
复制一个/多个提交到当前HEAD位置
git cherry-pick commit1 commit2 …
交互式调整之前提交的顺序
git rebase HEAD~num -i
标签
给一个记录打上标签
git tag 标签名 <commit>
描述离你最近的标签
git describe <ref>
输出结果类似于<tag>-<numCommits>-g<hash>
<tag>是离<ref>最近的标签，<numCommits>表示相差多少个提交，<hash>是<ref>的hash前几位
