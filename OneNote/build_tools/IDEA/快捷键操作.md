# 快捷键操作

| 快捷键              | 功能         | 快捷键          | 功能           |
| ---------------- | ---------- | ------------ | ------------ |
| `Ctrl+Shift+U`   | 查看实现关系图     | `Ctrl+Alt+单击` | 跳转到实现         |
| `Ctrl+F12`       | 查看当前类的所有方法 | `Ctrl+/`      | 给当前行加上/去掉注释   |
