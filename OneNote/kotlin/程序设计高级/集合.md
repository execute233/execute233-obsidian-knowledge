# 集合

## List 集合

对于 `List` 对象,它是不可变的。

```kotlin
val list: MutableList<Int> = mutableListOf(1, 2, 3, 4) // 一个可变 List
```

可创建可变 List:

```kotlin
val list: MutableList<Int> = mutableListOf(1, 2, 3, 4)
```

## Set 集合

创建 Set 集合与上面差不多,创建的 Set 集合没有重复元素:

```kotlin
val set: MutableSet<String> = mutableSetOf("AAA", "BBB", "CCC")
```

Set 更接近数学上的概念,可以进行集合间的操作,如:

```kotlin
set1 union set2      // 并集,等同于 +
set1 intersect set2  // 交集
set1 subtract set2   // 差集,等同于 -
```

Set 有不同预设的函数进行创建:

```kotlin
mutableSetOf()    // 底层为 LinkedHashSet,维持顺序
linkedSetOf()     // 底层为 LinkedHashSet,维持顺序
hashSetOf()       // hash 表,不维持顺序
setOf()           // 只读的 Set
setOfNotNull()    // 自动过滤 null 的 Set
sortedSetOf()     // 元素自动排序的 Set 集合,可以自定义排序规则
```

## Map 集合

写法稍微与 java 不同,如:

```kotlin
val map: MutableMap<Int, String> = mutableMapOf(
    1 to "1",
    2 to "2",
    3 to "3"
)
```

通过 `map.keys` 和 `map.values` 获得相应的集合。

有很多种 map:

```kotlin
mapOf()         // 只读 map
hashMapOf()     // 不保存 key 顺序的 map
mutableMapOf()  // 保存 key 顺序的 map
linkedMapOf()   // 同上
sortedMapOf()   // 自动排序 key 的 map
emptyMap()      // 空 map
```

获取值与 python 差不多,但要注意返回值可能为空:

```kotlin
var one: String? = map[1]
```

判断值是否在 map 中:

```kotlin
map.containsKey()   // 是否包含指定的 key
1 in map            // 同上
map.containsValue() // 是否包含指定的 value
```

遍历也很简单:

```kotlin
map.forEach { k, v -> … }
for (entry in map) { … }
for ((key, value) in map) { … }
```

新增键值对:

```kotlin
map[4] = "4"
map.put(4, "4")
map + (4 to "4")           // 添加新的键值对并生成一个新的 Map
map += (4 to "4")          // 直接添加键值对到当前的 Map
map += mapOf(4 to "4")     // 添加其他 Map 到此 Map 中
map.putAll(mapOf(4 to "4")) // 同上
map.putAll(setOf(4 to "4")) // 键值对集合也是可以的
```

插入相同的 key 时会覆盖,并返回被覆盖的结果:

```kotlin
val old = map.put(1, "one")
```

使用 `remove` 移除不需要的键值对,也可花式删除:

```kotlin
map.remove(1)
map -= 1
map -= listOf(1, 2)
```

也可以通过 value 删除:

```kotlin
map.values.remove("1")
```

Map 有时会返回 null,有些处理方法,如:

```kotlin
map.getOrDefault(5, "5")
map.getOrElse(5) { "5" }
map.getOrPut(1) { "one" } // 获取同时顺手加进去
```

## 集合与数组

对于数组,有很多方法转为集合,这些方法返回的大多是可变集合:

```kotlin
array.toList()
array.toSet()
// …
```

list 可以对其中每个元素操作后的结果转为新的 list,可以对 list 类型转换:

```kotlin
array.map { … }
array.mapIndexed { index, it -> … }
```

对于 map,可以快速单独对 key 和 value 操作:

```kotlin
map.mapKeys {}
map.mapValues {}
```

同时还有压缩操作:

```kotlin
val pairs: List<Pair<Int, String>> = list1.zip(list2)
val map = mutableMapOf<Int, String>()
map.putAll(pairs) // 将两个 List 合成个 Map 集合
val unzipPairs: Pair<List<Int>, List<String>> = pairs.unzip() // 还能解压
unzipPairs.first
unzipPairs.second
```

快速地将 list 转为 map 映射,其中的 value 在匿名函数中指定:

```kotlin
list.associateWith { … }
```

```kotlin
list.associateBy { … }              // 上面的方向操作,指定的 key,list 中的元素作为 value
list.associate { it to it.length }  // 自行返回个键值对
```

二维集合扁平化,将所有数据变成一维的:

```kotlin
list.flatten()
```

过滤操作,list、map 都可以:

```kotlin
list.filter { … }
```

过滤指定类型的集合:

```kotlin
list.filterIsInstance<T>()
```

既需要筛选出来的元素,也要筛出去的元素:

```kotlin
val (match, mismatch) = list.partition {}
```

条件判断:

```kotlin
list.any {}  // 是否至少一个元素满足条件
list.none {} // 集合中是否不存在任何一个元素满足条件
list.all {}  // 集合中是否每一个元素都满足条件
```

分组操作:

```kotlin
list.groupBy { … }
```

裁剪操作:

```kotlin
list.slice(num1..num2)  // 切片操作
list.take()             // 从第一个元素开始指定长度的片段
list.takeLast()         // 同上但是从尾部倒过来
list.drop()             // 这个和 take 是反着的,直接跳过前 N 个元素截取
list.dropLast()         // 同上但是从尾部倒着过来
list.takeWhile {}       // 返回符合指定条件的元素列表
```

分块操作:

```kotlin
list.chunked() // 指定多少个元素分为一块
```

## 序列

一个延迟获取数据的集合:

```kotlin
val sequence: Sequence<Int> = generateSequence { … }
```

使用序列可以对集合操作进行优化,不必每层操作都要执行一遍:

```kotlin
list.asSequence().filter { … }.map { … }.take()
```
