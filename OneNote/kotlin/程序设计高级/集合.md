可创建可变List
val list: MutableList<Int> = mutableListOf(1, 2, 3, 4) // 一个可变List
创建Set集合与上面差不多，创建的Set集合没有重复元素
val set: MutableSet<String> = mutableSetOf("AAA", "BBB", "CCC")
Set更接近数学上的概念，可以进行集合间的操作，如
set1 union set2 // 并集，等同于 +
set1 intersect set2 // 交集
set1 substract set2 // 差集，等同于 -
Set有不同预设的函数进行创建
mutableSetOf(), linkedSetOf() // 底层为LinkedHashSet,维持顺序
hashSetOf() // hash表，不维持顺序
setOf() // 只读的Set
setOfNotNull() // 自动过滤null的Set
sortedSetOf() // 元素自动排序的Set集合,可以自定义排序规则
写法稍微与java不同，如
val map: MutableMap<Int ,String> = mutableMapOf(
1 to "1",
2 to "2",
3 to "3"
)
有很多种map
mapOf() // 只读map
hashMapOf() // 不保存key顺序的map
mutableMapOf() // 保存key顺序的map
linkedMapOf() // 同上
sortedMapOf() // 自动排序key的map
emptyMap() // 空map
获取值与python差不多，但要注意返回值可能为空
var one: String? = map[1]
判断值是否在map中
map.contains() // 是否包含指定的key
map.containskey() // 同上
1 in map // 同上
map.containsValue() // 是否包含指定的Value
遍历也很简单
map.forEach { k, v -> … }
for (entry in map) {…}
for ((key, value) in map) {…}
新增键值对
map[4] = "4"
map.put(4, "4")
map + (4 to "4") // 添加新的键值对并生成一个新的Map
map += (4 to "4") // 直接添加键值对到当前的Map
map += mapOf(4 to "4") // 添加其他Map到此Map中
map.putAll(mapOf( 4 to "4")) // 同上
map.putAll(setOf(4 to "4")) // 键值对集合也是可以的
插入相同的key时会覆盖，并返回被覆盖的结果
val old = map.put(1, "one")
使用remove移除不需要的键值对,也可花式删除
map.remove(1)
map -= 1
map -= listOf(1, 2)
也可以通过value删除
map.values.removes("1")
Map有时会返回Null，有些处理方法,如
map.getOrDefault(5, "5")
map.getOrElse(5) {"5"}
map.getOrPut(1) {"one"} // 获取同时顺手加进去
对于数组，有很多方法转为集合,这些方法返回的大多是可变集合
array.toList()
array.toSet()
…
list可以对其中每个元素操作后的结果转为新的list,可以对list类型转换
array.map { … }
array.mapIndexed {index, it -> …}
对于map，可以快速单独对key和value操作
map.mapKeys {}
map.mapValues {}
同时还有压缩操作
val pairs: List<Pair<Int, String>> = list1.zip(list2)
val map = mutableMapOf<Int, String>()
map.putAll(pairs) // 将两个List合成个Map集合
val unzipPairs: Pair<List<Int>, List<String>> = pairs.unzip() // 还能解压
unzipPairs.first
unzipPairs.second
快速地将list转为map映射，其中的value在匿名函数中指定
list.associateWith { … }
list.associateBy { … } // 上面的方向操作，指定的key，list中的元素作为value
list.associate { it to it.length } // 自行返回个键值对
二维集合扁平化，将所有数据变成一维的
list.flatten()
过滤操作,list ,map都可以
list.filter { … }
过滤指定类型的集合
list.filterIsInstance<T>()
既需要筛选出来的元素，也要筛出去的元素
val (match, mismatch) = list.partition {}
条件判断
list.any {} // 是否至少一个元素满足条件
list.none {} // 集合中是否不存在任何一个元素满足条件
list.all {} // 集合中是否每一个元素都满足条件
分组操作
list.groupBy {..}
裁剪操作
list.slice( num1..num2) // 切片操作
list.take() // 从第一个元素开始指定长度的片段
list.takeLsat() // 同上但是从尾部倒过来
list.drop() // 这个和take是反着的，直接跳过前N个元素截取
list.dropLast() // 同上但是从尾部倒着过来
list.takeWhile {} // 返回符合指定条件的元素列表
分块操作
list.chunked() // 指定多少个元素分为一块
一个延迟获取数据的集合
val sequence: Sequence<Int> = generateSequence { … }
使用序列可以对集合操作进行优化，不必每层操作都要执行一遍
list.asSequence().filter{ … }.map{ … }.take()
