比较两个数组内容是否完全相同  
array1.contentEquals(array2)  
拷贝数组内容到新的数组  
var array: Array\<Int\> = arrayOf(1, 2, 3)  
array1:Array\<Int\> = array.copyOf() // [1, 2, 3]  
array2:Array\<Int?\> = array.copyOf(5) // 拷贝5个元素 [1, 2, 3, null, null]  
array3: Array\<Int\> = array.copyOf(1, 2) // 拷贝范围，从索引1(包括)开始,到索引2(不包括)结束 [2]  
分隔操作

也可以快速查找某个元素  
array.contains(13) // 判断数组中是否包含13这个元素  
13 in array // 同上  
array.indexOf(13) // 查找13这个元素的位置  
array.binarySearch(13) // 二分搜索，要求数据内的元素是有序的  
快速判断和获取元素  
array.any() // 数组是否为空  
array.first() // 快速获取首个元素  
array.last() // 快速获取最后一个元素  
也可以对数组里面的元素倒放  
array.reverse() // 在原数组上进行元素顺序的翻转  
array.reversedArray() // 翻转元素顺序到新的数组中  
还可以把里面的元素打乱  
array.shuffle()  
还可以排序(需实现Comparable接口)  
array.sort() // 排序，排序规则可以自定义  
array.sortDescending() // 按相反顺序排序  
快速填充数组内的内容  
array.fill(element)  
参数列表中变量名前加vararg即可，如  
fun test(vararg str: String) {}  
若要使数组作为可变长参数，可加*将数组拆出来，如  
test(*array)  
对于基本类型数组，都有相应的数组类，这样的效率可以优化，如

val array: Array\<IntArray\> = arrayOf(arrayOf(1, 2), arrayOf(3, 4), arrayOf(5, 6))
