# 数组

## 创建数组

使用 `arrayOf()`、`arrayOfNulls()`、`emptyArray()` 创建。

`Array` 是个泛型类:

![[_assets/数组/数组__09-14-19-0.png]]

使用类 `Array` 构造函数创建:

```kotlin
public inline constructor(size: Int, init: (Int) -> T)
// size: 初始化数组大小
// init: 初始化操作,循环调用传入函数 size 次,返回结果自动填充到相应位置

val array: Array<Int> = Array(3) { it } // 结果为 [0, 1, 2]
```

## 遍历数组

一个个元素遍历:

```kotlin
for (e in array) {
    println(e)
}
```

一个个通过索引遍历:

```kotlin
for (i in array.indices) {
    println(array[i])
}
```

同时遍历索引和元素,使用 `withIndex` 函数,生成一系列的 `IndexedValue` 对象:

```kotlin
for ((index, element) in array.withIndex()) {
    println("element is $element, index is $index")
}
```

类似于 java 的 stream 流,使用 lambda 表达式:

```kotlin
array.forEach { println(it) }
array.forEachIndexed { index, element ->
    println("element is $element, index is $index")
}
```

## 数组操作

比较两个数组内容是否完全相同:

```kotlin
array1.contentEquals(array2)
```

两个数组也可以通过 `+` 拼接在一起。

拷贝数组内容到新的数组:

```kotlin
var array: Array<Int> = arrayOf(1, 2, 3)
val array1: Array<Int> = array.copyOf()          // [1, 2, 3]
val array2: Array<Int?> = array.copyOf(5)        // 拷贝 5 个元素 [1, 2, 3, null, null]
val array3: Array<Int> = array.copyOfRange(1, 3) // 拷贝范围,从索引 1(包括)开始,到索引 3(不包括)结束 [2, 3]
```

分隔操作:

```kotlin
array.sliceArray(0..1)
```

也可以快速查找某个元素:

```kotlin
array.contains(13) // 判断数组中是否包含 13 这个元素
13 in array        // 同上
```

```kotlin
array.indexOf(13)      // 查找 13 这个元素的位置
array.binarySearch(13) // 二分搜索,要求数组内的元素是有序的
```

快速判断和获取元素:

```kotlin
array.any()    // 数组是否为空
array.first()  // 快速获取首个元素
array.last()   // 快速获取最后一个元素
```

也可以对数组里面的元素倒放:

```kotlin
array.reverse()        // 在原数组上进行元素顺序的翻转
array.reversedArray()  // 翻转元素顺序到新的数组中
```

还可以把里面的元素打乱:

```kotlin
array.shuffle()
```

还可以排序(需实现 `Comparable` 接口):

```kotlin
array.sort()            // 排序,排序规则可以自定义
array.sortDescending()  // 按相反顺序排序
```

快速填充数组内的内容:

```kotlin
array.fill(element)
```

## 可变长参数

参数列表中变量名前加 `vararg` 即可:

```kotlin
fun test(vararg str: String) {}
```

若要使数组作为可变长参数,可加 `*` 将数组拆出来:

```kotlin
test(*array)
```

## 原生类型数组

他们都有自有的方法:

```kotlin
val array: IntArray = intArrayOf(1, 2, 3, 4)
```

## 二维数组

类似于 java,可以这样声明:

```kotlin
val array: Array<IntArray> = arrayOf(arrayOf(1, 2), arrayOf(3, 4), arrayOf(5, 6))
```

比较二维数组的所有内容,需要深度比较:

```kotlin
array.contentDeepEquals(other)
```
