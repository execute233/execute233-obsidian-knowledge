# 特殊类型

## 数据类型

使用 `data` 修饰类,该类仅存储数据,且对该类有以下要求:

- 主构造函数中至少有一个参数。
- 主构造函数中的参数必须标记为 `val` 或 `var`。
- 数据类不能是抽象的、开放的、密封的或内部的。

同时编译器会自动生成以下函数:`equals()`、`hashCode()`、`toString()`、`componentN()`、`copy()`。

注意,编译器只会根据主构造函数中定义的属性生成对应函数,如果有些时候我们不希望这些属性被添加到自动生成的函数中,我们需要手动将其移出主构造函数,如:

```kotlin
data class Person(val name: String) {
    var age: Int = 0 // age 不会被处理
}
```

可以手动重写 `equals()` 和 `hashCode()`,但无法手动重写 `copy()`、`componentN()`,因为它们会覆盖父类。

## 枚举类型

使用 `enum` 修饰类,该类仅存储不同的多种状态,与 java 相似。

对于 enum 对象,有几个属性和方法可以直接调用:

```kotlin
enum.name     // 当前枚举的对象名
enum.ordinal  // 当前枚举的排列位置,位置与索引相似
```

也可以自定义属性和方法,如:

```kotlin
enum class LightState(var color: String) {
    RED("red"), YELLOW("yellow"), GREEN("green");
    fun isGreen() = this == GREEN
}
```

对于类也有方法和属性:

```kotlin
Enum.valueOf()         // 以字符串名称的形式转换为对应名称的枚举
enumValueOf<Enum>()    // 同上
Enum.entries           // 获取所有枚举
```

## 匿名类

使用 `object` 声明,如:

```kotlin
var obj = object [: 接口] {
    fun test()
    var age: Int = 18
}
// 这样的类是没有构造函数的
```

同时,如果一个接口有 `fun` 修饰符,则它是个函数式接口,重写与 java 相似,如:

```kotlin
fun interface KRunnable {
    fun invoke()
}

fun main() {
    var runnable = KRunnable { … }
    runnable.invoke()
}
```

也比如:

```kotlin
fun main() {
    test { … } // 直接现场写调用
}

fun interface Printer {
    fun print()
}

fun test(printer: Printer) {
    // 需要 Printer 接口实现对象
    printer.print()
}
```

## 单例类

单例类全局只能存在一个实例对象,其定义与类相似,但不能通过构造函数获取对象:

```kotlin
object Singleton { … }

fun main() {
    var singleton = Singleton
}
```

## 伴生对象

既支持单例类那样调用,又支持普通 class 那样调用(单例类写在普通类内部),类似于 java 的静态调用,如:

```kotlin
class Student(val name: String, val age: Int) {
    companion object Tools {
        fun create(name: String, age: Int) = Student(name, age)
    }
}

fun main() {
    Student.create("xx", 18)
}
```

## 委托模式

将构造操作委托给参数:

```kotlin
class Derived(var b: Base) : Base by b
interface Base { fun print() }
class BaseImpl : Base { … }

fun main() {
    var base: Base = Derived(BaseImpl())
}
```

属性也可以委托:

```kotlin
import kotlin.reflect.KProperty
class Example {
    var p: String by Delegate
}

class Delegate {
    // 需要重载属性的获取和设置
    operator fun getValue(thisRef: Any?, property: KProperty<*>): String { … }
    operator fun setValue(thisRef: Any?, property: KProperty<*>, value: String) { … }
}
```

太麻烦了,可以使用预设的 `lazy`,但只能对获取进行操作,对 `Example` 类修改为:

```kotlin
class Example {
    var p: String by lazy { … }
}
```

属性也可以委托给另一个属性:

```kotlin
class Example {
    var a: String = "xxx"
    var p: String by this::a
}
```

属性也可以委托给 map:

```kotlin
class User(map: MutableMap<String, Any>) {
    var name: String by map
    var age: Int by map
}

fun main() {
    val map: MutableMap<String, Any> = mutableMapOf(
        "name" to "xxx",
        "age" to 18
    )
    val user = User(map)
}
```
