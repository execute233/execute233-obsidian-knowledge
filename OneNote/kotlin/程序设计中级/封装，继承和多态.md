## 类的扩展函数

扩展函数也可以用变量接收。

可以在已有的类外部定义新的函数,也可以在其他类里面定义另外一个类的扩展函数,如:

```kotlin
fun main() {
    var str = "a"
    str.test()
}
fun String.test() {
    println(this)
}
```

```kotlin
fun main() {
    var func: String.() -> Int = {
        this.length
    }
    println("12345".func()) // func("12345") 也是可以的,这里的结果为 5
}
```

比如:

```kotlin
val stu = Student("xx0", 18)
stu.name = "xx1"
stu.hello()
```

可替换为:

```kotlin
Student("xx0", 18).apply {
    this.name = "xx1"
}.hello()
```

有时需要对象满足某些条件才能处理,可以用 `takeIf`,如:

```kotlin
str.takeIf { it.length > 7 }?.let { it + it } ?: str // 判断字符串长度是否大于 7,是则返回重复一次的字符串,否则原样返回
```

要对某个对象专门处理并返回不同类型的结果,可用 `with`,如:

```kotlin
val str = "xxx"
val len = with(str) {
    str.length
}
```

## 官方高阶扩展函数

为了简化开发,官方提供了一些高阶扩展函数在 `Any` 中,以便自定义简化开发。

有以下官方高阶扩展函数:

|定义|调用|说明|
|---|---|---|
|`fun <T> T.apply(block: T.() -> Unit): T {…}`|`obj.apply {…}`|在 `{}` 处理对象内的操作,并返回对象本身,利于链式调用|
|`fun <T> T.also(block: (T) -> Unit): T {…}`|`obj.also {…}`|在 `{}` 处理 it(传入参数)操作,返回对象本身,与 apply 相似|
|`fun <T, R> T.let(block: (T) -> R): R {…}`|`obj.let {…}`|在 `{}` 处理 it(传入参数)操作,返回处理最后一行的结果|
|`fun <T, R> T.run(block: T.() -> R) {…}`|`obj.run {…}`|在 `{}` 处理对象内的操作,返回处理最后一行的结果,与 let 相似|

`takeUnless` 与 `takeIf` 相反。

继承方式与 python 一样,但要写构造函数,如:

```kotlin
open class Student {}
class ArtStudent : Student() {}
```

使方法可被重写,用 `open` 关键字,子类用 `override` 关键字,变量也一样,如:

```kotlin
open class Student(var age: Int) {
    open val name: String = "xx"
    open fun say() = println("student")
}
```

```kotlin
class ArtStudent(age: Int) : Student(age) {
    override val name: String = "xxx"
    get() {}
    set(value) {}
    override fun hello() = println("artStudent")
}
```

使用 `is` 关键字判断变量是否为某个类或类的子类,某个接口的实现,如:

```kotlin
artStudent is Student
```

使用 `as` 可以强制转换成子类,对于空可以用 `as?`,如:

```kotlin
val student: Student? = null
val artStudent: ArtStudent = student as? ArtStudent ?: ArtStudent()
```
