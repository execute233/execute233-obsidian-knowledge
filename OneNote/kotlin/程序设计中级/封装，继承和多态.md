为了简化开发，官方提供了一些高阶扩展函数在Any中，以便自定义简化开发
有以下的官方高阶扩展函数

|   |   |   |
|---|---|---|
|定义|调用|说明|
```xml
fun \<T\> T.apply(block: T.() -\> Unit): T {…}
```
```kotlin
obj.apply{…}
```
在{}处理对象内的操作，并返回对象本身，利于链式调用|
```xml
fun \<T\> T.also(block: (T) -\> Unit): T {…}
```
```kotlin
obj.also{…}
```
在{}处理it(传入参数)操作,返回对象本身，与apply相似|
```xml
fun \<T, R\> T.let(block: (T) -\> R): R {…}
```
```kotlin
obj.let{…}
```
在{}处理it(传入参数)操作,返回处理最后一行的结果|
```xml
fun \<T, R\> T.run(block: T.() -\> R) {…}
```
```kotlin
obj.run{…}
```

takeUnless与takeIf相反

继承方式与python一样，但要写构造函数,如
open class Student {}
class ArtStudent : Student() {}
使方法可被重写，用open关键字，子类用override关键字,变量也一样，如
open class Student(var age: Int) {
open val name: String = "xx"
open fun say() = println("student")
}
class ArtStudent(age: Int): Student(age) {
override val name:String = "xxx"
get() {}
set(value) {}
override fun hello() = println("artStudent")
}
使用is关键字判断变量是否为某个类或类的值类，某个接口的实现，如
artStudent is Student
使用as可以强制转换成子类，对于空可以用as？，如
val student: Student? = null
val artStudent: ArtStudent = student as? ArtStudent ?: ArtStudent()
可以在已有的类外部定义新的函数，也可以在其他类里面定义另外一个类的扩展函数，如
fun main() {
var str = "a"
str.test()
}
fun String.test() {
println(this)
}
fun main() {
var func: String.() -> Int = {
this.length
}
println("12345".func()) // func("12345") 也是可以的，这里的结果为5
比如：
val stu = Student("xx0", 18)
stu.name = "xx1"
stu.hello()
可替换为
Student("xx0", 18).apply {
this.name = "xx1"
}.hello()
有时需要对象满足某些条件才能处理，可以用takeif，如
str.takeIf {it.length > 7}?.let {it + it} ?: str // 判断字符串长度是否大于7，是则返回重复一次的字符串，否则原样返回
要对某个对象专门处理并返回不同类型的结果，可用with，如
val str = "xxx"
val len = with(str) {
str.length
}
