# 类与对象

## 类的定义

与 java 类似,单独一个文件一个类。

## 构造函数

除了主构造函数外,还可以有次构造函数。

对象初始化,在类里使用 `init` 关键字:

```kotlin
class Student {
    init {
        // 初始化代码…
    }
}
```

## 运算符重载

使用 `operator` 关键字指定方法实现,如:

```kotlin
operator fun plus(another: Student): Student {
    return Student(another.name, another.age)
}
```

常见的运算符对应的函数名称:

|符号|对应的函数名称|符号|对应的函数名称|符号|对应的函数名称|符号|对应的函数名称|
|---|---|---|---|---|---|---|---|
|`+a`|`a.unaryPlus()`|`a + b`|`a.plus(b)`|`a..b`|`a.rangeTo(b)`|`a -= b`|`a.minusAssign(b)`|
|`-a`|`a.unaryMinus()`|`a - b`|`a.minus(b)`|`a..<b`|`a.rangeUntil(b)`|`a *= b`|`a.timesAssign(b)`|
|`!a`|`a.not()`|`a * b`|`a.times(b)`|`a in b`|`a.contains(b)`|`a /= b`|`a.divAssign(b)`|
|`a--`|`a.dec()`|`a / b`|`a.div(b)`|`a !in b`|`!a.contains(b)`|`a %= b`|`a.remAssign(b)`|
|`a++`|`a.inc()`|`a % b`|`a.rem(b)`|`a += b`|`a.plusAssign(b)`|||

重载些比较运算符,甚至是小括号,索引运算符:

|运算符|对应的函数名称|运算符|对应的操作|运算符|对应的操作|运算符|对应的操作|
|---|---|---|---|---|---|---|---|
|`a > b`|`a.compareTo(b) > 0`|`a()`|`a.invoke()`|`a[i]`|`a.get(i)`|`a[i] = b`|`a.set(i, b)`|
|`a < b`|`a.compareTo(b) < 0`|`a(i)`|`a.invoke(i)`|`a[i, j]`|`a.get(i, j)`|`a[i, j] = b`|`a.set(i, j, b)`|
|`a >= b`|`a.compareTo(b) >= 0`|`a(a, j)`|`a.invoke(i, j)`|`a[i_1,..,i_n]`|`a.get(i_1,…,i_n)`|`a[i_1,..,i_n] = b`|`a.set(i_1,…,i_n, b)`|
|`a <= b`|`a.compareTo(b) <= 0`|`a(i_1,..,i_n)`|`a.invoke(i_1,..,i_n)`|||||

## 中缀函数

使用时可以省略调用的点和括号,使用 `infix` 关键字修饰函数,且该函数必须是成员函数,只有一个参数,参数没有默认值。

```kotlin
class Student(var name: String, var age: Int) {
    infix fun text(string: String): String {
        return name + string
    }
}
```

```kotlin
fun main() {
    var stu = Student("xxx", 18)
    println(stu text "xxx")
}
```

中缀函数的运算优先级低于算数运算符、类型转换和 `rangeTo`,但高于逻辑运算符,如:

|表达式1|等价于表达式1的表达式|表达式2|等价于表达式2的表达式|
|---|---|---|---|
|`1 shl 2 + 3`|`1 shl (2 + 3)`|`a && b xor c`|`a && (b xor c)`|
|`0 until n * 2`|`0 until (n * 2)`|`a xor b in c`|`(a xor b) in c`|

## 空值和空类型

可以使用 `?:`(Elvis 运算符)自定义为空时的返回结果。

```kotlin
var str: String = null
val len: Int = str?.length ?: 0
```

## 解构声明

kotlin 不允许变量为 null,只有类型后加 `?` 为可空类型,这样后续操作可空变量需检查,如:

```kotlin
val stu: Student? = null
if (stu != null) {
    stu.name // 这里判断了非空,Student? 自动转换为 Student 类型
}
```

若明确该变量不为空,需 `!!` 强制使用,如:

```kotlin
stu!!.name // 可能会出现 NPE
```

但有更安全的操作,在后面用 `?`,变量引用为空时返回 null,如:

```kotlin
var str: String? = null
println(str?.length)
```

访问对象里的属性,可以优雅地将其内部属性解构出来,如:

```kotlin
val stu = Student("xxx", 18)
val (a, b) = stu // 直接把属性取出来,很优雅
println("name: $a, age: $b")
```

要实现这样的结构,需要添加约定函数,定义不定个 `componentN` 函数并通过赋值的方式返回解构的结果,如:

```kotlin
class Student(var name: String, var age: Int) {
    operator fun component1() = name // 解构的第一个参数
    operator fun component2() = age // 解构的第二个参数
    // operator fun component3() … // 以此类推
}
```

它也可以在 lambda 中解构,如:

```kotlin
val func1: (Student, Int) -> Unit = { (name, age), num ->
    语句..
}
```

## 访问权限控制

在类、对象、接口、构造函数和函数以及属性上都可使用,默认 `public`,有以下修饰符:

|修饰符|作用|备注|
|---|---|---|
|`public`|任何地方可访问|默认修饰符|
|`private`|当前文件可访问||
|`internal`|同一模块中可见||
|`protected`|仅子类可用|顶级声明不可用|

在类名后面加个小括号,如:

```kotlin
class Student(var name: String, var age: Int) {}
// 这样指定了必有的属性
```

要添加访问修饰符,例如:

```kotlin
class Student private constructor(name: String, age: Int) {}
```

要自定义属性的 `get`、`set`,可以这样:

```kotlin
class Student(name: String, age: Int) {
    var name: String
        get() {}
        set() {}
}
```

不想要立马初始化属性,可以用 `lateinit` 懒加载:

```kotlin
class Student() {
    lateinit var name: String
}
```

如果该类有一个主构造函数,则每个次构造函数要通过另一个次构造函数直接或间接地委托给主构造函数:

```kotlin
class Student(var name: String, var age: Int) {
    constructor(name: String) : this(name, 18)
}
```
