# 函数

kotlin 函数与 OOP 关系紧密,函数扩展对象操作详见 [[kotlin/程序设计中级/封装，继承和多态]];lambda / apply / let / run / also 都在 [[kotlin/程序设计中级/封装，继承和多态]] 应用。

## 函数的创建与使用

```kotlin
fun 函数名称([函数参数1: 类型[= 默认值], …]): 返回值类型 {
    语句
}
```

写的更简单点:

```kotlin
fun test(a: Int, b: Int) = a + b // 返回类型可以自动推断
```

## 递归函数

任何递归函数都可以用 `while` 写。

使用 `tailrec` 关键字优化递归函数,在编译阶段就能转为 `while` 进行优化。

## 函数类型

典型的函数类型要有接受的参数列表与返回值。

```kotlin
var func0: (Int) -> Unit // 表示存储接受 Int 参数但没返回值的函数
var func1: (Double, Double) -> String // 表示存储接受两个 Double 参数且返回值为 String 的函数
```

同样的,作为函数的参数可以这样写,并且能被当做普通函数被调用:

```kotlin
fun test(other: (Int) -> String) {
    other()
}
```

函数类型变量的赋值有下面几种方式:

```kotlin
var func: (String) -> Int = ::test // 这里 test 是一个已声明的函数 test(String): Int
var func: (String) -> Int = fun(str: String): Int {
    语句…
    return xxx
} // 直接现场写匿名函数
var func: (String) -> Int = fun(str: String) = 10 // 返回结果为固定值的函数可以直接这样写
var func: (String, String) -> Int = { a, b ->
    println(a)
    println(b)
    10
} // 写 lambda 更简洁,不使用参数可用 _ 弃用
```

对于接受参数为函数,调用时也可以用 lambda:

```kotlin
fun main() {
    test {
        println(it) // 一个参数 lambda 里面默认名字叫 it
        20
    }
}
```

```kotlin
fun test(func: (String) -> Int) {
    func("Hello World!")
}
```

匿名函数要显示使用 `return` 需要打标签:

```kotlin
val func: (Int) -> String = test@{
    if (it > 10) return@test "result"
    "result $it"
}
```

## 内联函数(使用 inline 关键字修饰方法)

`inline` 会把方法里的代码复制到调用处。

可对参数列表修饰 `noinline` 不进行内联。
