典型的函数类型要有接受的参数列表与返回值
var func0: (Int) -> Unit // 表示存储接受Int参数但没返回值的函数
var func1: (Double, Double) -> String // 表示存储接受两个Double参数切返回值为String的函数
同样的，作为函数的参数可以这样写，并且能被当做普通函数被调用
fun test(other: (Int) -> String) {
other()
}
