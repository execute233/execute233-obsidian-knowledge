# 基础语法

kotlin 语言基于 **类** 和 **函数** 组织代码。详细 OOP 三大特性见 [[kotlin/程序设计中级/类与对象|类与对象]]、[[kotlin/程序设计中级/封装，继承和多态|封装,继承和多态]];函数定义与高阶函数见 [[kotlin/程序设计中级/函数|函数]]。

## 声明变量

```kotlin
var [变量名称]: [变量类型] = [值]
// 可写 var a = 10,编译器会自动推断类型
```

## 顶层变量(定义在文件里)

```kotlin
var globalVar = "顶层变量"
```

## 声明常量

```kotlin
val [变量名称]: [变量类型] = [值]
// 可写 val a = 10,编译器会自动推断类型
```

## 条件判断

这里的 `if` 内仍可嵌套代码,默认最后一行作为返回的结果:

```kotlin
// 这里判断 score 是否大于 60,是就得到 Yes,否就得到 No,并且可以直接赋值给变量
var res = if (score > 60) "Yes" else "NO"
```

## 选择结构(类似于 switch)

```kotlin
when (目标) {
    匹配值1, 匹配值2… -> 代码…
    匹配值3, 匹配值4… -> 代码…
    else -> {
        代码…
    }
}
```

同时,与 `if` 一样可返回值。

也可以使用任意表达式作为分支条件,如:

```kotlin
val score = XXX
val grade = when (score) {
    in 100..90 -> "优秀"
    in 89..80 -> "良好"
    …
    else -> "不及格"
}
```

## 循环(类似于 python)

```kotlin
for (遍历的单个变量 in 可遍历目标 [step 步长]) {
    语句..
}
```

也可以反过来遍历:

```kotlin
for (i in 10 downTo 1 [step 步长]) {
    语句…
}
```

同时也可用:

```kotlin
while (循环条件) {
    语句..
}
```

## 属性

属性(property)是 kotlin 类成员的基础,详细访问控制见 [[kotlin/程序设计中级/类与对象|类与对象]]:

```kotlin
var <propertyName>[: <PropertyType>][= <property-initializer>]
    [<getter>]
    [<setter>]
```

例如:

```kotlin
var a: Int = 5
    get() {
        field * 10
    }
    set(value) {
        field = value // field 是 a 变量,value 是赋值的变量
    }
```

## 起别名

使用 `typealias` 关键字给类型起别名,如:

```kotlin
typealias Test = () -> Unit // Test 类型是一个无参数列表且无返回值的函数
```
