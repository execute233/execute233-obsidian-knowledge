3. 二进制层面上的操作（仅Int和Long）

|   |   |   |
|---|---|---|
|shl(bits)|有符号左移(乘以2的几次方)|`1 shl 2 = 4`|
|shr(bits)|有符号右移(除以2的几次方)|`8 shr 2 = 2`|
|ushr(bits)|无符号右移||
|and(bits)|按位与|`0111 and 0011 = 0011`|
|or(bits)|按位或|`0111 or 0011 = 0111`|
|xor(bits)|按位异或|`0111 xor 0011 = 0100`|
|inv(bits)|取反||
