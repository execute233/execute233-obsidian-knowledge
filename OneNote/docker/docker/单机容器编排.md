# 单机容器编排

## 快速开始

安装插件：

```bash
apt install docker-compose-plugin
```

IDEA 配置：配置成自己的 `docker-compose` 可执行文件路径。

配置路径示例：

| 配置项 | 路径 |
|---|---|
| Docker 可执行文件 | `/usr/local/bin/docker` |
| Docker 机器可执行文件 | （留空） |
| Docker Compose 可执行文件 | `/usr/local/bin/docker-compose`（v2.6.1） |

Compose V2 说明：从 Docker Desktop 3.4.0 开始，可以使用新的 Compose V2，它支持将 `compose` 命令作为 Docker CLI 的一部分。

然后编写 `docker-compose.yml` 文件：

```yaml
version: "3.9"  # docker 对应的版本号
```
