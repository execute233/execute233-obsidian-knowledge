**容器控制操作**
查看容器中的输出日志信息，可以加-t持续打印日志信息
docker logs 容器名/容器ID
容器已经启动，想要进入容器（前提创建容器时使用-i）
docker attach 容器名/容器ID
在容器中启动新的终端或是在容器中执行命令
docker exec -it 容器名/容器id bash
强制终止容器
docker kill 容器名/容器ID
暂停/恢复容器
docker pause/unpause 容器名/容器ID
**物理资源管理**
在启动时可以添加一些参数来对物理资源进行限制，如
docker run -m 内存限制 --memory-swap=内存与交换分区总共的内存的限制(一般是前面的2倍) 镜像名
可以对已有容器限制
docker update --memory 1024m container_name
限定CPU权重（默认1024）
docker run -c 1024 镜像名
限定使用的CPU核心，比如
docker run -it --cpuset-cpus=0, 1 镜像名
可以使用--cpus限定使用的CPU核心数（使用总和为几个CPU核心）
还有对磁盘IO读写的性能限制
docker run -it --device-write-bps=/dev/sda:10MB 镜像名 # 限制每秒写入数据量为10MB
**容器监控**
可以查看所有容器的情况
docker stats
查看指定容器中的进程
docker top 容器名/容器ID
