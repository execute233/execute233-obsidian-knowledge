**容器网络类型**  
可以使用以下命令产看docker默认创建的3个网络  
docker network ls # 有bridge、host、none三种  
默认的镜像什么都没有，需要安装  
apt install net-tools iputils-ping curl  
我们可以将其构建为新的镜像  
docker commit xxx xxx  
在启动前可以指定网络(默认bridge)  
docker run -it --network=bridge/host/none xxx  
也可以指定共享指定容器的网络（类似于配置host的容器，不过这里host的宿主是指定容器）  
docker run -it -network=container:容器名 xxx  
可以查看docker0网桥的配置  
docker network inspect bridge  
**自定义网络**  
docker默认提供三种网络驱动：bridge、overlay、macvlan  
可以这样创建自定义网络  
docker network create --driver bridge xxxx  
可以指定容器连接到的网络  
docker network connect \<网络名称\> \<容器名/容器ID\>  
**容器间网络**  
容器部署后的ip是自动分配的，但可以使用--ip来手动指定  
但还是不方便，可以借助docker的DNS服务器来解析到对应容器，注意只能在用户自定义网络下生效  
只要在启动时指定容器名字即可，在相同网络其他容器即可 ping 名称  
docker run -it --name=xxx --network=xxx xxx
