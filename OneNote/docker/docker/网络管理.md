# 网络管理

## 容器网络类型

容器间通信的端口映射、自定义网络、DNS 解析都依赖于 [[docker/docker/容器与镜像|容器与镜像]] 所创建的网络命名空间，每个容器拥有独立的网络栈。

可以使用以下命令查看 docker 默认创建的 3 个网络：

```bash
docker network ls    # 有 bridge、host、none 三种
```

默认的镜像什么都没有，需要安装：

```bash
apt install net-tools iputils-ping curl
```

我们可以将其构建为新的镜像：

```bash
docker commit xxx xxx
```

在启动前可以指定网络（默认 bridge）：

```bash
docker run -it --network=bridge/host/none xxx
```

也可以指定共享指定容器的网络（类似于配置 host 的容器，不过这里 host 的宿主是指定容器）：

```bash
docker run -it --network=container:容器名 xxx
```

可以查看 docker0 网桥的配置：

```bash
docker network inspect bridge
```

## 自定义网络

docker 默认提供三种网络驱动：bridge、overlay、macvlan。

可以这样创建自定义网络：

```bash
docker network create --driver bridge xxxx
```

可以指定容器连接到的网络：

```bash
docker network connect <网络名称> <容器名/容器ID>
```

## 容器间网络

容器部署后的 ip 是自动分配的，但可以使用 `--ip` 来手动指定：

```bash
docker run --ip xxx
```

但还是不方便，可以借助 docker 的 DNS 服务器来解析到对应容器，注意只能在用户自定义网络下生效。

只要在启动时指定容器名字即可，在相同网络其他容器即可 `ping` 名称：

```bash
docker run -it --name=xxx --network=xxx xxx
```
