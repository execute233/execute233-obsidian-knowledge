配置
docker-compose.yaml文件一般是这样的

![[_assets/安装与配置/安装与配置__09-14-58-0.png]]

下面操作都需要在docker-compose.yaml所在目录下运行
运行
docker compose up -d (d表示后台运行)
启动、停止、重启
docker-compose start
docker-compose stop
docker-compose restart
查看compose状态
docker-compose ps
停止并删除容器
docker compose down （加上-v代表连同数据卷一起删）
重新构建镜像（修改了构建目录里的代码）
docker compose build
