# 安装与配置

## 安装

麻烦，自己搜。

## 配置

`docker-compose.yaml` 文件一般是这样的：

![[_assets/安装与配置/安装与配置__09-14-58-0.png]]

下面操作都需要在 `docker-compose.yaml` 所在目录下运行。

## 运行

```bash
docker compose up -d    # -d 表示后台运行
```

## 启动、停止、重启

```bash
docker-compose start
docker-compose stop
docker-compose restart
```

## 查看 compose 状态

```bash
docker-compose ps
```

## 停止并删除容器

```bash
docker compose down    # 加上 -v 代表连同数据卷一起删
```

## 重新构建镜像

修改了构建目录里的代码时：

```bash
docker compose build
```
