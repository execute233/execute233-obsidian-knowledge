测试函数  
go test命令是用于测试依赖，所有以_test.go为后缀的都是test测试的一部分  
在*_test.go有3种类型的函数

|   |   |   |
|---|---|---|
|测试函数|函数名前缀为Test|测试程序的一些逻辑行为是否正确|
|基准函数|函数名前缀为Benchmark|测试函数的性能|
|示例函数|函数名前缀为Example|为文档提供示例文档|

每个测试函数必须导入testing包、基本格式为  
func TestName(t *testing.T) {} T用于报告测试失败和附加的日志信息，有以下方法

|   |   |   |
|---|---|---|
|Error(args ...interface{})|Errorf(format string, args ...interface{})|Fail()|
|FailNow()|Failed() bool|Fatal(args ...interface{})|
|Fatalf(format string, args ...interface{})|Log(args ...interface{})|Logf(format string, args ...interface{})|
|Name() string|Parallel()|Run(name string, f func(t *T)) bool|
|Skip(args ...interface{})|SkipNow()|Skipf(format string, args ...interface{})|
|Skipped() bool|||

然后我们就可以在对应的*_test.go文件目录下执行go test命令  
可添加-v参数，查看测试函数名称与时间  
可添加-run=""使用正则表达式匹配测试函数  
测试组  
可以用以下方式添加测试组  
func TestSplit(t *testing.T) {  
// 定义一个测试用例类型  
type test struct {  
input string  
sep string  
want []string  
}  
// 定义一个存储测试用例的切片  
tests := []test{  
{input: "a:b:c", sep: ":", want: []string{"a", "b", "c"}},  
{input: "a:b:c", sep: ",", want: []string{"a:b:c"}},  
{input: "abcd", sep: "bc", want: []string{"a", "d"}},  
{input: "沙河有沙又有河", sep: "沙", want: []string{"河有", "又有河"}},  
}  
// 遍历切片，逐一执行测试用例  
for _, tc := range tests {  
got := Split(tc.input, tc.sep)  
if !reflect.DeepEqual(got, tc.want) {  
t.Errorf("expected:%v, got:%v", tc.want, got)  
}  
}  
}  
子测试  
使用t.Run来完成子测试，如  
func TestSplit(t *testing.T) {  
type test struct { // 定义test结构体  
input string  
sep string  
want []string  
}  
tests := map[string]test{ // 测试用例使用map存储  
"simple": {input: "a:b:c", sep: ":", want: []string{"a", "b", "c"}},  
"wrong sep": {input: "a:b:c", sep: ",", want: []string{"a:b:c"}},  
"more sep": {input: "abcd", sep: "bc", want: []string{"a", "d"}},  
"leading sep": {input: "沙河有沙又有河", sep: "沙", want: []string{"河有", "又有河"}},  
}  
for name, tc := range tests {  
t.Run(name, func(t *testing.T) { // 使用t.Run()执行子测试  
got := Split(tc.input, tc.sep)  
if !reflect.DeepEqual(got, tc.want) {  
t.Errorf("expected:%#v, got:%#v", tc.want, got)  
}  
})  
}  
}  
测试覆盖率  
go test -cover可获取覆盖率  
-coverprofile可以将覆盖率相关记录输出到文件  
基准测试  
函数命名规则如下：  
func BenchmarkName(b *testing.B){}  
有以下方法

|   |   |   |
|---|---|---|
|Error(args ...interface{})|Errorf(format string, args ...interface{})|Fail()|
|FailNow()|Failed() bool|Fatal(args ...interface{})|
|Fatalf(format string, args ...interface{})|Log(args ...interface{})|Logf(format string, args ...interface{})|
|Name() string|ReportAllocs()|ResetTimer()|
|Run(name string, f func(b *B)) bool|RunParallel(body func(*PB))|SetBytes(n int64)|
|SetParallelism(p int)|Skip(args ...interface{})|SkipNow()|
|Skipf(format string, args ...interface{})|Skipped() bool|StartTimer()|
|StopTimer()|||

基准测试默认不会执行，需要添加-bench参数，比如  
go test -bench=Split 表示对Split函数进行基准测试  
还可以添加-benchmem来获取内存统计数据  
性能比较函数  
我们可以编写多个对外暴露的基准函数来进行比较，如  
func benchmark(b *testing.B, size int){/* ... */}  
func Benchmark10(b *testing.B){ benchmark(b, 10) }  
func Benchmark100(b *testing.B){ benchmark(b, 100) }  
func Benchmark1000(b *testing.B){ benchmark(b, 1000) }  
重置时间  
b.ResetTimer来重置计时器  
Setup与TearDown  
测试程序有时需要在测试之前进行额外的设置（setup）或在测试之后进行拆卸（teardown）  
定义TestMain函数来可以在测试之前进行额外的设置或者测试之后进行拆卸  
func TestMain(m *testing.M) {  
fmt.Println("write setup code here...") // 测试之前的做一些设置  
// 如果 TestMain 使用了 flags，这里应该加上flag.Parse()  
retCode := m.Run() // 执行测试  
fmt.Println("write teardown code here...") // 测试之后做拆卸工作  
os.Exit(retCode) // 退出测试  
}

可以自己操作，封装为方法
