# 泛型

## 方法内使用泛型

```go
func reverse[T any](t []T) []T
```

我们可以指定 T 是哪些类型,如 `[T int | float64]`。

可以定义多个泛型,如 `[K int | string, V float32 | float64]`。

## 类型泛型

我们也可以在类型里使用泛型,如:

```go
type Tree[T interface{}] struct {
    value T
}
```

可以为有泛型的类型定义方法,如:

```go
func (t *Tree[T]) Lookup(x T) *Tree[T] { ... }
```

实例化类型需要指定泛型,如:

```go
var stringTree Tree[string]
```

## 类型约束

类型约束定义了一个类型集——只有在这个类型集中的类型才能用作类型实参。

比如:

```go
func min[T interface{ int | float64 }](a, b T) T {}
```
