**变量声明**  
声明一个变量(可以声明全局)  
var name \<type\> // 默认值为0  
声明并赋值(可以声明全局)  
var name \<type\> = \<value\>  
初始化的时候省去数据类型，通过值自动匹配当前变量的数据类型(可以声明全局)  
var \<name\> = \<value\>  
省去var直接自动匹配(不能声明全局)  
\<name\> := \<value\>  
多变量声明  
var v1, v2 [type(全部变量类型一样)] = value1, value2  
也或者：  
var (  
v1 [type] = value1  
v2 [type] = value2  
)  
查看数据类型，可以使用fmt.printf("%T", v)  
**常量**  
常量定义  
const \<name\> \<type\> = \<value\>  
可以定义枚举  
const (  
BEIJIN = iota // iota表示自增，赋值0后面每个+1，每个枚举也可以单独赋值  
SHANGHAI  
SHENZHEN  
)  
也可以  
const (  
BEIJIN = 10*iota // 0  
SHANGHAI // 10  
SHENZHEN // 20  
)  
比如  
const (  
a, b = iota+1, iota+2 // 1, 2  
c, d // 2, 3  
e, f // 3, 4  
g, h = iota*2, iota*3 // 6, 9  
i, k // 8, 12  
)

**函数**  
定义  
func \<func_name\>([param1 \<type\>, …]) [return_type] | ([return_type1, type2, …]) {  
return [xxx]  
}  
这样调用  
v1, v2, … := \<func_name\>([param1, …]) // 因为是匿名的返回值，用:=接收  
也可以使用有名称的返回值方法  
func \<func_name\>([param1 \<type\>, …]) (name1 \<type\>, …) {  
name1 = ….  
return  
}  
这样调用  
v1, v2 = \<func_name\>([param1, …])  
注意  
函数名大写开头表示函数对外暴露，否则只能自己调用

**数组**  
定义固定长度数组  
var name \<[len]\>\<type\>  
便可以开始类似的遍历：  
for i := 0; i \< len(target); i++ {  
target[i]  
}  
或者  
for index, value := range target {  
// 类似于foreach，但这里每个元素和下标给了  
}  
赋了初值的数组  
v := \<[len]\>\<type\>{xxx, xxx, xxx, …} // 剩下没有的都会被赋初值  
方法要固定长度数组必须func name(arr_name [len]type)，好逆天，还要注意这是值传递，会拷贝一份
 
定义动态数组  
v := []\<type\>{xxx, xxx, xxx} // 动态数组，切片  
也可以这样定义  
v := make([]\<type\>, len, capacity)  
数组该怎么用它就怎么用，方法要动态数组时可以  
func func_name(name []\<type\>) // 还是值传递，值传递的是指针，神金
