# 基础

## 变量声明

声明一个变量(可以声明全局):

```go
var name <type> // 默认值为 0
```

声明并赋值(可以声明全局):

```go
var name <type> = <value>
```

初始化的时候省去数据类型,通过值自动匹配当前变量的数据类型(可以声明全局):

```go
var <name> = <value>
```

省去 var 直接自动匹配(不能声明全局):

```go
<name> := <value>
```

多变量声明:

```go
var v1, v2 [type(全部变量类型一样)] = value1, value2
```

也或者:

```go
var (
    v1 [type] = value1
    v2 [type] = value2
)
```

查看数据类型,可以使用 `fmt.Printf("%T", v)`。

## 常量

常量定义:

```go
const <name> <type> = <value>
```

可以定义枚举:

```go
const (
    BEIJIN  = iota // iota 表示自增,赋值 0 后面每个 +1,每个枚举也可以单独赋值
    SHANGHAI
    SHENZHEN
)
```

也可以:

```go
const (
    BEIJIN  = 10 * iota // 0
    SHANGHAI            // 10
    SHENZHEN            // 20
)
```

比如:

```go
const (
    a, b = iota + 1, iota + 2 // 1, 2
    c, d                      // 2, 3
    e, f                      // 3, 4
    g, h = iota * 2, iota * 3 // 6, 9
    i, k                      // 8, 12
)
```

## 基本数据类型

### 整型

- `(u)int8`、`(u)int16`、`(u)int32`、`(u)int64`
- 其它数字类型:`uint(uint32/uint64)`、`int(int32、int64)`、`uintptr`(用于存指针)
- 可以使用 `len()` 来获取不同平台的长度变化

### 浮点型

- `float32`、`float64`
- 可以使用 `math.MaxFloat32` 等等获得最大范围

### 布尔值

- `bool`

### 字符串

- 内部使用 UTF-8 编码,以原生类型出现
- 使用多行字符串可以使用反引号

## 字符串的常用函数

| 函数 | 说明 |
| --- | --- |
| `len(str)` | 求长度 |
| `+` 或 `fmt.Sprintf` | 拼接字符串 |
| `strings.Split` | 分割 |
| `strings.Contains` | 是否包含子串 |
| `strings.HasPrefix/HasSuffix` | 前/后缀判断 |

## if

可以一般使用:

```go
if 起始语句; 条件; 每次循环完毕语句 {}
```

if 可以增强使用,如:

```go
if 在条件判断前执行的语句; 条件 {}
```

可以用于 channel 的操作中,如:

```go
if data, ok := <-channel; ok {
    // channel 没有被关闭时
}
```

## switch 语句

```go
switch {
case 条件 1:
    xxx
case 条件 2:
    xxx
default:
}
// 注意 go 的 switch 不会穿透,要穿透就用 fallthrough
```

```go
switch v {
case 1:
    xxx
case 2, 3:
    xxx
default:
}
```

还可以使用表达式:

```go
switch {
case age > 20:
    xxx
case age > 10:
    xxx
default:
}
```

## 循环

```go
for [初始语句;] 循环条件 [; 单次循环结束语句] {}
```

前面后面都可以省略,比如无限循环:

```go
for {}
```

还有键值循环:

```go
for i := range 5 {}
for range 5 {}
```

## 函数

### 定义

```go
func <func_name>([param1 <type>, ...]) [return_type] | ([return_type1, type2, ...]) {
    return [xxx]
}
```

这样调用:

```go
v1, v2, ... := <func_name>([param1, ...]) // 因为是匿名的返回值,用 := 接收
```

也可以使用有名称的返回值方法:

```go
func <func_name>([param1 <type>, ...]) (name1 <type>, ...) {
    name1 = ...
    return
}
```

这样调用:

```go
v1, v2 = <func_name>([param1, ...])
```

> 注意:函数名大写开头表示函数对外暴露,否则只能自己调用。

## init 函数

> 要注意,同级目录的不同 go 文件里的方法可以互相调用。导入的包 `""` 是该项目下全路径名。

一般导包是:

```go
import (
    "xxx1"
    "xxx2"
)
```

我们可以起别名:

```go
import (
    _ "xxx"   // 匿名导包,无法使用包方法,但是会调用 init 方法
    xxx "xxx" // 差不多是给包起别名
    . "xxx"   // 把里面那个包全部方法可以在这里直接使用,不需要引用
)
```

## defer 关键字

将表达式优先压入方法栈,方法结束时出栈并执行,这东西是在 return 后面执行。

定义:

```go
defer 表达式
```

## 数组

定义固定长度数组:

```go
var name <[len]><type>
```

便可以开始类似的遍历:

```go
for i := 0; i < len(target); i++ {
    target[i]
}
```

或者:

```go
for index, value := range target {
    // 类似于 foreach,但这里每个元素和下标给了
}
```

赋了初值的数组:

```go
v := <[len]><type>{xxx, xxx, xxx, ...} // 剩下没有的都会被赋初值
```

> 方法要固定长度数组必须 `func name(arr_name [len]type)`,好逆天,还要注意这是值传递,会拷贝一份。

定义动态数组:

```go
v := []<type>{xxx, xxx, xxx} // 动态数组,切片
```

也可以这样定义:

```go
v := make([]<type>, len, capacity)
```

数组该怎么用它就怎么用,方法要动态数组时可以:

```go
func func_name(name []<type>) // 还是值传递,值传递的是指针,神金
```
