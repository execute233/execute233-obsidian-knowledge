下载源码（以linux为例）  
下载xxx.tar.gz  
tar zxvf xxx.tar.gz  
会有go文件夹  
编辑环境变量  
单一用户：~/.bash_profile  
所有用户：/etc/profile  
最后添加  
export GOROOT=go路径 # go源码包路径  
export GOPATH=xxx # go项目路径  
# 项目路径下是有bin pkg src三个文件夹，src里面的文件夹就是各个项目  
export PATH=$PATH:$GOROOT/bin$GOPATH/bin  
使环境变量生效  
source /etc/profile  
go run 对应go文件 # 编译并执行相应的go文件  
go build 对应go文件 # 编译对应的go文件为相应系统的可执行文件
