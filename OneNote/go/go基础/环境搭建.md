# 环境搭建

包管理见 [[go/go基础/Go Modules|Go Modules]];命令行参数解析见 [[go/go基础/库-flag|库-flag]]。

## 下载源码(以 Linux 为例)

1. 下载 `xxx.tar.gz`
2. `tar zxvf xxx.tar.gz`,会有 go 文件夹

## 编辑环境变量

- 单一用户:`~/.bash_profile`
- 所有用户:`/etc/profile`

最后添加:

```bash
export GOROOT=go路径         # go 源码包路径
export GOPATH=xxx            # go 项目路径
# 项目路径下是有 bin pkg src 三个文件夹,src 里面的文件夹就是各个项目
export PATH=$PATH:$GOROOT/bin$GOPATH/bin
```

使环境变量生效:

```bash
source /etc/profile
```

## 编译与执行

```bash
go run 对应go文件     # 编译并执行相应的 go 文件
go build 对应go文件   # 编译对应的 go 文件为相应系统的可执行文件
```

## 注意事项

> Go 语言的表达式最好不加分号。

导包可以:

```go
import "xxx"
```

或:

```go
import (
    "xxx"
    "xxx"
)
```
