**切片****silce(****记住这是指向数组的指针！！！****)**  
上面动态数组的声明就是切片  
v := []\<type\>{xxx, xxx, xxx} // 动态数组，切片  
声明切片，但是没有分配空间  
var name []\<type\> // 这东西相当于nil，还没开内存  
你要用它，还要手动开辟空间  
name = make([]\<type\>, len) // 初始值是0  
声明的同时分配空间  
name := make([]\<type\>, len)// 初始值也是0
 
傻逼使用  
name := make([]\<type\>, len, cap) // len是切片长度，cap是容量  
直接访问len外面的是非法的，可以通过下面方法来添加元素到len末尾  
v = append(v, element) // ps：真不如ArrayList，麻烦要死  
// 当len超过cap还会自动扩容到cap*2，抄ArrayList也抄不明白  
还可以类似于py的切片  
v1 = v2[l1: l2] // 左闭右开，包左不包右，没有step，其他一样，可以留空  
// 注意值没有复制，是改变了指针，当前变量某个元素改了另一个包含的话也会改  
可以开辟新切片v2，将v1里的值拷贝到v2  
copy(v1, v2)  
**map**  
第一种声明方式  
var name map[\<key_type\>]\<value_type\> // 你还是没内存，要自己申请  
make(map[\<key_type\>]\<value_type\>, len)  
// 赋值类似于py  
name[xxx] = xxx  
第二种声明方式  
name := make(map[\<key_type\>]\<value_type\>, len) // 上面的结合体  
第三种类似于py直接写里面的内容  
name := map[\<key_type\>]\<value_type\> {  
key: value,  
…  
}  
遍历可以  
for key,value := range name {  
…  
}  
删除指定元素  
delete(name, key)  
修改跟赋值一样  
传参要  
func func_name(name map[key_type]value_type) // 这里是引用传递  
**面向对象**  
声明一种数据类型  
type name 表达式 // 声明新的数据类型（typedef）  
声明结构体  
type name struct {  
type name  
…  
}  
也可以把name省略，使之成为匿名字段，通过类型访问（必须唯一）  
使用  
var name type  
name.xxx = xxx  
或者  
person = Person{} // 可以继续写里面的内容来初始化  
给函数使用，类似于c语言，最好写指针  
func func_name(name *struct_type)  
name.xxx = xxx  
还可以new一个结构体得到指针出来，如new(Person)  
也可以玩匿名结构体，如  
var p = struct {  
name string  
age int  
}  
**函数面向对象**  
函数要绑定结构体，要这样写，类似于py  
func (t type_name) func_name() { // t是变量名，type_name还是值传递  
t.xxx // t类似于java的this}  
写入结构体要指针  
func (t *type_name) func_name() { // t是变量名，type_name还是值传递  
t.xxx // t类似于java的this  
}  
作用于对象和指针是不同的，前者是复制，后者是可以直接修改  
定义对象  
name := struct_type(属性键值对, …)  
或  
name := struct_type((顺序同属性定义一样)…)  
**继承**  
结构体继承，直接属性写其他结构体就行了，不要名字  
name := { 继承类名{继承字段赋值} ,其他属性…}  
也可以匿名嵌套实现继承，如  
type Dog struct {  
Feet int8  
*Animal  
}  
**多态**  
定义  
type name interface { // 这个相当于定义指针  
func_name() [return_type]  
…  
}  
后面就可以定义该接口实现方法，其他结构体实现该结构等同于实现方法多态  
没有显式指定结构体实现接口，如果结构体有该接口的所有方法那么就是实现了  
多态赋值的话要这样  
var name interface_name  
name = &obj_name  
也可以  
name = &实现此接口的类{初始化字段} // 直接创建对象拿到其接口  
函数使用不需要加*，接口本身就是指针  
func func_name(name interface_type)  
接口还可以组合，类似于结构体的继承差不多  
**断言****/****万能类型**  
在go语言中，所有的数据类型都实现了interface{}类型，直接类比于py的Any得了  
可以使用断言功能判断是哪种类型，类似于instanceof  
value, ok = name.(\<type_name\>) // 判断某个变量是否属于某个类型  
// 这里ok表示断言是否成功，value为强转后类型  
**Error****接口****/****错误处理**  
一般使用error接口来表示错误类型  
type error interface {  
Error() string  
}  
可以自定义error，最简单的方式是使用errors 包提供的New函数创建一个错误  
func New(text string) error  
需要传入格式化描述信息时，可使用fmt.Errorf  
fmt.Errorf("查询数据库失败，err:%w", err)  
对于二次包装的错误，errors包提供了以下方法  
func Unwrap(err error) error // 获得err包含下一层错误  
func Is(err, target error) bool // 判断err是否包含target  
func As(err error, target interface{}) bool // 判断err是否为target类型  
还可以自定义结构体类型实现error接口  
type OpError struct {  
Op string  
}  
func (e *OpError) Error() string {  
return fmt.Sprintf("无权执行%s操作", e.Op)  
}  
**反射****-****变量基础**  
变量由type与value构成，而type又有static type(int、string…)和concrete type构成  
在多态过程中一个对象赋值给其他东西，type不会变的，value还是原来的对象  
比如：  
定义了Book结构体，Writer, Reader接口，Book实现了Writer,Reader接口的方法  
b := &Book{} // b: pair\<type:Book, value:book{}地址\>  
var r Reader // r: pair\<type: , value: \>  
r = b // r: pair\<type:Book, value:book{}地址\>  
var w Writer // w: pair\<type: , value\>  
w = r.(Writer) // 此处的断言成功，因为w、r具有相同的type  
**反射****-****使用**  
go里面有reflect包，使用其中一些有用的方法  
ValueOf(i interface{}) Value // 获取输入数据的值，为空返回0  
TypeOf(i interface{}) Type // 获取输入的值的类型，为空返回nil  
Type对象也有相应的方法  
numField() int // 获取当前类型字段数  
Field(i int) Field // 获取第i个属性  
Method(i int) Method // 获取第i个方法  
Field对象也有对应的方法  
Interface() // 获取当前字段的值  
Method对象也有对应的一些属性  
Name // 方法名  
Type // 方法类型  
要注意，获取的方法只认值传递的那个(this type)而不是(this *type)  
Value类型提供了各种方法，将值以指定形式返回  
要注意Value是对象的一个副本，还需调用Elem()来得到原本的对象以修改值,比如  
func change(a interface{}) {  
// 这里传入指针，如果是普通对象就是副本了  
fmt.Println(reflect.ValueOf(a).Type())  
// 通过指针用Elem拿到原始对象  
reflect.ValueOf(a).Elem().FieldByName("Age").SetInt(20)  
}
