# 路由

可以创建路由组来控制：

```go
// 定义路由组
apiGroup := r.Group("api")
UserGroup(apiGroup)

// 写一个方法，然后就可以在这个组下面写路由
func UserGroup(r *gin.RouterGroup) {
    r.GET("/users", func(c *gin.Context) {})
    r.POST("/users", func(c *gin.Context) {})
    r.DELETE("/users", func(c *gin.Context) {})
    r.PUT("/users", func(c *gin.Context) {})
}
```
