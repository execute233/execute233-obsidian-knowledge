# 请求

路由定义见 [[go/gin/路由]];请求参数绑定见 [[go/gin/bind绑定器]];HTTP 协议见 [[computer/计算机网络/HTTP协议]];底层基于 [[go/go基础/库-net-http]]。

## 查询参数

即拼接在 URL 后面的参数，使用 gin context：

```go
value := c.Query("key")
```

如果没有传递参数，可以指定默认值：

```go
value := c.DefaultQuery("value", "default_value")
```

指定了多个名称相同的 key，可以使用数组接收：

```go
value := c.QueryArray("keys")
```

## 动态 / 路径参数

URL 里的某个地方是动态的，在路由的 path 是 `"users/:id"`，指定了动态参数。可以这样来获取动态参数：

```go
userId := c.Param("id")
```

也可以写多个动态参数，如 `"users/:id/:name"`：

```go
userId := c.Param("id")
userName := c.Param("name")
```

## 表单参数

```go
// 拿到表单的指定字段
value := c.PostForm("key")

// 也一样，但是可以判断表单有没有传这个字段
value, ok := c.GetPostForm("key")

// 也可以拿到表单上传的文件
file, err := c.FormFile("file")

// 也可以接收多个 key 多个文件（也可能单个 key 上传多个文件）上传
form, err := c.MultipartForm()
for key, header := range form.File {
    fmt.Println(key, header)
}

// 对于上传的文件，gin context 有更便捷的操作
c.SaveUploadedFile(fileHeader, "./file.png")
```

## 原始内容

gin 的 context 对象就是对 go 库中 http 的封装，我们可以直接读取原始内容：

```go
// 注意 body 读取之后就没了，阅后即焚
bytesData, err := io.ReadAll(c.Request.Body)

// Body 是个 readCloser 接口，可以再次赋值让 Body 再次可用
c.Request.Body = io.NopCloser(bytes.NewReader(bytesData))
```
