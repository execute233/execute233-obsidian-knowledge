**查询参数**  
即拼接在URL后面的参数，使用gin cotext  
value := c.Query("key")  
如果没有传递参数，可以指定默认值  
value := c.DefaultQuery("value", "default_value")  
指定了多个名称相同的key，可以使用数组接收  
value := c.QueryArray("keys")  
**动态****/****路径参数**  
URL里的某个地方是动态的，在路由的path是"users/:id"，指定了动态参数  
可以这样来获取动态参数  
userId := c.Param("id")  
也可以写多个动态参数,如"users/:id/:name"  
userId := c.Param("id")  
userName := c.Param("name")

**原始内容**  
gin的context对象就是对go库中http的封装，我们可以直接读取原始内容  
// 注意body读取之后就没了，阅后即焚  
bytesData, err := io.ReadAll(c.Request.Body)  
// Body是个readCloser接口，可以再次赋值让Body再次可用  
c.Request.Body = io.NopCloser(bytes.NewReader(bytesData))
