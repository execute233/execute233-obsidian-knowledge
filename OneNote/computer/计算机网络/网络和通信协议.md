# 网络和通信协议

## OSI 七层网络模型

七层模型是一个网络框架，通过将通信系统划分为七个不同的层次，简化网络设计和实施。每层都有其特定的功能，独立于其他层，但协同工作以确保数据通信的完整性和效率。

传输层（第 4 层）的两大协议 [[computer/计算机网络/TCP连接]] 与 [[computer/计算机网络/UDP协议]] 分别面向连接与无连接场景。应用层（第 7 层）的 [[computer/计算机网络/HTTP协议]] 是 Web 的事实标准。

### 1. 应用层（Application Layer）

- **功能**：直接与最终用户交互，为应用程序提供网络服务。
- **常见协议**：HTTP、FTP、SMTP、SNMP、DNS、Telnet。

### 2. 表示层（Presentation Layer）

- **功能**：数据格式化、转换和数据加密，确保数据能被应用层正确读取和理解。
- **常见功能**：数据压缩、加密与解密、数据格式转换。

### 3. 会话层（Session Layer）

- **功能**：负责建立、管理和终止会话（通信连接）。
- **常见功能**：会话管理、全双工、半双工和单工操作模式、会话检查点和恢复功能。

### 4. 传输层（Transport Layer）

- **功能**：提供端到端的通信控制，确保数据可靠传输。
- **常见协议**：TCP、UDP。
- **常见功能**：流量控制、错误检测与纠正、数据重传。

### 5. 网络层（Network Layer）

- **功能**：负责路由和转发数据包，处理逻辑地址（如 IP 地址）。
- **常见协议**：IP、ICMP、ARP、RARP。
- **常见设备**：路由器。

### 6. 数据链路层（Data Link Layer）

- **功能**：提供节点到节点间的传输，处理物理寻址（MAC 地址）、错误检测和纠正。
- **常见协议**：Ethernet、PPP、HDLC。
- **常见设备**：交换机、网桥。

### 7. 物理层（Physical Layer）

- **功能**：定义了物理设备的电气和物理规范，如线缆类型、连接器、频率等。
- **常见标准**：RJ45、Ethernet、光纤标准。
