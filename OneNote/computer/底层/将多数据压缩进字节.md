# 将多数据压缩进字节

通常 CPU 是直接操作一个 WORD，而不能对某个位进行操作，可以定义以下操作来完成。

## 单个字节存储多个 Bool

### set（uint8_t word, uint8_t n）：设置指定位为指定值

![[_assets/将多数据压缩进字节/将多数据压缩进字节__09-17-28-0.png]]

```cpp
*word = *word | (1u << n);
```

### set（uint8_t word, uint8_t n）：将指定的位置为 0

![[_assets/将多数据压缩进字节/将多数据压缩进字节__09-17-29-1.png]]

```cpp
*word = *word & ~(1u << n);
```

### toggle（uint8_t word, uint8_t n）：将指定的位取反

![[_assets/将多数据压缩进字节/将多数据压缩进字节__09-17-35-2.png]]

```cpp
*word = *word ^ (1u << n);
```

### read（uint8_t word, uint8_t n）：读取指定位

![[_assets/将多数据压缩进字节/将多数据压缩进字节__09-17-36-3.png]]

```cpp
return (*word & (1u << n));
```
