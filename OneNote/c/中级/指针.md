# 指针

## 指针的创建与使用

指针是保存变量地址的变量，如：

```c
int a = 10;
int * p = &a; // 指针类型需要与变量相同，要加*符号，这里&是取地址操作
printf("%p", p); // 地址使用%p表示
printf("内存%p上存储的值为: %d", p, *p); // *号来获取对应地址的值
*p = 666; // 也可以修改指针对应的值
```

要初始化指针不赋值时，使用 `NULL`：

```c
int *p = NULL;
```

对于方法参数，可接受指针，如：

```c
void swap(int * a, int * b) {
    int tmp = *a;
    *a = *b;
    *b = tmp;
}
int main() {
    int a = 10, b = 20;
    swap(&a, &b);
}
```

也可以作为返回值：

```c
int * test(int a) { ... } // 注意不能返回局部变量的地址，函数调用完毕后局部变量会被销毁
```

## 指针与数组

数组在内存中是一块连续的空间，声明数组后其位置和大小就固定了，其数据可以用数组表示法和指针表示法获取的读取，于是可以：

```c
char str[] = "Hello World!";
char * p = str;
printf("%c", *p); // 输出结果为 H
printf("%c", p[0]); // 同上
printf("%c", *(p + 1)); // 这里表示指针向后移动1单位相应数据类型长度，输出结果为 e
```

以下两种写法是等价的：

```c
*(p + i) 和 str[i]
```

于是下面各个表达式的含义也不难理解：

```c
char str[] = "xxx";
char * p = str;
```

| 表达式 | 含义 |
|---|---|
| `*p` | 数组的第一个元素 |
| `p` | 数组的第一个元素的地址 |
| `p == str` | 肯定为真，都是数组首元素地址 |
| `*str` | `str` 就是首元素的地址，于是就代表第一个元素 |
| `&str[0]` | 首元素的地址 |
| `*(p + 1)` | 第二个元素 |
| `p + 1` | 第二个元素的内存地址 |
| `*p + 1` | 注意 `*` 的优先级要比 `+` 高，这是首元素的值加 1 |

对于二维数组，也是连续一段内存存储的，也可以使用指针访问，如：

```c
int arr[2][3] = {{1, 2, 3}, {4, 5, 6}};
int * p = arr[0]; // 因为是二维数组，要指向第一个元素，降一个维度才能给到正确的指针
// 同理如果是 arr[1] 则是指向二维数组中的第二个数组的首元素
printf("%d = %d", *(p + 4), arr[1][1]); // 这两种访问形式都是一样的
```

## 多级指针

还可以创建指向指针的指针，甚至可以无限套娃下去，如：

```c
int a = 20;
int * p = &a;    // 普通指针
int ** pp = &p;  // 二级指针
int *** ppp = &pp; // 三级指针
printf("%d", ***ppp); // 多少级指针就用多少个*来获得存储的值
```

## 指针数组与数组指针

指针数组是存储指针变量的数组，如：

```c
int a, b, c;
int * arr[3] = {&a, &b, &c};
*arr[0] = 999; // []优先级高，先通过[0]取出地址，然后再用*赋值到对应的地址上
printf("%d", a);
printf("%d", **arr); // 也可以用二级指针
```

数组指针的目标是整个数组，它是指向整个数组的指针，如：

```c
int arr[3] = {111, 222, 333};
int (*p)[3] = &arr; // 本质上还是数组，里面每个元素都是指针
printf("%d, %d, %d", *(*p + 0), *(p + 1), *(p + 2));
// 此时 p 代表整个数组的地址，*p 代表指向数组中首个元素的地址
// *p + i 指向数组中第 i 个（0 开始）元素的地址，*(*p + i) 就是取对应地址上的值
```

## 函数指针

一个指向函数的指针，如：

```c
int sum(int a, int b) { return a + b; }
int main() {
    int (*p)(int, int) = sum; // 拿到函数地址
    int result = p(1, 2); // 使用方法和函数差不多
}
```

也可以让函数指针作为参数传入：

```c
int sum(int (*p)(int, int), int a, int b) {
    return p(a, b);
}
int sumImpl(int a, int b) {
    return a + b;
}
int main() {
    int (*p)(int, int) = sumImpl;
    int result = sum(p, 10, 20);
}
```

## void 指针

`void` 指针表示 "无类型指针"，它可以指向任何类型的数据，即任何类型的指针都可以直接赋值给 `void` 指针，无需强制类型转换。
