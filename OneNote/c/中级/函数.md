# 函数

## 函数的创建

函数声明在文件上面，函数体在下面，如：

```c
#include <studio.h>
void test(int, int);
int main() {
    ...
}
void test(int a, int b) { ... }
```

也可以在上面直接声明函数，如：

```c
#include <studio.h>
void test(int a, int b) { ... }
int main() {
    ...
}
```
