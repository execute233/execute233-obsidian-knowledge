# math.h

### double sqrt(double _x)

求平方根。

### double pow(double _x, double _y)

求 `_x` 的 `_y` 次方。

### double tan(double _x)

求 `tan` 值（`_x` 为弧度制）。

类似的还有 `sin()`、`cos()`。

### double ceil(double _x)

向上取整。

### double floor(double _x)

向下取整。

### int abs(int _x)

取绝对值。

类似的还有 `double fabs(double _x)` 等适应不同类型。
