# 基本数据类型

## 变量

跟 java 类似

基本数据类型的占用空间详见 [[c/基本/变量]] 中的运算符部分;`typedef` 给类型起别名时常用 [[c/高级/结构体，联合体和枚举]]。

## typedef 关键字

一般在上面顶层使用该关键字,作用就是给类型取个别名,如

```c
#include <stdio.h>

typedef const char * String;

int main() {
    String str = "Hello World!"; // 简化了前面的类型
    const char * str = "Hello World!"; // 同上等价
    printf(str);
}
```

也可以在结构体上使用,如

```c
typedef struct Stu {
    int id;
    int age;
    char name[10];
} Student;

int main() {
    Student s = {1, 18, "xxx"};
}
```

## 各类型占用空间

各种基本类型的占用空间及表示(跨平台就是个笑话😅):

| 数据类型 | 32位字节数 | 64位字节数 | 取值范围 |
|---|---|---|---|
| `char` | 1 | 1 | -2⁷ ~ 2⁷ - 1 |
| `short` | 2 | 2 | -2¹⁵ ~ 2¹⁵ - 1 |
| `int` | 4 | 4 | -2³¹ ~ 2³¹ - 1 |
| `long` | 4 | 8 | 32位: -2³¹ ~ 2³¹ - 1<br>64位: -2⁶³ ~ 2⁶³ - 1 |
| `long long` | 8 | 8 | -2⁶³ ~ 2⁶³ - 1 |
| `float` | 4 | 4 | 6~7位有效数字 |
| `double` | 8 | 8 | 15~16位有效数字 |
| `long double` | 8/12/16😅 | 8/12/16😅 | 😅 |
| 指针 | 4 | 8 | 2³² 或 2⁶⁴ |
