一般在上面顶层使用该关键字，作用就是给类型取个别名，如  
#include \<stdui.h\>  
typedef const char * String;  
int main() {  
String str = "Hello World!"; // 简化了前面的类型  
const char * str = "Hello World!"; // 同上等价  
printf(str);  
}  
也可以在结构体上使用，如  
typedef struct Stu {  
int id;  
int age;
