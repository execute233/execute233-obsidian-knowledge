# 字符串

字符串底层是字符数组,基础见 [[c/基本/数组]] 与 [[c/基本/基础知识]]。字符串相关函数见 [[c/系统库/string.h]],字符串 IO 见 [[c/系统库/stdio.h]]。

## 字符串的声明

```c
char str[] = {'H', 'e', 'l', 'l', 'o', '\0'};
char str[] = "Hello";
```

## 控制台输入输出

## 接受输入输出

```c
scanf("%s", str);       // 将输入结果按照格式分配给后续的变量
scanf("%d", &a);        // 接受数字输入
```

也可以用字符串专有函数

```c
gets(str);              // 接受字符串输入
puts(str);              // 打印字符串到控制台
```

专门处理单个字符

```c
getChar();              // 获取一个字符
```
