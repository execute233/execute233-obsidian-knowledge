# 数组

## 数组的创建与使用

```c
// 注: 未指定初始值的数是内容地址中的一块,内容是什么完全随机的
```

数组的创建方式如下

```c
类型 数组名称[数组大小] = {数据1, 数据2, …};
```

可以创建默认的数组,如

```c
int arr[10];
```

指定下标的数组

```c
int arr[10] = {[4] = 777, [9] = 666};
```

也可以根据赋值确定数组长度

```c
int arr[] = {1, 2, 3};
```

## 多维数组

同上面差不多,如

```c
int arr[3][2] = {{3, 4}, {5, 2}, {1, 4}};
```
