# 结构体，联合体和枚举

结构体的使用常涉及 [[c/中级/指针]];typedef 别名见 [[c/基本/基本数据类型]];结构体作为函数参数传入见 [[c/中级/函数]]。

## 结构体

将多种数据类型集结到一起，形成一个整体，如：

```c
struct Student {
    int id;
    int age;
    char * name;
};
int main() {
    struct Student stu = {1, 18, "xxx"}; // 创建个结构体
    // 指定某个数据也可以这样写
    // struct Student stu = {.id = 1, .age = 18, .name = "xxx"};

    int a = stu.age; // 取出结构体中的数据
}
```

### 内存对齐

结构体所占空间由最大占位的元素决定，如上面的 `Student`，由于 `int` 占 4 byte 且最大，则此结构体占 12 byte。

比如 `{char name[10], short age, double money}`，则每个变量的地址（伪地址）为：

- `name`：0000
- `age`：0010（刚好 10 能被 2 整除）
- `money`：0016（`double` 要求索引地址能被大小整除）

## 结构体数组

以上面的 `Student` 为例，结构体数组创建方式如下：

```c
struct Student arr[] = {{1, 18, "xxx"}, {2, 17, "xxx"}, {3, 20, "xxx"}};
arr[i].age; // 拿到指定索引的结构体的数据 age
```

## 结构体指针

结构体也可以有指针，如：

```c
struct Student stu = {1, 18, "xxx"};
struct Student * p = &stu; // 获得指针的方式同样
printf("%s", (*p).name); // 由于 . 运算符优先级更高，先 (*p) 获得值再访问其数据
printf("%d", p->age);    // 上面语句的简化
```

## 函数中结构体的使用

同 `int` 一样，结构体作为传入参数是值传递，相当于改局部变量：

```c
void test(struct Student stu) { stu.age = 19; }       // 这样的修改是无效的！
void test(struct Student * stu) { stu->age = 19; }    // 这样的修改才有效！
```

## 联合体

与结构体用法相似，但是联合体用的是同一个内容空间，联合体定义如：

```c
union Object {
    int a;
    char b;
    float c;
}; // 联合体占用空间由里面占用最多空间的类型决定，修改里面一个内容就不用其它的
```

## 枚举

用于表示预设好的整数常量。假设用枚举表示风扇的档位，如：

```c
enum Status {low = 1, middle = 2, high = 3}; // 也可以不定义枚举值，默认第一个为 0，后续依次 +1
int main() {
    enum Status s = middle;
    printf("%d", s); // 结果为 2
}
```
