# 预处理

预处理是编译流程的第一阶段,详见 [[c/编译,构建,调试/c语言的编译]]。`#define` 宏函数与 [[c/中级/函数]] 配合使用。

## 文件包含

使用 `#include` 指令把其他文件里面的东西复制粘贴过来。

使用方式如下：

```c
#include <文件名称>  // 引用的是编译器里库路径的头文件
#include "文件名称"  // 引用的是程序目录相对路径中的头文件，没有再去库里找
```

## 宏定义

`#define` 的作用与 `#include` 相似，它会将内容在编译阶段全部替换。

使用 `#define` 定义宏，规则如下：

```c
#define 宏名(记号) 内容
```

也可以用参数，如：

```c
#define MUL(x) x * x
int main() {
    printf("%d", MUL(9)); // 结果为 81
}
```

也可以替换为函数，如：

```c
#define bb(i) printf("%d", "I have been replaced to #i");
```

也可以取消定义：

```c
#undef 宏名
```

## 系统中预定义的宏

| 宏 | 含义 |
|---|---|
| `__DATE__` | 当前日期，类似于 `Jun 27 2023` 的字符串 |
| `__TIME__` | 当前时间，类似于 `10:00:00` 的字符串 |
| `__FILE__` | 当前源代码文件的名称（含路径）的字符串 |
| `__LINE__` | 当前的行号，整数 |
| `__FUNCTION__` | 当前正在访问的函数名 |

## 条件编译

```c
#ifdef PI // 判断是否定义了符号 PI，有处理下面的指令
#define M 666
#else // 如果没定义 PI，就处理这个分支的语句
#define M 777
#endif // 最后 endif 指令结束整个判断
```

也可以判断某个预定义的值，以及 if 多分支，如：

```c
#if M == 666
#define K 999
#elif M == 777
...
#else
...
#endif
```

## 编译器操作

```c
#program 设定编译器作态或者指示编译器完成一些特定的动作
#error 停止编译并输出自定义错误信息
```

## #pragma

用于指定计算机或操作系统特定的编译器功能，注意这对于每个编译器都有所不同。

### #pragma once

指定该文件在编译时只打开一次，等同于 7. 宏定义防止重复的解决方式。

### #pragma message(messageStr)

在编译时显示信息。

## 有用的预处理语句

我们可能会遇到重复包含同一个头文件的冲突，可以在头文件使用：

```c
#ifndef _头文件名(大写)_H_
#define _头文件名(大写)_H_
... // 所有的语句都要放在这里
#endif
```
