# 高级树 其它树

## 线索化二叉树

实际上我们发现，一棵二叉树的某些结点会存在 NULL 的情况，我们可以利用这些为 NULL 的指针，将其线索化为某一种顺序遍历的指向下一个按顺序的结点的指针，这样遍历就会很方便了。

可以将其线索化，首先按前序查找：

线索化的规则为：

- 节点左指针，指向当前遍历的前驱节点
- 节点右指针，指向当前遍历的后继节点

线索化后：

![Exported image](_assets/%E9%AB%98%E7%BA%A7%E6%A0%91%20%E5%85%B6%E5%AE%83%E6%A0%91/%E9%AB%98%E7%BA%A7%E6%A0%91%20%E5%85%B6%E5%AE%83%E6%A0%91__11-44-07-2.png)

但是现在有一个问题，我们怎么知道，某个结点的指针到底是指向的其左右孩子，还是说某种遍历顺序下的前驱或是后继结点呢？所以，我们还需要分别为左右添加一个标志位，来表示左右指针到底指向的是孩子还是遍历线索。

整个二叉树完成线索化后：

![Exported image](_assets/%E9%AB%98%E7%BA%A7%E6%A0%91%20%E5%85%B6%E5%AE%83%E6%A0%91/%E9%AB%98%E7%BA%A7%E6%A0%91%20%E5%85%B6%E5%AE%83%E6%A0%91__11-44-08-3.png)

以下是前序遍历线索化的实现：

```c
Node pre = NULL; // 需要一个指针来保存后续节点的指向
// 线索化过程只要正常遍历即可，不过要注意存在空指针的节点
void preOrderThreaded(Node root) {
    if (root == NULL) return;
    // ---------- 线索化 ----------
    if (root->left == NULL) { // 判断左节点是否为 NULL，如果是则指向上一个节点
        root->left = pre;
        root->leftTag = 1;
    }
    if (pre != NULL && pre->right == NULL) { // 判断上一个节点右边是否为 NULL，如果是就线索化指向当前节点
        pre->right = root;
        pre->rightTag = 1;
    }
    pre = root; // 每遍历完一个就要更新上一个节点
    // ---------- 线索化结束 ----------
    if (root->leftTag == 0) preOrderThreaded(root->left); // 注意只有标志为 0 才可以继续向下，不然就是线索了
    if (root->rightTag == 0) preOrderThreaded(root->right);
}
void quickPreOrderPrint(Node root) {
    while (root != NULL) {
        printf("%c, ", root->element);
        if (root->leftTag == 0) {
            root = root->left; // 如果是左孩子，走左边
        } else {
            root = root->right; // 如果左边不是孩子，而是线索，那就走右边，无论是线索还是孩子，都得往右边走
        }
    }
}
```

### 中序遍历线索化二叉树

线索化后：

![Exported image](_assets/%E9%AB%98%E7%BA%A7%E6%A0%91%20%E5%85%B6%E5%AE%83%E6%A0%91/%E9%AB%98%E7%BA%A7%E6%A0%91%20%E5%85%B6%E5%AE%83%E6%A0%91__11-44-10-4.png)

中序线索化后与前序只是线索化的顺序不同，它被安排在了中间：

```c
void inOrderThreaded(Node root) {
    if (root == NULL) return;
    if (root->leftTag == 0) inOrderThreaded(root->left);
    // ---------- 线索化 ----------，放中间去，其他还是一样的
    if (root->left == NULL) { // 判断左节点是否为 NULL，如果是则指向上一个节点
        root->left = pre;
        root->leftTag = 1;
    }
    if (pre != NULL && pre->right == NULL) { // 判断上一个节点右边是否为 NULL，如果是就线索化指向当前节点
        pre->right = root;
        pre->rightTag = 1;
    }
    pre = root; // 每遍历完一个就要更新上一个节点
    // ---------- 线索化结束 ----------
    if (root->rightTag == 0) inOrderThreaded(root->right);
}
void quickInOrderPrint(Node root) {
    while (root != NULL) { // 中序遍历要先完成左边，所以要走到最左边先
        while (root != NULL && root->leftTag == 0) { // 如果左边一直不是线索，就一直找
            root = root->left;
        }
        // 一般是到最左边节点时 leftTag 为 1 跳出了上面那个循环
        printf("%c, ", root->element); // 到了最左边再打印，中序开始
        while (root != NULL && root->rightTag == 1) { // 打印完就该右边了，右边如果是线索化之后的结果，那就是下一个节点
            root = root->right;
            printf("%c, ", root->element);
        }
        root = root->right;
    }
}
```

### 后序遍历线索化二叉树

线索化后：

![Exported image](_assets/%E9%AB%98%E7%BA%A7%E6%A0%91%20%E5%85%B6%E5%AE%83%E6%A0%91/%E9%AB%98%E7%BA%A7%E6%A0%91%20%E5%85%B6%E5%AE%83%E6%A0%91__11-44-11-5.png)

我们会发现 B 无法找到其兄弟结点 C，所以说这样是行不通的，因此要完成后续遍历，我们只能对结点进行改造 —— 添加一个父节点的指针：

```c
void postOrderThreaded(Node root) {
    if (root == NULL) return;
    if (root->leftTag == 0) { // 注意只有标志为 0 才可以继续向下，不然就是线索了
        postOrderThreaded(root->left);
        if (root->left != NULL) root->left->parent = root; // 左边完事后，如果不为空，那么设定父子关系
    }
    if (root->rightTag == 0) {
        postOrderThreaded(root->right);
        if (root->right) root->right->parent = root; // 右边完事后，如果不为空，设置父子关系
    }
    // ---------- 线索化 ----------，放后面去，其他还是一样的
    if (root->left == NULL) { // 判断左节点是否为 NULL，如果是则指向上一个节点
        root->left = pre;
        root->leftTag = 1;
    }
    if (pre != NULL && pre->right == NULL) { // 判断上一个节点右边是否为 NULL，如果是就线索化指向当前节点
        pre->right = root;
        pre->rightTag = 1;
    }
    pre = root; // 每遍历完一个就要更新上一个节点
    // ---------- 线索化结束 ----------
}
void quickPostOrderPrint(Node root) {
    Node last = NULL, node = root; // 需要两个暂存指针，一个记录上一次遍历的节点，还有一个从 root 开始
    while (node != NULL) {
        while (node->left != last && node->leftTag == 0) { // 依然是从整棵树左边节点开始，和前面一样，但是防止无线循环
            node = node->left;
        }
        while (node != NULL && node->rightTag == 1) { // 左边完了还有右边，如果右边是线索那就一路向前，跟前面一样的
            printf("%c, ", node->element); // 沿途打印
            last = node;
            node = node->right;
        }
        if (node == root && node->right == last) {
            // 上面操作完成后，那么当前节点左右就结束了，此时就要去寻找其他兄弟节点了
            // 直接通过 parent 拿到兄弟节点，如果是根节点就要特殊处理了
            printf("%c, ", node->element);
            return;
        }
        while (node != NULL && node->right == last) { // 如果当前节点的右孩子就是上一个遍历的节点，就一路向前
            printf("%c, ", node->element); // 直接打印当前节点
            last = node;
            node = node->parent;
        }
        // 到这只有一种情况了，是从左子树上来的，那么当前节点的右边要么是线索要么是右子树，所以一路向右
        if (node != NULL && node->rightTag == 0) {
            node = node->right;
        }
    }
}
```

## 二叉查找树

具有一定的规则：

- 左子树的所有节点的值，均小于根节点的值
- 右子树的所有节点的值，均大于其根节点的值
- 二叉搜索树的子树也是二叉搜索树
