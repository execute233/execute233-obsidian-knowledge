**根节点**：最上方的节点，这里是A  
**度**：每个节点连接的子节点的树木（最大值），这里是3  
**子树**：每个节点延伸下去的下一个节点  
**节点的层次**：树的根节点为1，每下一层就+1,  
**树的深度**：整棵树中所有节点的最大层次
 
**子节点**：与当前结点直接向下相连的结点，比如B, C, D 都是A的子节点，反过来就是父节点  
**叶子结点**：某个节点没有任何子节点  
**兄弟节点**：两个节点的父亲都是同一个  
**祖先节点**：从根节点一直到某个节点的整条路径的所有节点，比如L的祖先节点就是A, B, E

**二叉树的性质**  
性质一：对于一棵二叉树，第 $i$ 层的最大节点数量为 $2^{i - 1}$  
性质二：对于一个深度为  
的二叉树，可具有的最大节点数量为

$n = 2^{0} + 2^{1} + 2^{2} + \ldots + 2^{k - 1} = 2^{k - 1} - 1$

性质三：假设一棵二叉树中度为0,1,2的节点数量分别为 $n_{0} ， n_{1} ， n_{2}$  
则节点总数 $n = n_{0} + n_{1} + n_{2}$  
边数之和 $E = \left(n - 1 = n\right)_{1} + 2 n_{2} &nbsp;$ 结合 $n = n_{0} + n_{1} + n_{2} = n_{1} + 2 n_{2} +$ 得  
性质四：一棵完全二叉树的节点数n满足

$2^{k - 1} - 1 < n < 2^{k} - 1$

只看左边，整理可得一棵具有n个节点的完全二叉树的深度为

$\left(k = \left[\right. l o g\right)_{2} ⁡ n \left]\right. + 1$

性质五：对于一个完全二叉树，对于任意一个节点i，节点的顺序为从上往下，从左往右

![Exported image](Exported%20image%2020260801222403-10.png)  

- 对于一个拥有左右孩子的节点来说，左孩子为2i，右孩子为2i+!
- 如果i=1，那么是二叉树的根节点；如果i\>1，那么父节点是[i/2]
- 如果2i\>n,则节点没有左孩子
- 如果2i+1\>n,则节点没有右孩子  
由n个节点可以构造出多少种不同的二叉树？  
假设只有一个节点或者没有节点，只有 $h \left(\right. 1 \left.\right) = h \left(\right. 0 \left.\right) = 1$ 种  
假设有两个节点，其中一个拿来做根节点，剩下一个要么左1右0，要么左0右1，即

$h \left(\right. 2 \left.\right) = h \left(\right. 1 \left.\right) \times h \left(\right. 0 \left.\right) + h \left(\right. 0 \left.\right) \times h \left(\right. 1 \left.\right) = 2$

假设有三个节点，其中一个做根节点，可以左2右0，左1右1，左0右2，即

$h \left(\right. 3 \left.\right) = h \left(\right. 2 \left.\right) \times h \left(\right. 0 \left.\right) + h \left(\right. 1 \left.\right) \times h \left(\right. 1 \left.\right) + h \left(\right. 0 \left.\right) \times h \left(\right. 2 \left.\right)$

假设有n个节点，那么可以左(n-1)右0, 左(n-2)右1, …, 左0右(n-2)
