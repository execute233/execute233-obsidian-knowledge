### 基本概念

- **根节点**：最上方的节点，这里是 A
- **度**：每个节点连接的子节点的数量（最大值），这里是 3
- **子树**：每个节点延伸下去的下一个节点
- **节点的层次**：树的根节点为 1，每下一层就 +1
- **树的深度**：整棵树中所有节点的最大层次
- **子节点**：与当前结点直接向下相连的结点，比如 B、C、D 都是 A 的子节点，反过来就是父节点
- **叶子结点**：某个节点没有任何子节点
- **兄弟节点**：两个节点的父亲都是同一个
- **祖先节点**：从根节点一直到某个节点的整条路径的所有节点，比如 L 的祖先节点就是 A、B、E

## 二叉树的性质

### 性质一

对于一棵二叉树，第 $i$ 层的最大节点数量为 $2^{i-1}$。

### 性质二

对于一个深度为 $k$ 的二叉树，可具有的最大节点数量为：

$$n = 2^0 + 2^1 + 2^2 + \ldots + 2^{k-1} = 2^k - 1$$

### 性质三

假设一棵二叉树中度为 0、1、2 的节点数量分别为 $n_0, n_1, n_2$，则节点总数：

$$n = n_0 + n_1 + n_2$$

边数之和 $E = n - 1 = n_1 + 2n_2$，结合 $n = n_0 + n_1 + n_2 = n_1 + 2n_2 + 1$ 得：

$$n_0 = n_2 + 1$$

### 性质四

一棵完全二叉树的节点数 $n$ 满足：

$$2^{k-1} - 1 < n < 2^k - 1$$

只看左边，整理可得一棵具有 $n$ 个节点的完全二叉树的深度为：

$$k = \lfloor \log_2 n \rfloor + 1$$

### 性质五

对于一个完全二叉树，对于任意一个节点 $i$，节点的顺序为从上往下，从左往右。

![Exported image](_assets/%E6%A0%91%20%E6%A3%AE%E6%9E%97%20%E4%BA%8C%E5%8F%89%E6%A0%91/%E6%A0%91%20%E6%A3%AE%E6%9E%97%20%E4%BA%8C%E5%8F%89%E6%A0%91__11-43-49-10.png)

- 对于一个拥有左右孩子的节点来说，左孩子为 $2i$，右孩子为 $2i+1$
- 如果 $i=1$，那么是二叉树的根节点；如果 $i>1$，那么父节点是 $\lfloor i/2 \rfloor$
- 如果 $2i > n$，则节点没有左孩子
- 如果 $2i+1 > n$，则节点没有右孩子

### 卡特兰数

由 $n$ 个节点可以构造出多少种不同的二叉树？

假设只有一个节点或者没有节点，只有 $h(1) = h(0) = 1$ 种。

假设有两个节点，其中一个拿来做根节点，剩下一个要么左 1 右 0，要么左 0 右 1，即：

$$h(2) = h(1) \times h(0) + h(0) \times h(1) = 2$$

假设有三个节点，其中一个做根节点，可以左 2 右 0、左 1 右 1、左 0 右 2，即：

$$h(3) = h(2) \times h(0) + h(1) \times h(1) + h(0) \times h(2)$$

假设有 $n$ 个节点，那么可以左 $(n-1)$ 右 0、左 $(n-2)$ 右 1、……、左 0 右 $(n-1)$。

可以使用动态规划来实现，例如：

```c
int main(){
    int size;
    scanf("%d", &size);     // 读取需要的 N
    int dp[size + 1];
    dp[0] = dp[1] = 1;      // 没有结点或是只有一个结点直接得到 1
    for (int i = 2; i <= size; ++i) {
        dp[i] = 0;          // 一开始先等于 0 再说
        for (int j = 0; j < i; ++j) {     // 内层循环是为了计算所有情况,比如 i 等于 3,那么就从 j = 0 开始,计算 dp[0] 和 dp[2] 的结果,再计算 dp[1] 和 dp[1]...
            dp[i] += dp[j] * dp[i - j - 1];
        }
    }
    printf("%d", dp[size]);     // 最后计算的结果就是 N 个结点构造的二叉树数量了
}
```

求出的结果序列为 1, 1, 2, 5, 14, 42, 132, ……

这也是**卡特兰数**，通项公式：

$$C_n = \frac{1}{n+1} C_{2n}^{n} = \frac{(2n)!}{n! \times (n+1)!}$$

## 二叉树的遍历

![Exported image](_assets/%E6%A0%91%20%E6%A3%AE%E6%9E%97%20%E4%BA%8C%E5%8F%89%E6%A0%91/%E6%A0%91%20%E6%A3%AE%E6%9E%97%20%E4%BA%8C%E5%8F%89%E6%A0%91__11-43-52-12.png)

### 前序遍历

走到哪里遍历到哪里，先走左边再走右边。

A -> B -> D -> E -> C -> F

```c
void preorderPrint(Node root) {
    printf(format"%c ", root->element);
    if (root->left != NULL) preorderPrint(root->left);
    if (root->right != NULL) preorderPrint(root->right);
}
```

### 中序遍历

先完成整个左子树的遍历，然后打印根节点，最后遍历整个右子树。

D -> B -> E -> A -> C -> F

```c
void inorderPrint(Node root) {
    if (root == NULL) return;
    inorderPrint(root->left);
    printf(format"%c ", root->element);
    inorderPrint(root->right);
}
```

### 后序遍历

等待左右子树都遍历完成，才会打印根节点。

D -> E -> B -> F -> C -> A

```c
void postorderPrint(Node root) {
    if (root == NULL) return;
    postorderPrint(root->left);
    postorderPrint(root->right);
    printf(format"%c ", root->element);
}
```

### 层序遍历

按照每一层遍历。

A -> B -> C -> D -> E -> F

使用队列将每一层存入。

```c
void levelOrderPrint(TreeNode root) {
    if (root == NULL) return;
    struct Queue queue;
    initQueue(&queue);
    offerQueue(&queue, root);
    while (!isEmpty(&queue)) {
        TreeNode node = pollQueue(&queue);
        printf(format"%c ", node->element);
        if (node->left) offerQueue(&queue, node->left);
        if (node->right) offerQueue(&queue, node->right);
    }
}
```
