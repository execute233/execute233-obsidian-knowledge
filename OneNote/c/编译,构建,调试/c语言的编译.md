以GCC为例,将源代码编译为可执行文件的过程如下

![Exported image](Exported%20image%2020260801222506-0.png)- 预处理（Pre-Processing）：首先会经过预处理器将程序中的预编译指令进行处理，然后把源文件中的注释这些没用的东西都给扬了。
- 编译（Compiling)：处理好之后，就可以正式开始编译，首先会编译为汇编代码。
- 汇编(Assembling)：接着就该将汇编代码编译为机器可以执行的二进制机器指令了，会得到一个二进制目标文件。
- 链接（Linking）：最后需要将这个二进制目标文件与系统库和其他库的OBJ文件、库文件链接起来，最终生成了可以在特定平台运行的可执行文件。
 
对于要编译到指定阶段文件，可使用命令  
gcc -E main.c -o main.i  
其中输出文件名后缀决定了编译到哪个阶段,-E表明输入.c源文件,-S表米输入是修改后源文件，-c表明输入是汇编代码  
使用gcc main.o -o main 将上述过程文件转为可执行exe文件  
对于多文件编译,需要写多个.c文件进行编译，如  
gcc main.c test.c -o main
