利用概率值进行分类  
一般使用贝叶斯公式

$P \left(C|W\right) = \frac{P \left(W|C\right) P \left(\right. C \left.\right)}{P \left(\right. w \left.\right)}$

P(C) 表示C出现的概率，一般是目标值  
P(W|C) 表示C条件下W出现的概率  
P(W) 表示W出现的概率  
原始贝叶斯是

$P \left(A B\right) = P \left(A\right) P \left(B|A\right) = P \left(B\right) P \left(\right. A \left|\right. B \left.\right)$

加入朴素后

$P \left(A B\right) = P \left(A\right) P \left(\right. B \left.\right)$

拉普拉斯平滑系数  
为了避免概率值为0，分子分母分别加上一个数值

$P \left(F_{1} , C\right) = \frac{N_{i} + 𝛼}{N + 𝛼 m}$

$𝛼$ 为拉普拉斯平滑系数，一般为1  
$N_{i}$ 是 $F_{1}$ 中符合条件C的样本数量  
N 是在条件C下所有样本的总数  
m 表示说有独立样本的总数  
代码示例  
import numpy as np  
import pandas as pd  
import matplotlib.pyplot as plt  
import jieba  
from sklearn.feature_extraction.text import CountVectorizer # 词频统计包，把评论内容转为词频矩阵  
from sklearn.naive_bayes import MultinomialNB # 朴素贝叶斯
 
data = pd.read_csv('./data/书籍评价.csv', encoding='gbk')  
data['label'] = np.where(data['评价'] == '好评', 1, 0)  
y = data['label']  
comment_list = [','.join(jieba.lcut(line)) for line in data['内容']] # 对评论内容做切词  
# 加载停用词列表，里面记录的词不参与训练  
with open("./data/stopwords.txt", "r", encoding="utf-8") as f:  
stopwords = [line.strip() for line in f.readlines()]  
stopwords = list(set(stopwords)) # 停用词去重  
# 创建向量化对象，从comment_list删除停用词  
transfer = CountVectorizer(stop_words=stopwords)  
transfer.fit(comment_list) # 统计词频矩阵，训练  
x = transfer.transform(comment_list).toarray() # 统计词频矩阵，转换结果就是[[第n条评论切词分布有则为1否则0]...]  
transfer.get_feature_names_out()  
x_train = x[:10]  
y_train = y[:10]  
x_test = x[10:]  
y_test = y[10:]  
estimator = MultinomialNB() # 朴素贝叶斯对象  
estimator.fit(x_train, y_train)  
y_pred = estimator.predict(x_test)
