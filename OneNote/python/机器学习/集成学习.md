**GBDT****（梯度****/****残差提升树** **Gradient Boosting Decision Tree****）**  
通过拟合残差来提升（-梯度 = 残差 = 真实值 - 预测值）

![Exported image](_assets/%E9%9B%86%E6%88%90%E5%AD%A6%E4%B9%A0/%E9%9B%86%E6%88%90%E5%AD%A6%E4%B9%A0__11-50-41-12.png)

以梯度提升树为例，假设：  
前一轮得到的强学习器是： $f_{i - 1} \left(\right. x \left.\right)$  
损失函数为平方损失是： $L \left(\right. y , &nbsp; f_{i - 1} \left(\right. x \left.\right) \left.\right)$  
本次迭代的目标是找到一个弱学习器：   让本轮的损失最小化： $L \left(y , &nbsp; f_{i} \left(x\right)\right) = L \left(y , &nbsp; f_{i - 1} \left(x\right) + h_{i} \left(x\right)\right) = \left(\left(\right. y - &nbsp; f_{t - 1} \left(x\right) - &nbsp; h_{t} \left(x\right) \left.\right)\right)^{2}$  
那么要拟合的负梯度为：

$- \left[\frac{𝜕 L \left(y , &nbsp; f \left(x_{i}\right)\right)}{𝜕 f \left(x_{i}\right)}\right] = y_{i} - f \left(\right. x_{i} \left.\right)$

GBDT拟合的负梯度就是残差。如果进行的是分类问题，则损失函数变为logloss，此时拟合的目标值是该损失函数的负梯度值

import pandas as pd  
from sklearn.ensemble import GradientBoostingClassifier  
from sklearn.model_selection import train_test_split, GridSearchCV  
from sklearn.metrics import accuracy_score
 
data = pd.read_csv('./data/train.csv')  
x = data[['Pclass', 'Sex', 'Age']].copy()  
y = data['Survived'].copy()  
x['Age'] = x['Age'].fillna(x['Age'].mean())  
x = pd.get_dummies(x)  
x_train, x_test, y_train, y_test = train_test_split(x, y, test_size=0.2, random_state=23)  
# 单个GBDT树  
estimator = GradientBoostingClassifier(n_estimators=50)  
estimator.fit(x_train, y_train)  
y_pre = estimator.predict(x_test)  
print('单个GBDT树准确率: ', accuracy_score(y_test, y_pre)) # 0.7932960893854749  
# 超参网格搜索

'n_estimators': [50, 100, 200],

# 有些模型模型做网格搜索时要先训练，是个例需要记住  
estimator = GridSearchCV(param_grid=param_dict, estimator=GradientBoostingClassifier(), cv=5)  
estimator.fit(x_train, y_train)  
y_pre = estimator.best_estimator_.predict(x_test)  
print('网格搜索后的准确率: ', accuracy_score(y_test, y_pre)) # 0.8156424581005587  
**XGBoost****（极端梯度提升树** **Extreme Gradient Boosting****）**  
构建思想：  
最小化训练数据的损失函数，但训练的模型复杂度较高易过拟合

$\underset{f \in F}{m i n} ⁡ \frac{1}{N} \sum_{i = 1}^{N} L \left(\right. y_{i} , f \left(\right. x_{i} \left.\right) \left.\right)$

然后在损失函数中添加正则化项，提高对未知数据的泛化性能

$\underset{}{m i n} ⁡ \frac{1}{N} \sum_{i = 1}^{N} L \left(\right. y_{i} , f \left(\right. x_{i} \left.\right) \left.\right) + \Omega \left(\right. f \left.\right)$

XGBoost是对GBDT的改进，在损失函数中添加了正则化项

$o b j \left(𝜃\right) = \sum_{i}^{n} L \left(\right. y_{i} , \hat{y}_{i} \left.\right) + \sum_{k = 1}^{K} \Omega \left(\right. f_{k} \left.\right)$

正则化项用来降低模型复杂度

$𝛺 \left(f\right) = 𝛾 T + \frac{1}{2} \lambda \left‖\left(w\right‖\right)^{2}$

$𝛾 T$ 的 $T$ 表示一棵树的叶子节点数量  
$\lambda \left‖\left(w\right‖\right)^{2}$ 中的 $w$ 表示叶子结点输出值组成的向量， $\left‖\left(w\right‖\right)$ 为向量的模， $\lambda$ 为对该项的调节系数  
XGBoost打分函数推导

1. 损失函数基础上 + 正则化项
2. 泰勒二阶展开转成近似函数
3. 把问题从 样本角度 -\> 叶节点角度 进行分析
4. 打分函数 -\> Gain值 = 拆分前的分 - (拆分后左子树的分 + 拆分后右子树的分)

要计算第t轮的结果（预测值），则第t-1轮是已知的，于是

$\left(o b j\right)^{t} = \sum_{i = 1}^{n} L \left(\right. y_{i} , \hat{y}_{i}^{\left(\right. t \left.\right)} \left.\right) + \sum_{k = 1}^{t} 𝛺 \left(\right. f_{k} \left.\right) = \sum_{i = 1}^{n} L \left(\right. y_{i} , \hat{y}_{i}^{\left(t - 1\right)} + f_{t} \left(\right. x_{i} \left.\right) \left.\right) + \sum_{k = 1}^{t - 1} 𝛺 \left(\right. f_{k} \left.\right) + 𝛺 \left(\right. f_{t} \left.\right)$

泰勒展开式是

$f \left(x + \Delta x\right) = f \left(x\right) + f^{'} \left(x\right) \Delta x + \frac{1}{2} f ' ' \left(x\right) \Delta x^{2} + \ldots + \frac{1}{n !} f^{\left(n\right)} \left(\right. x \left.\right) \Delta x^{n}$

a式可二阶泰勒展开为

$\left(o b j\right)^{\left(\right. t \left.\right)} \approx \sum_{i = 1}^{m} \left[L \left(y_{i} , \hat{y}_{i}^{\left(t - 1\right)}\right) + g_{i} f_{t} \left(x_{i}\right) + \frac{1}{2} h_{i} f_{t}^{2} \left(x_{i}\right)\right] + \sum_{k = 1}^{t - 1} 𝛺 \left(f_{k}\right) + 𝛺 \left(\right. f_{t} \left.\right)$

其中 $g_{i}$ 和 $h_{i}$ 分别为损失函数的一阶导和二阶导  
$g_{i} = 𝜕_{\hat{y}^{t - 1}} L \left(y_{i} , \hat{y}_{i}^{\left(t - 1\right)}\right)$ $h_{i} = 𝜕_{\hat{y}^{t - 1}}^{2} L \left(y_{i} , \hat{y}_{i}^{\left(t - 1\right)}\right)$  
注意到可以去掉一些常数，得到

$\left(o b j\right)^{\left(\right. t \left.\right)} \approx \sum_{i = 1}^{m} \left[g_{i} f_{t} \left(x_{i}\right) + \frac{1}{2} h_{i} f_{t}^{2} \left(x_{i}\right)\right] + 𝛾 T + \frac{1}{2} \lambda \left‖\left(w\right‖\right)^{2}$

样本预测值可表示为(T为叶节点数量)

$\sum_{i = 1}^{m} g_{i} f_{t} \left(x_{i}\right) = \sum_{j = 1}^{T} \left(\sum_{i \in I_{j}}^{} g_{i}\right) w^{2}$

转换到叶子结点的问题

$\sum_{i = 1}^{m} \frac{1}{2} h_{i} f_{t}^{2} \left(x_{i}\right) = \frac{1}{2} \sum_{j = 1}^{T} \left(\sum_{i \in I_{j}}^{} h_{i}\right) w_{j}^{2}$ $\frac{1}{2} \lambda \left‖\left(w\right‖\right)^{2} = \frac{1}{2} \lambda \sum_{i = 1}^{T} w_{i}^{2}$

最终

$\left(o b j\right)^{\left(t\right)} \approx \sum_{i = 1}^{T} \left[G_{i} w_{t} + \frac{1}{2} \left(H_{i} + \lambda\right)\right] w_{i}^{2} + 𝛾 T$

其中，Gi表示所有样本的一阶导和，Hi表示说有样本的二阶导和  
$G_{i} = \sum_{i \in I_{j}} g_{i}$ $H_{i} = \sum_{i \in I_{j}} h_{i}$  
令

$\frac{d \left(o b j\right)^{\left(t\right)}}{d w_{i}} = \sum_{i = 1}^{T} \left(G_{i} + \left(H_{i} + \lambda\right)\right) w_{i} = 0$

得到

$w_{i} = - \frac{G_{i}}{H_{i} + \lambda}$

带入c式得

$\left(o b j\right)^{\left(t\right)} \approx - \frac{1}{2} \sum_{i = 1}^{T} \frac{G_{i}^{2}}{H_{i} + \lambda} + 𝛾 T$

该公式称为打分函数，从损失函数与树的复杂度两方面衡量，构建树时可以来选择树的划分点：

$G a i n = \left(O b j\right)_{L + R} - \left(\left(O b j\right)_{L} + \left(O b j\right)_{R}\right) = \frac{1}{2} \left[\frac{G_{L}^{2}}{H_{L} + \lambda} + \frac{G_{R}^{2}}{H_{R} + \lambda} - \frac{\left(G_{L} + G_{R}\right)_{}^{2}}{H_{L} + H_{R} + \lambda}\right] - 𝛾$

然后根据Gain值对树中的每个叶子结点尝试进行分裂  
计算分裂前 - 分裂后的分数：  
如果gain \> 0，则分裂之后树的损失更小，会考虑此次分裂  
如果gain\< 0，说明分裂后的分数比分裂前的分数大，此时不建议分裂  
当触发以下条件时停止分裂：  
达到最大深度  
叶子结点数量低于某个阈值  
所有的结点在分裂不能降低损失  
等等...  
代码示例（sklearn中没有，安装xgboost包即可，编码风格支持sklearn或非sklearn）  
import joblib  
import numpy as py  
import pandas as pd  
import xgboost as xgb  
from collections import Counter  
from sklearn.model_selection import train_test_split, GridSearchCV  
from sklearn.model_selection import StratifiedKFold # 分层采样对象  
from sklearn.utils import class_weight
 
# 数据处理  
data = pd.read_csv('./data/红酒品质分类.csv')  
x = data.iloc[:, :-1]  
y = data.iloc[:, -1] - 3 # 最后一列是标签，把范围 [3, 8] -\> [0, 5]  
(x_train, x_test, y_train, y_test) = train_test_split(x, y, test_size=0.2, random_state=23, stratify=y)  
pd.concat([x_train, y_train], axis=1).to_csv("./data/train.csv", index=False)  
pd.concat([x_test, y_test], axis=1).to_csv("./data/test.csv", index=False)
 
# 模型训练与保存  
train_data = pd.read_csv("./data/train.csv")  
test_data = pd.read_csv("./data/test.csv")  
x_train = train_data.iloc[:, :-1] # 除了最后一列都是标签  
y_train = train_data.iloc[:, -1]  
x_test = test_data.iloc[:, :-1]  
y_test = test_data.iloc[:, -1]  
# 加入平衡权重，因为样本数据集是不均衡的  
# 平衡权重，参考的标签  
class_weight.compute_sample_weight('balanced', y_train)  
# 默认二分类，这里指定下  
estimator = xgb.XGBClassifier(n_estimators=100, learning_rate=0.1, max_depth=3, objective="multi:softmax")  
estimator.fit(x_train, y_train)  
joblib.dump(estimator, "./model/xgb.pkl")  
print(estimator.score(x_test, y_test)) # 0.6375
 
# 网格搜索+交叉验证  
train_data = pd.read_csv("./data/train.csv")  
test_data = pd.read_csv("./data/test.csv")  
x_train = train_data.iloc[:, :-1] # 除了最后一列都是标签  
y_train = train_data.iloc[:, -1]  
x_test = test_data.iloc[:, :-1]  
y_test = test_data.iloc[:, -1]  
estimator = joblib.load("./model/xgb.pkl")  
param = {  
'max_depth': [2, 3, 5], 'n_estimators': [100, 200, 500], 'learning_rate': [0.1, 0.2, 0.5]  
}  
# 创建分层采样对象，指定折数、是否打乱  
skf = StratifiedKFold(n_splits=5, shuffle=True, random_state=23)  
# 创建网格搜索+交叉验证对象  
estimator = GridSearchCV(estimator, param, cv=skf)  
estimator.fit(x_train, y_train)  
y_pre = estimator.predict(x_test)  
print(estimator.best_score_) # 0.677092524509804  
print(estimator.best_params_) # {'learning_rate': 0.2, 'max_depth': 3, 'n_estimators': 200}
