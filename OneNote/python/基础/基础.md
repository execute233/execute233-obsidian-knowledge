# 基础

## 各种量的定义

逆天 py，用名字标识：

- 单下划线开头 - protected
- 双下划线开头 - private
- 常量 - 全部字母大写
- 虚数 - 用 `实部+虚部j` 来定义，使用 `.real` 和 `.imag` 获取实部和虚部

## 序列

通用操作：

```python
x in s              # 判断x是否是s里的元素
x not in s          # 与上面相反
len(s)              # s中元素的个数
max(s)              # s中的最大值
min(s)              # s中的最小值
s.index(x)          # 序列s中第一次出现x的位置
```

### 列表 `[]`, `list()`

```python
append(x)                # 在列表最后添加一个元素
insert(index, x)         # 在第index位置增加一个元素
clear()                  # 清除列表中的所有元素
pop(index)               # 取出第index元素,并从列表中删除
remove(x)                # 删除列表中出现的第一个x
reverse()                # 反转列表
copy()                   # 拷贝所有元素生成一个新列表
sort(key=None, reverse=False)  # 排序:排序规则,排序方式(默认升序)
```

#### 列表生成式

```python
lst = [expression for item in range]
lst = [expression for item in range if condition]
```

### 元组 `()`, `tuple()`

```python
有元组生成式,同list差不多,将[]改为()即可
```

### 字典 `{}`, `zip(lst1, lst2)`, `dict(key1=value1, ...)`

#### 元素获取

```python
d[key]                   # 获取字典d的元素,不存在时报错
d.get(key)               # 同上,但不存在时返回None
d.get(key, defaultValue) # 同上,不存在时返回defaultValue
```

#### 元素遍历

```python
for key, value in d.items():
    xxx

# 或
for element in d.items():  # key和value组成的元组
    xxx
```

#### 元素操作

```python
keys()                # 获取所有的key数据
values()              # 获取所有的value数据
pop(key, default)     # key存在获取相应的value并删除k-v对,否则取默认值
d.popitem()           # 随机取出k-v对,并删除这个k-v对
d.clear()             # 字面意思
```

#### 字典生成式

```python
d = {key: value for item in range}

# 如
d = {item: item + 1 for item in range(3)}  # {0: 1, 1: 2, 2: 3}
```

### 集合 `{}`

```python
add(x)       # 如果x不在集合s中,则添加x到集合s中
remove(x)    # 删除元素x,没有则报错
clear()      # 字面意思
```

## 序列的切片

```python
[开始索引 : 截止的索引 : 步长]
```

```python
s.count(x)  # 序列s中出现x的次数

# 如:
lst = [i for i in range(10) if i % 2 == 0]  # [0, 2, 4, 6, 8]
```

## 注意事项

- 其他语言里的 `switch` 在 py 里是 `match`，不用 `break`
- 有 `if..else` 和 `while..else` 语句，只有正常执行没有中断才会执行 `else` 中的内容
