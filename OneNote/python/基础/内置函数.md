# 内置函数

## print(self, *args, sep=' ', end='\n', file=None)

参数说明：

- `self` - 调用对象本身
- `*args` - 多个接受输出的参数
- `sep` - `*args` 中多个输出参数之间的内容
- `end` - 结束时的输出
- `file` - 输出到的文件对象

## input()

```python
input([prompt])
```

参数说明：

- `prompt` - 提示信息，可选
- 返回值为用户输入的字符串
