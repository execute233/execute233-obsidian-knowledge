# 内置函数

## print(*objects, sep=' ', end='\n', file=sys.stdout, flush=False)

参数说明：

- `*objects` - 多个接受输出的参数
- `sep` - `*objects` 中多个输出参数之间的分隔内容
- `end` - 结束时的输出字符
- `file` - 输出到的文件对象
- `flush` - 是否立即刷新输出缓冲区

## input()

```python
input([prompt])
```

参数说明：

- `prompt` - 提示信息，可选
- 返回值为用户输入的字符串
