**格式化字符串**

1. **占位符格式化**

```python
%s: 字符串格式
%d: 十进制数格式
%f: 浮点数格式(可用%?.?f指定保留位数)
```

```python
print("xx%dxx", num)
```

4. **f-string**

```python
f"xxx{str}xxx"
```

6. **str.format**

```python
"xxx{0}xxx{1}xxx{2}".format(str1, str2, str3)
有以下详细格式
```

|   |   |
|---|---|
|:|引导符号|
|填充|用于填充单个字符|
|对齐方式|< > ^ 分别为左 右 居中对齐|
|宽度|字符串的输出宽度|
|，|数字的千位分割符,|
|.精度|浮点小数部分或字符串的最大输出长度|
|类型|b\d\o\x\X或e\E\f\%|

```python
如
如：
"{0:*\<20}".format(s) # 显示宽度20，左对齐,空白部分*填充
```
