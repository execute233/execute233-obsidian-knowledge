# 字符串相关

## 相关方法

### str.lower()

略

### str.upper()

略

### str.split(sep=None)

略

### str.count(sub)

结果为 `sub` 这个字符串在 `str` 中出现的次数

### str.find(sub)

查询 `sub` 这个字符串是否存在,不存在为 `-1`,否则为结果首次出现的索引

### str.index(sub)

功能与 `find` 相同,但不存在时会报错

### str.startswith(s)

略

### str.endswith(s)

略

### str.replace(old, news)

略

### str.center(width, fillchar)

在指定的宽度范围居中,可使用 `fillchar` 填充

### str.join(iter)

在 `iter` 每个元素后面都增加一个新字符串 `str`

### str.strip(chars)

去掉左侧和右侧 `chars` 中列出的字符串

### str.lstrip(chars)

去掉左侧 `chars` 中列出的字符串

### str.rstrip(chars)

去掉右侧 `chars` 中列出的字符串

## 字符串检验相关

### str.isdigit()

都是数字(阿拉伯数字)

### str.isnumeric()

都是数字

### str.isalpha()

都是字母(包含中文字符)

### str.isalnum()

都是数字或字母(包含中文字符)

### str.islower()

所有字符都是小写

### str.isupper()

所有字符都是大写

### str.istitle()

所有字符都是首字母大写

### str.isspace()

都是空白字符(`\n`、`\t` 等)

## 格式化字符串

### 占位符格式化

```python
%s  # 字符串格式
%d  # 十进制数格式
%f  # 浮点数格式(可用%?.?f指定保留位数)

print("xx%dxx" % num)
```

### f-string

```python
f"xxx{str}xxx"
```

### str.format

```python
"xxx{0}xxx{1}xxx{2}".format(str1, str2, str3)
```

格式说明:

| 字段 | 含义 |
|---|---|
| `:` | 引导符号 |
| 填充 | 用于填充单个字符 |
| 对齐方式 | `<` `>` `^` 分别为左、右、居中对齐 |
| 宽度 | 字符串的输出宽度 |
| `,` | 数字的千位分隔符 |
| `.精度` | 浮点小数部分或字符串的最大输出长度 |
| 类型 | `b` `d` `o` `x` `X` 或 `e` `E` `f` `%` |

示例:

```python
"{0:*<20}".format(s)  # 显示宽度20,左对齐,空白部分*填充
```

## 正则表达式

### 元字符

具有特殊意义的专用字符,例如 `^` 和 `$` 分别表示匹配的开始和结束。

| 元字符 | 描述说明 | 举例 | 结果 |
|---|---|---|---|
| `.` | 匹配任意字符(除 `\n`) | `'p\nython\n'` | `p`、`y`、`t`、`h`、`o`、`\t`、`n` |
| `\w` | 匹配字母、数字、下划线 | `'python\n123'` | `p`、`y`、`t`、`h`、`o`、`n`、`1`、`2`、`3` |
| `\W` | 匹配非字母、数字、下划线 | `'python\n123'` | `\n` |
| `\s` | 匹配任意空白字符 | `'python\t123'` | `\t` |
| `\S` | 匹配任意非空白字符 | `'python\t123'` | `p`、`y`、`t`、`h`、`o`、`n`、`1`、`2`、`3` |
| `\d` | 匹配任意十进制数 | `'python\t123'` | `1`、`2`、`3` |
