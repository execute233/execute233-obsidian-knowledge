# 常见问题

## matplotlib 中文显示乱码

### 法一(下载中文字体)

1. 下载 SimHei 字体
2. linux 下到 `/usr/share/fonts`,其他系统双击安装
3. 删除 `~/.matplotlib` 中的缓存文件
4. 修改 `~/.matplotlib/matplotlibrc` 为:

```yaml
font.family: sans-serif
font.sans-serif: SimHei
axes.unicode_minus: False
```

### 法二(py 里动态配置)

```python
from pylab import mpl

mpl.rcParams["font.sans-serif"] = ["SimHei"]  # 也可以修改为 "Microsoft YaHei"
# 修改后若部分字符无法正常显示,可以:
mpl.rcParams["axes.unicode_minus"] = False
```
