## LangGraph 是什么

LangGraph 是用于构建**有状态、多步骤 Agent 工作流**的图编排框架。

它适合以下场景：

- 模型需要循环调用工具；
- 工作流存在分支、循环和并行任务；
- 需要保存会话和执行状态；
- 执行到一半需要人工审批；
- 节点失败后需要重试或恢复；
- 多个 Agent 需要分工协作；
- 普通业务代码、外部 API 和 LLM 需要组合执行。

核心心智模型：

```text
State：工作流共享的数据
Node：读取 State，执行逻辑，返回局部状态更新
Edge：决定节点之间如何跳转
Reducer：决定同一 State 字段的新旧值如何合并
Checkpointer：跨执行保存线程状态
Store：跨线程保存长期数据
```

最重要的一句话：

> **节点负责做事，边负责带路，State 负责携带整个执行过程的数据。**

## 环境准备

```bash
python -m venv .venv
```

Windows PowerShell：

```powershell
.venv\Scripts\Activate.ps1
```

安装基础依赖：

```bash
pip install -U langgraph langchain-openai python-dotenv
```

工具调用示例还会使用：

```bash
pip install -U langchain
```

生产持久化示例还需要：

```bash
pip install -U langgraph-checkpoint-postgres "psycopg[binary,pool]"
```
