# 游戏时间

```cs
// 游戏开始到现在所花的时间(秒)
Debug.Log(Time.time);

// 时间缩放值,1 表示正常速度,<1 慢动作,>1 快进
Debug.Log(Time.timeScale);

// FixedUpdate 方法的固定调用间隔(秒)
Debug.Log(Time.fixedDeltaTime);

// 上一帧到当前帧所用的游戏时间(秒),常用于位移计算:位移 = 速度 * Time.deltaTime
Debug.Log(Time.deltaTime);
```
