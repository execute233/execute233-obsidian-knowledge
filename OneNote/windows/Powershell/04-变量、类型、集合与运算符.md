# 1. PowerShell 变量

PowerShell 变量以 `$` 开头：

```powershell
$name = "Ema"
$age  = 15
$enabled = $true
```

读取：

```powershell
$name
$age
$enabled
```

PowerShell 变量名默认不区分大小写，`$name`、`$Name`、`$NAME` 指向同一个变量。

---

# 2. 默认动态类型

```powershell
$value = 100
$value.GetType()      # System.Int32

$value = "Hello"
$value.GetType()      # System.String

$value = Get-Date
$value.GetType()      # System.DateTime
```

PowerShell 默认根据赋给变量的 .NET 对象决定其类型，同一个未受类型约束的变量可在不同时间保存不同类型的值。

Java 视角对照：

```text
Java      变量声明通常带静态类型
PowerShell 变量默认没有固定类型约束
```

---

# 3. 查看真实类型

```powershell
$value.GetType()
$value.GetType().FullName

$a | Get-Member
```

注意：

```powershell
$array | Get-Member
```

会因为 Pipeline 自动枚举而显示数组内元素的成员。如果要看数组对象本身：

```powershell
Get-Member -InputObject $array
```

---

# 4. 常见 .NET 类型

| PowerShell 写法 | .NET 类型                        |
| ------------- | ------------------------------ |
| `[byte]`      | `System.Byte`                  |
| `[int]`       | `System.Int32`                 |
| `[long]`      | `System.Int64`                 |
| `[float]`     | `System.Single`                |
| `[double]`    | `System.Double`                |
| `[decimal]`   | `System.Decimal`               |
| `[string]`    | `System.String`                |
| `[bool]`      | `System.Boolean`               |
| `[datetime]`  | `System.DateTime`              |
| `[timespan]`  | `System.TimeSpan`              |
| `[array]`     | `System.Array`                 |
| `[hashtable]` | `System.Collections.Hashtable` |

这些 `[int]` / `[string]` 等通常被称为 `Type Accelerator`，是常用 .NET 类型名称的简短写法。

---

# 5. 强制类型转换

```powershell
$value = "123"
[int]$value
```

得到 `123`，类型 `Int32`。PowerShell 支持 `[Type] expression` 形式的显式类型转换。

---

# 6. 强类型变量

```powershell
[int]$port = 8080
```

现在 `$port = "9000"` 时 PowerShell 会尝试把 `"9000"` 转成 `Int32`，类型保持不变。赋值时无法转换则报错。

PowerShell 官方称之为 `Type-constrained variable`。

---

# 7. 数字 Literal

```powershell
123
0xFF         # 十六进制
0b11111111   # 二进制
1KB
1MB
1GB
1TB
```

`1KB` / `1MB` 等是二进制乘数：

```text
1KB = 1024
1MB = 1024²
1GB = 1024³
1TB = 1024⁴
```

所以 `500MB` 本身就是一个数字表达式，`$_.WorkingSet64 -gt 500MB` 可直接工作。

---

# 8. 算术运算符

```powershell
10 + 5
10 - 5
10 * 5
10 / 5
10 % 3
```

`+` 与 `*` 不只作用于数字：`+` 可连接字符串、数组、Hashtable；运算行为受左操作数类型影响。

```powershell
"Power" + "Shell"          # "PowerShell"

$array1 = @(1, 2)
$array2 = @(3, 4)
$array1 + $array2           # @(1, 2, 3, 4)
```

---

# 9. 左操作数驱动类型转换

```powershell
10 - "9"
```

得到 `1`。因为左边 `10` 是 `Int32`，PowerShell 尝试把右边 `"9"` 转成 `Int32`。

Microsoft 类型转换文档明确指出：操作符通常根据左操作数的类型决定运算所需类型，然后尝试转换右操作数。

---

# 10. 比较运算符

PowerShell 不使用 Java 风格的 `==` / `!=`，而是：

```text
-eq  equal
-ne  not equal
-gt  greater than
-ge  greater or equal
-lt  less than
-le  less or equal
```

例如：

```powershell
10 -eq 10      # True
10 -gt 5       # True
10 -le 5       # False
```

---

# 11. 自动类型转换

```powershell
1 -eq "1.0"
```

结果 `True`。因为左边 `Int32`，PowerShell 尝试把 `"1.0"` 转成整数后比较。

> [!warning]
> `"1.0" -eq 1` 与 `1 -eq "1.0"` 在混合类型比较中可能语义不同，正式脚本不要依赖模糊的隐式转换，推荐 `[int]$port = 8080` 这种写法。

---

# 12. 字符串比较默认忽略大小写

```powershell
"PowerShell" -eq "powershell"   # True
```

显式大小写敏感：

```powershell
-ceq     # Case-sensitive
-ieq     # case-Insensitive
```

还有 `-clike` / `-ilike` / `-cmatch` / `-imatch` 等类似变体。

---

# 13. 集合比较陷阱

```powershell
1, 2, 3, 2, 4 -eq 2
```

返回：

```text
2
2
```

而不是 `True`。PowerShell 比较运算符在左操作数是集合时，对集合成员进行比较并返回匹配的元素，而不是返回 Boolean。官方文档把这种行为描述为"既可比较两个标量，也可用一个输入值过滤集合成员"。

Java 类比：

```java
array.stream()
    .filter(x -> x == 2)
    .toList();
```

而不是 `array.equals(2)`。

---

# 14. -contains 与 -in

如果只想问"集合是否包含某值"：

```powershell
$array -contains 2      # True

$extensions = ".java", ".kt", ".ps1"
$extensions -contains ".java"     # True

".java" -in $extensions           # True
```

`-contains` 与 `-in` 属于 containment operators，即使面对集合也返回 Boolean，并在发现匹配后停止查找。

Pipeline 中常见：

```powershell
Get-ChildItem -File |
    Where-Object {
        $_.Extension -in ".java", ".kt", ".ps1"
    }
```

---

# 15. -like 与 -match

`-like` 使用通配符：

```powershell
"PowerShell" -like "Power*"
"application.yml" -like "*.yml"
```

通配符 `*` 匹配任意数量字符，`?` 匹配一个字符。

`-match` 使用正则：

```powershell
"java-service-01" -match "^java-"
"server-8080" -match "\d+"
```

简单文件名用 `-like`，复杂规则用 `-match`。

---

# 16. -is 与 -as

测试对象是否为指定 .NET 类型：

```powershell
$value = Get-Date
$value -is [datetime]      # True
$value -is [string]        # False
```

`-is` 与 `-isnot` 始终返回 Boolean，且不会自动枚举集合成员。

`-as` 尝试类型转换，失败时返回 `$null`：

```powershell
"2026-08-11" -as [datetime]    # DateTime 对象
"hello" -as [datetime]         # $null
```

这是 `-as` 与 `[int]"hello"` 这种 cast 的重要区别——cast 失败会报错。

---

# 17. 集合 -is 的坑

```powershell
$a = Get-Date
$b = Get-Date

@($a, $b) -is [datetime]       # False
@($a, $b) -is [array]          # True
```

类型运算符作用于整个输入对象，不会自动枚举集合成员。

---

# 18. Boolean 转换

常见 False 值：

```text
$false
$null
数字 0
空字符串 ""
空集合 @()
```

非空字符串是 `True`：

```powershell
[bool]"False"      # True
```

非空字符串即非空字符串，并不是解析字符串里的 Boolean 含义。要解析字符串中的 Boolean：

```powershell
[bool]::Parse("false")
```

---

# 19. Collection 转 Boolean

```powershell
[bool]@()      # False
[bool]@(0)      # False
[bool]@(0, 0)   # True
```

规则：

```text
空集合              → False
单元素集合           → 看元素自己的 Boolean
两个及以上元素         → True
```

---

# 20. 逻辑运算符

```powershell
$a = 10

($a -gt 5) -and ($a -lt 20)
```

`-and` / `-or` 支持短路求值：

```text
-and  左边 False 则不评估右边
-or   左边 True  则不评估右边
```

---

# 21. 运算符优先级

PowerShell 有自己的优先级规则，比较运算符 `-gt` / `-eq` 优先于 `-and` / `-or`，且 `-and` / `-or` / `-xor` 处于同一优先级组，从左到右计算。

复杂表达式建议主动加括号：

```powershell
($a -gt 10) -and
(($b -eq "prod") -or ($b -eq "dev"))
```

---

# 22. $null

```powershell
$null -eq $undefinedVariable    # True
```

推荐：

```powershell
$null -eq $value
```

而不是：

```powershell
$value -eq $null
```

因为集合比较时 `$value -eq $null` 会变成"从集合中筛选 `$null` 元素"。PSScriptAnalyzer 有一条默认启用的规则专门警告这种写法。

形成肌肉记忆：

```powershell
if ($null -eq $value) { }
if ($null -ne $value) { }
```

# 23. Array

```powershell
$numbers = 1, 2, 3, 4, 5

$numbers = @(
    1
    2
    3
)

$data = @(
    1
    "hello"
    (Get-Date)
    $true
)
```

PowerShell Array 可包含不同类型的元素。

强类型数组：

```powershell
[int[]]$numbers = @(1, 2, 3)
```

---

# 24. Array 索引与切片

```powershell
$array[0]
$array[-1]      # 最后一个

$array[0, 2, 4]
$array[0..3]    # 前四个
```

Range：

```powershell
1..5
```

得到 `1 2 3 4 5`。

---

# 25. Array 强制包装 @()

```powershell
$processes = @(Get-Process -Name java -ErrorAction SilentlyContinue)
```

无论结果是 0、1 还是多个，`$processes.Count` 都可靠工作。PowerShell 官方 Array 文档专门介绍 `@()` 这一用途。

# 26. Hashtable

```powershell
$config = @{
    Host = "localhost"
    Port = 8080
    Env  = "dev"
}
```

Hashtable 是 `System.Collections.Hashtable`，存储 `Key → Value` 映射。

读取：

```powershell
$config["Host"]
$config.Host
```

修改：

```powershell
$config.Port = 9000
$config.Debug = $true
$config.Remove("Debug")
```

普通 Hashtable Key 顺序不固定，需要固定顺序用：

```powershell
[ordered]@{
    Name = "user-service"
    Port = 8080
}
```

---

# 27. PSCustomObject

```powershell
$service = [PSCustomObject]@{
    Name   = "user-service"
    Port   = 8080
    Status = "Running"
}
```

PowerShell 3.0 起可把 literal Hashtable 转换为 `[pscustomobject]` 创建带属性的自定义对象。

```powershell
$service | Get-Member
```

显示 `Name` / `Port` / `Status` 都是 `NoteProperty`。

`[PSCustomObject]` 适合进入 Pipeline、JSON、CSV、REST API 等结构化数据工作流。

---

# 28. Hashtable VS PSCustomObject

```text
Hashtable     根据 Key 找 Value，是 Dictionary
PSCustomObject 通过属性访问，是 Object
```

PowerShell 脚本工程推荐使用 `[PSCustomObject]`，避免到处拼接字符串。

---

# 29. 创建多个 Service Objects

```powershell
$services = @(
    [PSCustomObject]@{
        Name   = "user-service"
        Port   = 8080
        Status = "Running"
    }
    [PSCustomObject]@{
        Name   = "order-service"
        Port   = 8081
        Status = "Stopped"
    }
    [PSCustomObject]@{
        Name   = "agent-service"
        Port   = 8082
        Status = "Running"
    }
)

$services | Where-Object Status -eq Running
```

# 30. Scope

主要 Scope：

```text
Global
Script
Local
Private
```

PowerShell 的 Scope 可嵌套，变量、函数、Alias 等通常在创建它们的 Scope 和子 Scope 中可见。

```powershell
$Global:Name = "Ema"
$Local:Name  = "Ema"
```

函数会创建子 Scope，查找变量时从当前 Scope 开始向父 Scope 搜索。但子 Scope 中对变量赋新值通常不会修改父 Scope 中同名变量。

显式修改全局：

```powershell
function Test-Scope {
    $Global:name = "inside"
}
```

正式函数中尽量避免随意修改 Global 状态。

---

# 31. ?? 与 ??=

PowerShell 7 提供 Null-coalescing：

```powershell
$name = $null
$result = $name ?? "Unknown"     # Unknown
```

`??=` 表示"如果是 `$null` 则赋值"：

```powershell
$configPath ??= ".\config.json"
```

`??` 判断的是 `$null`，不是 JavaScript `||` 的 falsey。

---

# 32. 三元表达式

PowerShell 7.0 引入：

```powershell
condition ? trueValue : falseValue
```

```powershell
$port = 8080

$status =
    ($port -eq 8080) ?
        "default" :
        "custom"
```

简单 `if/else` 表达式用三元很合适，复杂逻辑仍建议 `if/elseif/else`。

# 33. 赋值运算符

```powershell
$a = 10
$a += 5
$a -= 5
$a *= 2
$a /= 2
$a %= 3
$a++
$a--

$a ??= "default"
```

Array 的 `+=` 实质上是创建新数组：

```powershell
$array = @(1, 2)
$array += 3
```

大量元素构建时不要无脑使用 `+=`，应使用更合适的数据结构或 Pipeline。

# 34. 本课 Java → PowerShell 陷阱

陷阱一：字符串比较默认不区分大小写。

```powershell
"PowerShell" -eq "powershell"     # True
```

需要严格区分用 `-ceq`。

陷阱二：集合与标量比较返回匹配元素而不是 Boolean。

```powershell
1, 2, 3 -eq 2     # 2
```

陷阱三：非空字符串即为 True。

```powershell
[bool]"false"     # True
```

陷阱四：Null 检查顺序。

```powershell
$value -eq $null     # 危险
$null -eq $value     # 推荐
```

陷阱五：混合类型隐式转换。

```powershell
1 -eq "1.0"     # True
```

不要简单套 Java 的类型比较直觉。

# 35. 综合实战：Service Configuration Model

```powershell
$services = @(
    [PSCustomObject]@{
        Name        = "user-service"
        Port        = 8080
        Environment = "prod"
        Enabled     = $true
        MemoryLimit = 512MB
    }
    [PSCustomObject]@{
        Name        = "order-service"
        Port        = 8081
        Environment = "prod"
        Enabled     = $true
        MemoryLimit = 1GB
    }
    [PSCustomObject]@{
        Name        = "agent-service"
        Port        = 9000
        Environment = "dev"
        Enabled     = $false
        MemoryLimit = 2GB
    }
)
```

查询启用 + 生产 + 大内存：

```powershell
$services |
    Select-Object `
        Name,
        Port,
        Environment,
        @{
            Name = "Tier"
            Expression = {
                ($_.MemoryLimit -ge 1GB) ?
                    "Large" :
                    "Standard"
            }
        }
```
