# 1. if

```powershell
if ($port -eq 8080) {
    "Default port"
}
```

完整结构：

```powershell
if (<condition1>) {
    # ...
}
elseif (<condition2>) {
    # ...
}
else {
    # ...
}
```

PowerShell 依次测试条件，一旦某个分支成立就执行对应代码并结束整个 `if` 结构。

---

# 2. if 的条件不一定非得是 Boolean

```powershell
if ("hello") {
    "True"
}
```

非空字符串 → True。

```powershell
if ("") {
    "True"
}
else {
    "False"
}
```

空字符串 → False。

Boolean 转换规则：

```text
$null       → False
""          → False
0           → False
非空 String → True
普通对象     → True
```

集合有自己的特殊转换规则。

---

# 3. 一个非常 PowerShell 的条件

```powershell
if (Get-Process -Name java -ErrorAction SilentlyContinue) {
    "Java is running"
}
```

`Get-Process` 没有结果是 False，有 Process 对象是 True。

类似：

```powershell
if (Test-Path $path) { }

if ($object) { }
```

---

# 4. 集合转 Boolean 要小心

```powershell
$result = @(0)

if ($result) {
    "TRUE"
}
else {
    "FALSE"
}
```

结果是 `FALSE`，因为单元素集合的 Boolean 值取决于那个唯一元素。

```powershell
$result = @(0, 0)   # TRUE
```

如果真要检查数量：

```powershell
if ($collection.Count -gt 0) { }
```

---

# 5. 多条件判断

```powershell
if (
    $environment -eq "prod" -and
    $port -eq 8080
) {
    "Production service"
}
```

推荐复杂条件加括号：

```powershell
if (
    ($environment -eq "prod") -and
    ($port -ge 8000)
) {
    ...
}
```

---

# 6. Guard Clause

```powershell
if (-not (Test-Path $configPath)) {
    return
}

# 正常逻辑
```

比嵌套 `if` 更扁平：

```text
发现异常条件
    ↓
尽早离开
```

---

# 7. switch

如果出现多个 `elseif`：

```powershell
switch ($status) {

    "Running" {
        "Service running"
        break
    }

    "Stopped" {
        "Service stopped"
        break
    }

    "Paused" {
        "Service paused"
        break
    }

    default {
        "Unknown"
    }
}
```

官方将 `switch` 描述为处理多个条件的一种更简洁方式。

---

# 8. switch 与 Java 最大区别

Java 的 `switch` 一个值命中一个 case。PowerShell 不是这样：

```powershell
switch (3) {

    3 {
        "first"
    }

    3 {
        "second"
    }
}
```

输出：

```text
first
second
```

一个输入匹配多个条件时，所有匹配条件的动作都可能执行，除非显式 `break`。

---

# 9. switch 默认匹配行为

```powershell
switch ("PROD") {
    "prod" {
        "Matched"
    }
}
```

可匹配，因为普通 `switch` 默认精确匹配 + 忽略大小写，等价于 `-Exact` 模式。

> [!warning]
> PowerShell `switch` 在普通匹配时会将输入值与比较值转成字符串。如果类型敏感，更推荐使用 ScriptBlock：
>
> ```powershell
> switch ($value) {
>     { $_ -is [int] } { "Integer" }
>     { $_ -is [string] } { "String" }
> }
> ```

---

# 10. switch 中的 $_

```powershell
switch (10) {
    { $_ -gt 5 } {
        "$_ > 5"
    }
}
```

`$_` 代表当前正在被 switch 检查的输入值。

---

# 11. switch 直接处理数组

```powershell
switch (1, 2, 3, 4, 5) {
    { $_ % 2 -eq 0 } { "$_ is even" }
    { $_ % 2 -ne 0 } { "$_ is odd" }
}
```

PowerShell 会逐元素处理。

---

# 12. continue 在 switch 中很特别

```powershell
switch (1, -1, 2, -2, 3) {
    { $_ -lt 0 } {
        continue
    }
    default {
        $_
    }
}
```

输出：

```text
1
2
3
```

`continue` 不是退出整个 switch，而是跳过当前输入，处理下一个。`break` 才是结束整个 switch。

---

# 13. switch -Wildcard

```powershell
switch -Wildcard ("application-prod.yml") {
    "*.yml"          { "YAML" }
    "application-*"  { "Application config" }
}
```

两个 Pattern 都匹配，因此两段都会执行（PowerShell `switch` 没有自动 break）。

---

# 14. switch -Regex

```powershell
switch -Regex ("server-8080") {
    '^server-(\d+)$' {
        "Port = $($Matches[1])"
    }
}
```

`-Regex` 使用正则匹配，成功时 `$Matches` 可用。

---

# 15. switch -File

```powershell
switch -File .\application.log {
    "ERROR*" { $_ }
}

switch -Regex -File .\application.log {
    'ERROR|Exception' { $_ }
}
```

`switch -File` 一次读取一个文件，逐行交给 switch 处理。

---

# 16. foreach

```powershell
foreach ($item in $collection) {

}
```

例如：

```powershell
$ports = 8080, 8081, 9000

foreach ($port in $ports) {
    "Checking $port"
}
```

遍历对象：

```powershell
foreach ($process in Get-Process) {
    $process.ProcessName
}
```

`foreach` 是 PowerShell 的语言结构，遍历集合元素。

---

# 17. foreach VS ForEach-Object

```powershell
Get-Process |
    ForEach-Object {
        $_.ProcessName
    }
```

`ForEach-Object` 是 Cmdlet。

```powershell
foreach ($process in Get-Process) {
    $process.ProcessName
}
```

`foreach` 是语言结构。

简单选择：

```text
正在写 Pipeline           → ForEach-Object
正在写较复杂流程控制       → foreach
```

复杂流程控制示例：

```powershell
foreach ($service in $services) {

    if (-not $service.Enabled) {
        continue
    }

    if ($service.Port -lt 1) {
        continue
    }

    # 多步业务逻辑
}
```

---

# 18. continue

```powershell
foreach ($number in 1..5) {

    if ($number -eq 3) {
        continue
    }

    $number
}
```

输出：

```text
1
2
4
5
```

`continue` 终止当前 iteration，直接进入下一轮。

---

# 19. break

```powershell
foreach ($number in 1..10) {

    if ($number -eq 5) {
        break
    }

    $number
}
```

结果：

```text
1
2
3
4
```

`break` 立刻退出当前循环。

---

# 20. for

```powershell
for ($i = 0; $i -lt 10; $i++) {
    $i
}
```

结构：

```text
Init
↓
Condition
↓
Body
↓
Repeat
↓
Condition
...
```

传统写法：

```powershell
for ($i = 0; $i -lt 10; $i++) {
    $i
}
```

PowerShell 官方将 `for` 定义为：只要条件继续求值为 True，就持续运行代码块。

需要 Index 或特殊步长时 `for` 比 `foreach` 更合适：

```powershell
for ($i = 0; $i -lt $servers.Count; $i++) {
    "$i -> $($servers[$i])"
}
```

无限循环：

```powershell
for (;;) { }

while ($true) { }
```

确保有 `break` 或可靠的终止条件。

---

# 21. while

```powershell
while (<condition>) { }
```

进入循环体前检查条件。条件一开始 False 时一次也不执行。

适合状态驱动：

```powershell
$retry = 0

while ($retry -lt 3) {
    "Attempt $retry"
    $retry++
}
```

---

# 22. do while

```powershell
do {
    # Body
} while (<condition>)
```

至少执行一次。

---

# 23. do until

```powershell
do {

} until (<condition>)
```

条件 False 时继续，True 时停止。至少运行一次。

等待文件出现：

```powershell
do {
    Start-Sleep -Seconds 1
} until (
    Test-Path ".\ready.txt"
)
```

---

# 24. 选择循环结构

| 需求             | 优先考虑             |
| -------------- | ---------------- |
| 遍历 Collection  | `foreach`        |
| Pipeline 逐对象处理 | `ForEach-Object` |
| 需要 Index       | `for`            |
| 按条件重复          | `while`          |
| 至少执行一次         | `do while`       |
| 一直运行直到条件成立     | `do until`       |

---

# 25. 嵌套循环与 Label

```powershell
foreach ($hostName in @("server01", "server02")) {
    foreach ($port in @(80, 443)) {
        "$hostName : $port"
    }
}
```

默认 `break` 只退出最内层循环。Label 可跳出指定层：

```powershell
:serverLoop foreach ($server in $servers) {
    foreach ($port in $ports) {
        if (...) {
            break serverLoop
        }
    }
}
```

`continue serverLoop` 终止当前内层循环，跳到外层 `serverLoop` 处理下一个 Server。Label 必须直接放在循环前。

---

# 26. return 的真正含义

```powershell
function Get-Answer {
    42
}
```

执行：

```powershell
$result = Get-Answer     # 42
```

根本没写 `return`，因为 PowerShell 把正常输出到成功输出流的结果作为函数输出。

---

# 27. return 的陷阱

```powershell
function Get-Result {

    "Starting calculation..."

    $result = 42

    return $result
}

$value = Get-Result
```

`$value` 实际上是：

```text
Starting calculation...
42
```

因为 `"Starting calculation..."` 本身也产生了 Output。官方文档专门用几乎相同的例子提醒这一点。

---

# 28. 调试信息不要污染输出

```powershell
Write-Verbose       "Starting calculation"
Write-Information   "Starting calculation"
```

而不要：

```powershell
"Starting calculation"
```

裸字符串也可能成为函数返回值的一部分。`return` 适合"提前退出函数"或"从函数中途离开"。

---

# 29. return 数组的自动展开

```powershell
function Get-Numbers {

    $numbers = 1, 2, 3

    return $numbers
}

Get-Numbers | Measure-Object    # Count = 3
```

PowerShell 会自动枚举集合，把元素逐个送入 Pipeline。

要阻止自动展开：

```powershell
return (, $numbers)

# 或
Write-Output -NoEnumerate $numbers
```

---

# 30. break / continue / return 对照

| 关键字        | 作用                                     |
| ---------- | -------------------------------------- |
| `continue` | 跳过当前 iteration                         |
| `break`    | 离开当前 loop / switch                     |
| `return`   | 离开当前 function/script/scriptblock scope |

# 31. 实战：Service Health Checker

服务模型：

```powershell
$services = @(
    [PSCustomObject]@{
        Name    = "user-service"
        Host    = "localhost"
        Port    = 8080
        Enabled = $true
    }
    [PSCustomObject]@{
        Name    = "order-service"
        Host    = "localhost"
        Port    = 8081
        Enabled = $true
    }
    [PSCustomObject]@{
        Name    = "agent-service"
        Host    = "localhost"
        Port    = 9000
        Enabled = $false
    }
)
```

PowerShell 7.6 的 `Test-Connection` 支持 `-TcpPort` 与 `-Quiet`：

```powershell
Test-Connection `
    -TargetName localhost `
    -TcpPort 8080 `
    -Quiet
```

返回 `True` / `False`，比解析 `ping` / `netstat` / `curl` 文本输出更符合 PowerShell 思维。

---

# 32. 第一版 Health Checker

```powershell
$results = foreach ($service in $services) {

    if (-not $service.Enabled) {
        [PSCustomObject]@{
            Name   = $service.Name
            Host   = $service.Host
            Port   = $service.Port
            Status = "Disabled"
        }
        continue
    }

    $available = Test-Connection `
        -TargetName $service.Host `
        -TcpPort $service.Port `
        -Quiet

    $status = if ($available) {
        "Healthy"
    }
    else {
        "Down"
    }

    [PSCustomObject]@{
        Name   = $service.Name
        Host   = $service.Host
        Port   = $service.Port
        Status = $status
    }
}
```

为什么 `$results = foreach (...) { }` 可行？因为循环体中 `[PSCustomObject]` 输出会被收集到 `$results`。

```powershell
$results |
    Where-Object Status -eq "Down"
```

后续 Pipeline 仍然可用。

---

# 33. 用 switch 改进状态显示

```powershell
foreach ($result in $results) {

    switch ($result.Status) {

        "Healthy" {
            "$($result.Name): OK"
            break
        }
        "Down" {
            "$($result.Name): ERROR"
            break
        }
        "Disabled" {
            "$($result.Name): SKIPPED"
            break
        }
        default {
            "$($result.Name): UNKNOWN"
        }
    }
}
```

# 34. 加入重试

```powershell
foreach ($service in $services) {

    if (-not $service.Enabled) {
        continue
    }

    $maxRetries = 3
    $attempt    = 0
    $available  = $false

    while (
        -not $available -and
        $attempt -lt $maxRetries
    ) {

        $attempt++

        $available = Test-Connection `
            -TargetName $service.Host `
            -TcpPort $service.Port `
            -Quiet

        if (-not $available) {
            Start-Sleep -Seconds 1
        }
    }

    [PSCustomObject]@{
        Name      = $service.Name
        Available = $available
        Attempts  = $attempt
    }
}
```

`foreach` 处理多个 Service，`while` 实现每个 Service 重试，`if` 决定是否继续，`[PSCustomObject]` 输出结果——已经是比较正规的自动化代码。

# 35. 本课 Java → PowerShell 差异

差异一：PowerShell `switch` 默认匹配多个分支，除非 `break`。

差异二：`switch ($array)` 会逐元素处理集合。

差异三：`switch` 默认比较会进行 String Conversion，类型敏感逻辑更推荐 `{ $_ -is [int] }` 这种 ScriptBlock。

差异四：`continue` 在 `switch` 里表示"跳到下一个输入值"。

差异五：`return` 并不决定函数唯一输出，函数前面产生的普通 Success Output 也是输出。
