**Hash**
就是HashMap<String, HashMap<String, String>>,但里面只能存字符串,不能再嵌套
添加Hash类型的数据
hset <key> [<字段> <值>]
获取(或一次性获取所有字段和值)
hget <key> <字段>
hgetall <key>
判断某个字段是否存在
hexists <key> <字段>
删除Hash中的某个字段
hdel <key> <字段>
查看存了多少个键值对
hlen <key>
一次性获取说有的键
hkeys <key>
一次性获得所有的值
hvals <key>
**List**
列表，支持随机访问，双端操作
可以直接向一个已存在的List中添加数据，不存在会自动创建
-- 头部添加元素
lpush <key> <element> …
-- 尾部添加元素
rpush <key> <element> …
-- 在指定元素前/后添加元素
linsert <key> before/after <指定元素> <element>
同样的，获取元素也简单
-- 根据下标
lindex <key> <下标>
-- 获取并移除头部元素
lpop <key>
-- 获取并移除尾部元素
rpop <key>
-- 获取指定范围内的元素
lrange <key> start stop
下标同py一样可以是负数,比如获取全部元素
lrange <key> 0 -1
从前一个数组中的最后一个数取出来放到另一个数组的头部
rpoplpush 当前数组 目标数组
支持阻塞操作，等到某列表里有了数据后再进行pop
blpop <key>… timeout
**Set**
如HashSet一样，不允许重复元素，不支持随机访问
向Set添加一个或多个值
sadd <key> <value>…
查看Set有多少个值
scard <key>
集合中是否包含指定值
sismember <key> <value>
列出所有值
smembers <key>
集合间的运算
-- 差集
sdiff <key1> <key2>
-- 交集
sinter <key1> <key2>
-- 并集
sunion <key1> <key2>
-- 将集合的差集存到目标集合中
sdiffstore 目标 <key1> <key2>
-- 交集并集保存一样
移除指定值到另外一个集合中
smove <key> 目标 value
移除操作
-- 随机移除一个幸运儿
spop <key>
-- 移除指定
srem <key> <value>…
**SortedSet**
为每个值设定了分数，分数的大小决定了值的位置
创建
zadd <key> [<score> <value>]…
查询有多少个值
zcard <key>
移除指定值
zrem <key> <value>
给指定值的分数加上增量increment
zincrby <key> <increment> <value>
获取区间里的所有值
zrange <key> start stop
通过分数段获取范围内的值
zrangebyscore <key> start stop [withscores] [limit]
获取分数段内的数量
zcount <key> start stop
根据分数获取指定值的排名
zrank <key> <value>
