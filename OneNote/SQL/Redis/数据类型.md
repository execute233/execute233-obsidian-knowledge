# 数据类型

Redis 共支持五种数据类型:String (基本操作中)、Hash、List、Set、SortedSet。

基本操作命令 (set/get/mset 等) 见 [[Redis/基本操作|基本操作]],序列化与磁盘存储格式见 [[Redis/持久化|持久化]]。

## Hash

就是 `HashMap<String, HashMap<String, String>>`,但里面只能存字符串,不能再嵌套。

|命令|说明|
|---|---|
|`hset <key> [<字段> <值>]`|添加 Hash 类型的数据|
|`hget <key> <字段>`|获取某个字段|
|`hgetall <key>`|一次性获取所有字段和值|
|`hexists <key> <字段>`|判断某个字段是否存在|
|`hdel <key> <字段>`|删除 Hash 中的某个字段|
|`hlen <key>`|查看存了多少个键值对|
|`hkeys <key>`|一次性获取所有的键|
|`hvals <key>`|一次性获取所有的值|

## List

列表,支持随机访问,双端操作。

可以直接向一个已存在的 List 中添加数据,不存在会自动创建。

```bash
-- 头部添加元素
lpush <key> <element> …
-- 尾部添加元素
rpush <key> <element> …
-- 在指定元素前/后添加元素
linsert <key> before/after <指定元素> <element>
```

获取元素:

```bash
-- 根据下标
lindex <key> <下标>
-- 获取并移除头部元素
lpop <key>
-- 获取并移除尾部元素
rpop <key>
-- 获取指定范围内的元素
lrange <key> start stop
```

下标同 Python 一样可以是负数,比如获取全部元素:

```bash
lrange <key> 0 -1
```

从前一个数组中的最后一个数取出来放到另一个数组的头部:

```bash
rpoplpush 当前数组 目标数组
```

支持阻塞操作,等到某列表里有了数据后再进行 pop:

```bash
blpop <key>… timeout
```

## Set

如 HashSet 一样,不允许重复元素,不支持随机访问。

|命令|说明|
|---|---|
|`sadd <key> <value>…`|向 Set 添加一个或多个值|
|`scard <key>`|查看 Set 有多少个值|
|`sismember <key> <value>`|集合中是否包含指定值|
|`smembers <key>`|列出所有值|

集合间的运算:

```bash
-- 差集
sdiff <key1> <key2>
-- 交集
sinter <key1> <key2>
-- 并集
sunion <key1> <key2>
-- 将集合的差集存到目标集合中
sdiffstore 目标 <key1> <key2>
-- 交集并集保存一样
```

移除指定值到另外一个集合中:

```bash
smove <key> 目标 value
```

移除操作:

```bash
-- 随机移除一个幸运儿
spop <key>
-- 移除指定
srem <key> <value>…
```

## SortedSet

为每个值设定了分数,分数的大小决定了值的位置。

|命令|说明|
|---|---|
|`zadd <key> [<score> <value>]…`|创建|
|`zcard <key>`|查询有多少个值|
|`zrem <key> <value>`|移除指定值|
|`zincrby <key> <increment> <value>`|给指定值的分数加上增量 increment|
|`zrange <key> start stop`|获取区间里的所有值|
|`zrangebyscore <key> start stop [withscores] [limit]`|通过分数段获取范围内的值|
|`zcount <key> start stop`|获取分数段内的数量|
|`zrank <key> <value>`|根据分数获取指定值的排名|
