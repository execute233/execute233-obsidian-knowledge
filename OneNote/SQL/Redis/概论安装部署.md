# 概论安装部署

Redis 是一个开源的键值存储数据库,所有的数据全部存放在内存中,它的性能大大高于磁盘 IO,并且它也可以支持数据持久化,他还支持横向扩展、主从复制等。

## 安装

- Linux:直接 `sudo apt install redis-server`
- Windows:网上找安装包解压即用,`redis-server.exe` 是启动程序

## 配置外网访问

在配置文件里:

- 删除 `bind 127.0.0.1`
- 将 `protected-mode` 改为 `no`
