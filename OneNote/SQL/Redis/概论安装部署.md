# 概论安装部署

> Redis 是一种键值存储数据库,作为 NoSQL 的一种,详见 [[NoSQL/NoSQL概述|NoSQL概述]]。

Redis 是一个开源的键值存储数据库,所有的数据全部存放在内存中,它的性能大大高于磁盘 IO,并且它也可以支持数据持久化 (见 [[Redis/持久化|持久化]]),他还支持横向扩展、主从复制 (见 [[Redis/主从复制|主从复制]]) 等。

## 安装

- Linux:直接 `sudo apt install redis-server`,详情见 [[liunx/linux命令/软件安装|软件安装]]
- Windows:网上找安装包解压即用,`redis-server.exe` 是启动程序

服务管理使用 `systemctl`,详见 [[liunx/linux命令/系统操作相关|系统操作相关]]。

## 配置外网访问

在配置文件里:

- 删除 `bind 127.0.0.1`
- 将 `protected-mode` 改为 `no`
