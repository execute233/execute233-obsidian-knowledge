在Redis下，数据库是由一个整数索引标识，而不是由一个数据库名称。默认情况下，我们连接Redis数据库之后，会使用0号数据库，我们可以通过Redis配置文件中的参数来修改数库总数，默认为16个。
可以通过以下语句进行切换：
select 序号;
数据操作
添加数据
set <key> <value>
setex <key> <seconds> <value> 设置过期时间
setnx <key> <value> 只有key不存在时才会设置值
一次添加多个
mset <key1> <value1><key2> <value2>
然后可以通过key获取存入的值
get <key>
支持数据的过期时间设定
set <key> <value> EX 秒
set <key> <value> PX 毫秒
也可以单独对其他的键值对设置过期时间
expire <key> 秒
查询键值对还有多久过期(秒)(毫秒)
ttl <key>
pttl <key>
键值对转为永久
persist <key>
删除数据
del <key>
查看所有的键(可以通配符匹配)
keys *
查询某个键是否存在
exists <key>…
随机拿一个键
randomkey
将一个数据库中的内容移动到另一个数据库中
move <key> 数据库序号
修改一个键为另一个键(不检查是否已经存在)(会检查)
rename <key> <新的名称>
renamenx <key> <新的名称>
如果存放的是数值，可以自增自减操作(自增1)(自增b)(自减1)(自减b)
incr <key>
incr <key> b
decr <key>
decrby <key>
查看数据类型
type <key>
