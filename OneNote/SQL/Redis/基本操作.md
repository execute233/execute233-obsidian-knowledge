# 基本操作

在 Redis 下,数据库是由一个整数索引标识,而不是由一个数据库名称。默认情况下,我们连接 Redis 数据库之后,会使用 0 号数据库,我们可以通过 Redis 配置文件中的参数来修改数据库总数,默认为 16 个。

可以通过以下语句进行切换:

```bash
select 序号;
```

## 数据操作

### 添加数据

```bash
set <key> <value>
setex <key> <seconds> <value>  -- 设置过期时间
setnx <key> <value>            -- 只有 key 不存在时才会设置值
```

一次添加多个:

```bash
mset <key1> <value1> <key2> <value2>
```

### 获取数据

```bash
get <key>
```

### 设置过期时间

```bash
set <key> <value> EX 秒
set <key> <value> PX 毫秒
```

也可以单独对其他的键值对设置过期时间:

```bash
expire <key> 秒
```

查询键值对还有多久过期(秒/毫秒):

```bash
ttl <key>
pttl <key>
```

键值对转为永久:

```bash
persist <key>
```

### 删除数据

```bash
del <key>
```

### 查询操作

```bash
keys *              -- 查看所有的键(可以通配符匹配)
exists <key>...     -- 查询某个键是否存在
randomkey           -- 随机拿一个键
move <key> 数据库序号 -- 将一个数据库中的内容移动到另一个数据库中
type <key>          -- 查看数据类型
```

### 重命名

```bash
rename <key> <新的名称>   -- 修改一个键为另一个键(不检查是否已经存在)
renamenx <key> <新的名称> -- 修改一个键为另一个键(会检查)
```

### 数值自增自减

如果存放的是数值,可以自增自减操作:

```bash
incr <key>       -- 自增 1
incrby <key> b   -- 自增 b
decr <key>       -- 自减 1
decrby <key> b   -- 自减 b
```
