# 事务和锁

## 事务

同 MySQL 一样,也有事务机制。

|命令|说明|
|---|---|
|`multi`|开启事务|
|`exec`|执行事务|
|`discard`|取消事务|

实际上整个事务是创建了一个命令队列,它不像 MySQL 那种在事务中也能单独得到结果,而是我们提前将所有的命令装在队列中,但是并不会执行,而是等我们提交事务的时候再统一执行。

## 锁

虽然 Redis 中也有锁机制,但是它是一种乐观锁,不同于 MySQL,MySQL 中的锁是悲观锁,那么什么是乐观锁什么是悲观锁呢?

- **悲观锁**:时刻认为别人会来抢占资源,禁止一切外来访问,直到释放锁,具有强烈的排他性质。
- **乐观锁**:并不认为会有人来抢占资源,所以会直接对数据进行操作,在操作时再去验证是否有其他人抢占资源。

`watch` 与 `unwatch` 可指定值的监视,如果接下来有事务执行前目标被修改,则取消本次事务。
