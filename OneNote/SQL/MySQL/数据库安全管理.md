# 数据库安全管理

> 用户授权与权限管理是 [[SQL语句/DCL数据控制]] 的具体实现。与 [[MySQL/管理]] 同属 DBA 日常运维工作 (字符集、校对规则、权限等)。MySQL 用户概念对应 Linux 用户,详见 [[liunx/linux命令/用户 用户组 权限]]。

## 用户管理

### 添加用户

```sql
CREATE USER [IF NOT EXISTS] 'username'[@'address']
[IDENTIFIED [WITH AUTH_PLUGIN] BY 'password'|RANDOM PASSWORD]
[WITH resource_option [resource_option] …]
[password_option]
```

### 查看用户

```sql
SELECT * FROM mysql.user;
```

### 重命名用户

```sql
RENAME USER 'name' TO 'new_name';
```
