# 数据类型

> 本篇是 MySQL 数据类型总览。[[MySQL/函数|函数]] 中各字符串/日期函数的操作对象依赖于这些类型。索引建立与字段类型密切相关,详见 [[MySQL/索引|索引]]。Redis 中键值数据均为字符串,与 [[Redis/数据类型|数据类型]] 不同。

## 数字

|数据类型|字节数|取值范围|
|---|---|---|
|TINYINT|1|-128 ~ 127|
|SMALLINT|2|-32 768 ~ 32 767|
|MEDIUMINT|3|-8 388 608 ~ 8 388 608|
|INT|4|-2 147 483 648 ~ 2 147 483 647|
|BIGINT|8|-9 223 372 036 854 775 808 ~ 9 223 372 036 854 775 807|

可以:

```sql
CREATE TABLE my_Int (
    int_1 INT(3) ZEROFILL,
    int_2 TINYINT(6) UNSIGNED ZEROFILL
);
```

指定显示宽度,使用零填充(不能负数)。

## 浮点数

|数据类型|字节数|取值范围|
|---|---|---|
|FLOAT|4|0 和 1.175 494 351E-38 ~ 3.402 823 466E+38|
|DOUBLE|8|0 和 2.225 073 858 507 201 4E-308 ~ 1.797 693 134 862 315 7E+308|

## 定点数

定点数类型(DECIMAL)通过 `DECIMAL(M, D)` 设置位数和精度,其中:

- `M` 表示数字总位数(不包括 `.` 和 `-`),最大值为 65,默认值为 10。
- `D` 表示小数点后的位数,最大值为 30,默认值为 0。

## BIT

存储二进制数据。

## 时间和日期类型

|数据类型|取值范围|日期格式|
|---|---|---|
|YEAR|1901 ~ 2155|YYYY|
|DATE|1000-01-01 ~ 9999-12-31|YYYY-MM-DD|
|TIME|-838:59:59 ~ 838:59:59|HH:MM:SS|
|DATETIME|1000-01-01 00:00:00 ~ 9999-12-31 23:59:59|YYYY-MM-DD HH:MM:SS|
|TIMESTAMP|1970-01-01 00:00:01 ~ 2038-01-19 03:14:07|YYYY-MM-DD HH:MM:SS|

## 字符串

|数据类型|类型说明|
|---|---|
|CHAR|固定长度字符串|
|VARCHAR|可变长度字符串|
|TEXT|大文本数据|
|ENUM|枚举类型|
|SET|字符串对象|
|BINARY|固定长度的二进制数据|
|VARBINARY|可变长度的二进制数据|
|BLOB|二进制大对象(Binary Large Object)|
