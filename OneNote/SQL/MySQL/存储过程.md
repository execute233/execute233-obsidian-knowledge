# 存储过程

> 存储过程执行多条 SQL 语句,需依赖 [[SQL语句/DDL数据定义]] 创建的表结构。过程中常包含 [[SQL语句/DML数据操作]] 的 INSERT/UPDATE/DELETE 语句,与 [[MySQL/触发器]] 同样响应数据变更但更主动。

存储过程是执行多条 SQL 语句,是多条 SQL 语句的执行者。

## 创建存储过程

```sql
CREATE PROCEDURE 存储过程名称([参数列表])
BEGIN
    -- ...
END;
```

## 执行存储过程

```sql
CALL 存储过程名称([参数列表]);
```
