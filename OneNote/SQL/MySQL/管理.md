# 管理

## 字符集与校对规则

```sql
SHOW CHARACTER SET;                          -- 查看支持的所有字符集
SHOW COLLATION;                              -- 查看所有支持的校对规则
SHOW VARIABLES LIKE 'character%';            -- 查看各个级别的默认字符配置
SHOW VARIABLES LIKE 'collation%';            -- 查看校对规则在各个级别的默认配置
```
