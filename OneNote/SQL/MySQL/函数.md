# 函数

## 聚集函数

聚集函数一般用作统计,包括:

|函数|说明|
|---|---|
|`count([distinct] *)`|统计所有的行数(distinct 表示去重再统计)|
|`count([distinct] 列名)`|统计某列的值总和|
|`sum([distinct] 列名)`|求一列的和(注意必须是数字型的)|
|`avg([distinct] 列名)`|求一列的平均值(注意必须是数字类型)|
|`max([distinct] 列名)`|求一列的最大值|
|`min([distinct] 列名)`|求一列的最小值|

一般聚集函数是这样使用的:

```sql
SELECT count(distinct 列名) FROM 表名 WHERE 条件;
```

## 字符串函数

|函数|说明|
|---|---|
|`substring(字符串, 起始位置, 结束位置)`|截取字符串,注意下标是从 1 开始|
|`left(字符串, 长度)`|从左向右截取字符串|
|`right(字符串, 长度)`|从右向左截取字符串|
|`upper(字符串)`|转大写|
|`lower(字符串)`|转小写|
|`replace(字符串, 原文, 替换文)`|替换字符串|
|`concat(字符串1, 字符串2)`|拼接字符串|
|`length(字符串)`|字符串长度|

## 日期函数

|函数|说明|
|---|---|
|`date_add(日期, INTERVAL 增量 单位)`|快速计算日期往后推|
|`datediff(日期1, 日期2)`|计算日期间隔天数|
|`curdate()`|当前日期|
|`curtime()`|当前时间|
|`now()`|当前日期+时间|
|`day(日期)`|取出日|
|`month(日期)`|取出月|
|`year(日期)`|取出年|

## 流程控制函数

|函数|说明|
|---|---|
|`if(条件表达式, 值1, 值2)`|跟三元运算符差不多|
|`ifnull(值1, 值2)`|值 1 为 NULL 则返回值 2,否则返回 NULL|
|`nullif(值1, 值2)`|如果值 1 与值 2 相等,则返回 NULL|
|`isnull(值)`|判断是否为 NULL|

有以下的流程控制语句:

```sql
IF [NOT] EXISTS(语句) THEN
    -- ...
ELSE
    -- ...
END IF;
```
