# 索引

当数据量变得非常庞大时,可以创建索引来提高查询效率。

> 索引建立与字段的 [[MySQL/数据类型|数据类型]] 密切相关(列宽越小、类型越简单效率越高),索引是 [[MySQL/事务|事务]] 一致性 (ACID) 的关键实现手段之一。索引相关统计查询见 [[MySQL/函数|函数]] 的 `count/EXPLAIN` 等。

## 创建索引

```sql
CREATE INDEX 索引名称 ON 表名(列名);
```

## 查看索引

```sql
SHOW INDEX FROM 表名;
```

## 删除索引

```sql
DROP INDEX 索引名称 FROM 表名;
```

> 与 Java 的 HashMap 类似,都是用于 O(1) 快速定位的结构,详见 [[java/javaSE/JUC-并发容器|JUC-并发容器]]。
