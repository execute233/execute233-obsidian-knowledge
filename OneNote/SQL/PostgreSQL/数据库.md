# 数据库

## 基本建库

```sql
CREATE DATABASE "db_name"
WITH
    ENCODING = 'UTF8'
    LC_COLLATE = 'en_US.UTF-8'
    LC_CTYPE   = 'en_US.UTF-8'
    TEMPLATE   = template0;
```

## 常用命令

|命令|说明|
|---|---|
|`\c xxx`|切换数据库|
|`\l`|列出所有数据库|
|`\dt`|列出当前数据库的所有表|
|`\d table_name`|查看表结构|
