# 配置

- 默认端口:5432
- 程序名称:`postgres`
- 默认用户名:`postgres`
- 连接程序:`psql`

## Linux 下安装

先更新仓库:

```bash
sudo apt install -y postgresql-common
sudo /usr/share/postgresql-common/pgdg/apt.postgresql.org.sh
```

然后下载:

```bash
apt install postgresql-18
```
