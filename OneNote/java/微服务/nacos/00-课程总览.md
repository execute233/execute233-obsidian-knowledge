# Nacos 课程总览

这套笔记以 Linux 部署和 Java 实战为主，按 Nacos 3.2.4 串起服务发现、配置管理、集群原理及 MCP / Prompt 使用。

## 版本基线

| 项目 | 本课程选择 |
| --- | --- |
| 版本核对时间 | <code>2026-10-03</code> |
| Nacos Server / Console | 最新稳定发布 <code>3.2.4</code> |
| 操作环境 | Linux / macOS（sh 脚本）、64 位 JDK 17+ |
| Spring Boot / Cloud / Alibaba | <code>4.0.0 / 2025.1.0 / 2025.1.0.0</code> |
| Spring 工程中的 Nacos Client | BOM 管理的 <code>3.1.1</code> |
| MCP Java SDK | <code>2.0.1</code> |

Server 固定为最新稳定版；Spring 依赖使用官方明确列出的版本组合。后续升级先看 [[14-版本升级与旧文纠偏|升级与迁移]]，不独立替换某个 BOM 或 Client 版本。
