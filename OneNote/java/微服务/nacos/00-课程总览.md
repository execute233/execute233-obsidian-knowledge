# Nacos 课程总览

这套笔记以 Windows 原生部署和 Java 实战为主，按 Nacos 3.2.4 串起服务发现、配置管理、集群原理及 MCP / Prompt 使用。

> [!abstract]
> 课程重点：先跑通单机和服务调用，再理解配置、集群与恢复，最后完成 AI 资源实操。

## 版本基线

| 项目 | 本课程选择 |
| --- | --- |
| 版本核对时间 | <code>2026-10-03</code> |
| Nacos Server / Console | 最新稳定发布 <code>3.2.4</code> |
| 操作环境 | Windows、PowerShell 7、64 位 JDK 17+ |
| Spring Boot / Cloud / Alibaba | <code>4.0.0 / 2025.1.0 / 2025.1.0.0</code> |
| Spring 工程中的 Nacos Client | BOM 管理的 <code>3.1.1</code> |
| MCP Java SDK | <code>2.0.1</code> |

Server 固定为最新稳定版；Spring 依赖使用官方明确列出的版本组合。后续升级先看 [[14-版本升级与旧文纠偏|升级与迁移]]，不独立替换某个 BOM 或 Client 版本。

## 示例占位符

本文及各课面向公开阅读。尖括号中的大写名称是**待填写的占位符**，运行前替换；<code>${...}</code> 和 <code>System.getenv(...)</code> 则从读者自己的环境变量读取值。

| 占位符 / 环境变量 | 填写内容 |
| --- | --- |
| <code>&lt;JDK_DIR&gt;</code> | JDK 安装目录 |
| <code>&lt;TOOLS_DIR&gt;</code> | 下载与解压的工具目录 |
| <code>&lt;NACOS_DIR&gt;</code> | 解压后的 Nacos 根目录，含 bin / conf / target |
| <code>&lt;NACOS_HOST&gt;</code> | 客户端可达的 Nacos 主机名或 IP |
| <code>&lt;NACOS_NODE_1_HOST&gt;</code> 等 | 集群各节点的内网地址 |
| <code>&lt;PRODUCT_HOST&gt;</code> / <code>&lt;ORDER_HOST&gt;</code> | 商品 / 订单应用地址 |
| <code>&lt;INSTANCE_HOST&gt;</code> / <code>&lt;MCP_HOST&gt;</code> | 注册实例 / MCP 服务的可达地址 |
| <code>&lt;MCP_TARGET_IP_OR_CIDR&gt;</code> | MCP 工具导入允许访问的目标 IP 或网段 |
| <code>&lt;MYSQL_HOST&gt;</code> / <code>&lt;MYSQL_DATABASE&gt;</code> | MySQL 地址 / Nacos 专用数据库名 |
| <code>&lt;MYSQL_USERNAME&gt;</code> / <code>&lt;MYSQL_PASSWORD&gt;</code> | 数据库账号 / 密码 |
| <code>&lt;DEV_NAMESPACE_ID&gt;</code> / <code>&lt;PROD_NAMESPACE_ID&gt;</code> | 控制台创建的命名空间 ID |
| <code>&lt;NACOS_TOKEN_SECRET_BASE64&gt;</code> | 读者自行生成的签名密钥，不是登录 Token |
| <code>&lt;NACOS_IDENTITY_KEY&gt;</code> / <code>&lt;NACOS_IDENTITY_VALUE&gt;</code> | 集群统一的内部身份配置 |
| <code>NACOS_SERVER_ADDR</code> | Server 地址，格式为主机:主端口，集群可用逗号分隔 |
| <code>NACOS_HTTP_BASE_URL</code> | HTTP API 基础地址，包含协议、主端口与上下文路径 |
| <code>NACOS_USERNAME</code> / <code>NACOS_PASSWORD</code> / <code>NACOS_ACCESS_TOKEN</code> | 读者自己的凭据，不填写进公开文章 |

示例中的服务名、包名、演示订单和标准端口仅用于说明技术流程；主机、目录、命名空间 ID 与凭据由读者按环境填写。

## 建议学习顺序

1. 先读 01—03，完成本机 Nacos 启动和账号授权。
2. 跑 04—05，验证商品 / 订单调用和不重启配置刷新。
3. 学 06—10，定位身份与权限问题，理解故障恢复与集群条件。
4. 保留默认 AI 功能模式，完成 11—13 的工具调用与模板读取。
5. 用 14 了解版本迁移、升级验证和回退限制。

本课程的完整实操是单机；集群课提供三节点配置与验证思路。MCP 工具调用与 Prompt 读取不需要购买模型 API，也不会自动向模型发送请求。

## 练习验收

| 练习 | 可以观察到的结果 |
| --- | --- |
| 单机启动 | Console 可登录，主端口和 SDK gRPC 可达 |
| 服务注册 | 同一商品服务下显示 <code>9001 / 9002</code> 两个实例 |
| 服务调用 | 订单接口能返回某个商品实例的结果 |
| 配置刷新 | 修改 <code>demo.message</code> 后接口返回新内容 |
| 环境隔离 | 两个 Namespace 的同名资源分别读取 |
| MCP | Nacos 发现 <code>product-mcp</code>，工具返回演示商品 |
| Prompt | 查询到已发布版本，标签切换后重新读取新内容 |
