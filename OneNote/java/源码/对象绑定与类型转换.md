# 对象绑定与类型转换

## 第一套底层转换接口

![[_assets/对象绑定与类型转换/对象绑定与类型转换__09-26-41-0.png]]

- Printer 把其它类型转为 String
- Parser 把 String 转为其它类型
- Formatter 综合 Printer 与 Parser 功能
- Converter 把类型 S 转为类型 T
- Printer、Parser、Converter 经过适配转换成 GenericConverter 放入 Converters 集合
- FormattingConversionService 利用其它它们实现转换

## 第二套底层转换接口

![[_assets/对象绑定与类型转换/对象绑定与类型转换__09-26-46-1.png]]

- PropertyEditor 把 String 与其它类型相互转换
- PropertyEditorRegistry 可以注册多个 PropertyEditor 对象
- 与第一套接口直接可以通过 FormatterPropertyEditorAdapter 来进行适配

## 高层转换接口

![[_assets/对象绑定与类型转换/对象绑定与类型转换__09-26-48-2.png]]

- 它们都实现了 TypeConverter 这个高层转换接口，在转换时，会用到 TypeConverter Delegate 委派 ConversionService 与 PropertyEditorRegistry 真正执行转换（Facade 门面模式）
    - 首先看是否有自定义转换器，`@InitBinder` 添加的即属于这种（用了适配器模式把 Formatter 转为需要的 PropertyEditor）
    - 再看有没有 ConversionService 转换
    - 再利用默认的 PropertyEditor 转换
    - 最后有一些特殊处理
- SimpleTypeConverter 仅做类型转换
- BeanWrapperImpl 为 bean 的属性赋值，当需要时做类型转换，走 Property
- DirectFieldAccessor 为 bean 的属性赋值，当需要时做类型转换，走 Field
- ServletRequestDataBinder 为 bean 的属性执行绑定，当需要时做类型转换，根据 directFieldAccess 选择走 Property 还是 Field，具备校验与获取校验结果功能

```java
// 仅有类型转换功能
SimpleTypeConverter typeConverter = new SimpleTypeConverter();
Integer number = typeConverter.convertIfNecessary("13", int.class);
Date date = typeConverter.convertIfNecessary("1999/03/04", Date.class);
```

```java
// 走 setters，给 bean 属性赋值
MyBean target = new MyBean();
BeanWrapperImpl wrapper = new BeanWrapperImpl(target);
wrapper.setPropertyValue("name", "张三");
wrapper.setPropertyValue("age", "10"); // 类型不一致会转换
```

```java
// 利用反射直接给（私有）字段赋值
target = new MyBean();
DirectFieldAccessor accessor = new DirectFieldAccessor(target);
accessor.setPropertyValue("name", "张三");
accessor.setPropertyValue("age", "10"); // 类型不一致也会转换
```

```java
// 执行数据绑定
target = new MyBean();
DataBinder binder = new DataBinder(target);
binder.initDirectFieldAccess(); // 可以是有成员变量赋值(如果不存在 setter)
MutablePropertyValues pvs = new MutablePropertyValues();
pvs.add("name", "张三");
pvs.add("age", "10");
```

## 自定义类型转换器

```java
MockHttpServletRequest request = new MockHttpServletRequest();
MyBean target = new MyBean();
```

### 1、用工厂，无转换功能

```java
ServletRequestDataBinderFactory factory = new ServletRequestDataBinderFactory(null, null);
ServletRequestDataBinder dataBinder = factory.createBinder(new ServletWebRequest(request), target, "name");
```

### 2、使用 @InitBinder 转换

`@InitBinder` 在 Controller 中的用法见 [[ControllerAdvice之@InitBinder]]。

```java
InvocableHandlerMethod method =
    new InvocableHandlerMethod(new MyController(), MyController.class.getMethod("initBinder", WebDataBinder.class));
ServletRequestDataBinderFactory factory = new ServletRequestDataBinderFactory(null, null);
WebDataBinder dataBinder = factory.createBinder(new ServletWebRequest(request), target, "name");
```

### 3、使用 ConversionService 转换

```java
FormattingConversionService service = new FormattingConversionService();
service.addFormatter(new MyDateFormatter());

ConfigurableWebBindingInitializer initializer = new ConfigurableWebBindingInitializer();
initializer.setConversionService(service);
ServletRequestDataBinderFactory factory = new ServletRequestDataBinderFactory(null, initializer);
```

### 4、同时使用 @InitBinder 和 ConversionService 转换

会优先用 @InitBinder 注册的转换器，优先级更高。

```java
InvocableHandlerMethod method =
    new InvocableHandlerMethod(new MyController(), MyController.class.getMethod("initBinder", WebDataBinder.class));

FormattingConversionService service = new FormattingConversionService();
service.addFormatter(new MyDateFormatter());

ConfigurableWebBindingInitializer initializer = new ConfigurableWebBindingInitializer();
initializer.setConversionService(service);
ServletRequestDataBinderFactory factory = new ServletRequestDataBinderFactory(List.of(method), initializer);
```

### 使用默认的 ConversionService 转换

对于特殊的日期，需要在 `@DateTimeFormat`，这样就会自动添加转换器。

```java
DefaultFormattingConversionService service = new DefaultFormattingConversionService();
// SpringBoot 可以用这个
// ApplicationConversionService service = new ApplicationConversionService();

ConfigurableWebBindingInitializer initializer = new ConfigurableWebBindingInitializer();
initializer.setConversionService(service);

ServletRequestDataBinderFactory factory = new ServletRequestDataBinderFactory(null, initializer);
WebDataBinder dataBinder = factory.createBinder(new ServletWebRequest(request), target, "user");
dataBinder.bind(new ServletRequestParameterPropertyValues(request));
```

### 1、使用 @InitBinder 转换，传给 factory 让它回调方法

```java
static class MyController {
    @InitBinder // 扩展 dataBinder 转换器
    public void initBinder(WebDataBinder binder) {
        // 添加自定义转换器
        binder.addCustomFormatter(new MyDateFormatter());
    }
}

static class MyDateFormatter implements Formatter<LocalDateTime> {
    private static final DateTimeFormatter formatter = DateTimeFormatter.ofPattern("yyyy|MM|dd");

    @Override
    public LocalDateTime parse(String text, Locale locale) throws ParseException {
        return LocalDateTime.parse(text, formatter);
    }

    @Override
    public String print(LocalDateTime object, Locale locale) {
        return formatter.format(object);
    }
}
```

## 获取泛型参数

### JDK 方法

```java
// 拿到带有泛型信息的父类，另一个 getSuperClass 是没有泛型信息的
Type type = MyDateFormatter.class.getGenericSuperclass();
if (type instanceof ParameterizedType) {
    // 我们要加判断，看是不是泛型父类
    // 获取泛型参数
    Type argument = ((ParameterizedType) type).getActualTypeArguments()[0];
}
```

### Spring 中有封装

```java
Class<?> aClass = GenericTypeResolver.resolveTypeArgument(MyDateFormatter.class, Formatter.class);
```
