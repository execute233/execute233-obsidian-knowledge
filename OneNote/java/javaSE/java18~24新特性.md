# java18~24新特性

## 虚拟线程

比传统的线程更加轻量化,其执行器类似于 [[JUC-线程池]] 中的线程池,但每个平台线程可以管理多个虚拟线程。

```java
// 开个虚拟线程执行器,类似于线程池,但每个线程管理多个虚拟线程
// 在一个虚拟线程等待时,其管理的线程会执行其他的线程,直到等待结束
try (var executor = Executors.newVirtualThreadPerTaskExecutor()) {
    while (xxx) {
        executor.submit(() -> {
            // ...
        });
    }
}

// 直接创建虚拟线程
Thread.ofVirtual().start(() -> {
    // ...
});
```

## 加强版 switch 模式匹配

类似于 [[java9~17新特性]] 中增强的 switch,可对多个类型进行匹配:

```java
public String processMessage(Object message) {
    return switch (message) {
        case String text -> "text" + text;
        case Integer num -> "num" + num;
        default -> "unknown";
    };
}
```
