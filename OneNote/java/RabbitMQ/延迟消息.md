生产者发送消息时指定一个时间，消费者不会你可收到消息，而是在指定时间之后才收到消息
**死信交换机**
当队列满足下列情况之一时，就会成为死信

- 消费者使用basic.reject或basic.nack声明消费失败，并且requeue参数为false
- 消息是一个过期消息（达到了队列或消息设置的过期时间），超时无人消费
- 要投递的队列消息堆积满了，最早的消息肯呢个成为死信

队列通过dead-letter-exchange指定了交换机，那么该队列中的死信会投递到这个交换机中。该交换机成为死信交换机(DLX)
发送消息指定expiration参数即可设置消息的过期时间（毫秒 ）

延迟消息插件
当消息投递到交换机后可以暂存一定时间，到期后再投递到队列
下载相关插件放在plugins目录后启用
rabbitmq-plugins enable rabbitmq_delayed_message_exchange
然后就可以配置

![[_assets/延迟消息/延迟消息__09-23-00-1.png]]

发送消息需要通过消息头x-delay来设置过期时间，java代码里可以
template.convertAndSend("1", "mysql.1", "hello world!", message -\> {
message.getMessageProperties().setDelayLong(30000L);
return message;
});
