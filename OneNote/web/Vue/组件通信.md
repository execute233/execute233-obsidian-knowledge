# Vue 组件通信

## 一、`props`（父传子）

```html
<!-- 父组件 -->
<Child :title="msg" :count="1" />
```

```html
<!-- 子组件 -->
<script setup lang="ts">
defineProps<{
  title: string
  count?: number
}>()
</script>
```

> `props` 是只读的，子组件不能直接修改；想要反向传递需要触发事件。

## 二、自定义事件（子传父）

事件名推荐使用 `kebab-case` 风格：

```html
<!-- 子组件 -->
<script setup lang="ts">
const emit = defineEmits<{
  (e: 'update', value: string): void
}>()

emit('update', 'hello')
</script>
```

```html
<!-- 父组件 -->
<Child @update="onUpdate" />
```

## 三、mitt（任意组件通信）

`mitt` 是一个 200 字节的事件总线，适合小型项目。

```bash
npm i mitt
```

一般放在 `src/utils/emitter.ts`：

```ts
import mitt from 'mitt'

type Events = {
  'update-user': { id: number }
  'logout': undefined
}

const emitter = mitt<Events>()

export default emitter
```

常用方法：

| 方法 | 作用 |
| --- | --- |
| `emitter.all` | 拿到所有绑定的事件 |
| `emitter.emit(name, payload)` | 触发事件 |
| `emitter.off(name, fn)` | 解绑事件 |
| `emitter.on(name, fn)` | 绑定事件 |

使用：

```ts
import emitter from '@/utils/emitter'

emitter.on('update-user', ({ id }) => console.log(id))
emitter.emit('update-user', { id: 1 })
```

> 一般在 `onUnmounted` 中解绑事件，避免内存泄漏。

## 四、`v-model`

Vue 3 中 `v-model` 默认对应 `modelValue` prop 与 `update:modelValue` 事件。

```html
<!-- 在原生 input 上：等价 :value + @input -->
<input v-model="msg" />
<input :value="msg" @input="msg = $event.target.value" />
```

用在组件标签上：

```html
<!-- 父组件 -->
<MyInput v-model="msg" />
```

```html
<!-- 子组件 -->
<script setup lang="ts">
defineProps<{ modelValue: string }>()
const emit = defineEmits<{ (e: 'update:modelValue', value: string): void }>()

function onInput(e: Event) {
  emit('update:modelValue', (e.target as HTMLInputElement).value)
}
</script>

<template>
  <input :value="modelValue" @input="onInput" />
</template>
```

> [!info] 适用场景
> `v-model` 一般用于 UI 组件库，自定义业务组件优先考虑 props + emit。

## 五、`$attrs`（爷孙通信）

父组件传给子组件，但子组件没有声明为 `props` 的属性，会作为 `$attrs` 进入子组件，再透传到孙组件：

```html
<!-- 父组件 -->
<Child :foo="1" bar="2" />
```

```html
<!-- 子组件透传 -->
<GrandChild v-bind="$attrs" />
```

```html
<!-- 爷孙通信：孙组件里可以通过 defineProps 接收 -->
<script setup lang="ts">
defineProps<{ foo?: number; bar?: string }>()
</script>
```

> 在 `<script setup>` 中可使用 `useAttrs()` 获取。

## 六、`$refs` 与 `$parent`

```html
<!-- 父组件 -->
<Child ref="childRef" />
```

```html
<script setup lang="ts">
import { ref } from 'vue'

const childRef = ref()

function callChild() {
  childRef.value?.someMethod()
}
</script>
```

通过 `$parent` 可以访问父组件实例（不推荐滥用）。

## 七、`provide` / `inject`

祖先组件提供数据，后代组件注入：

```html
<!-- 祖先组件 -->
<script setup lang="ts">
import { provide, ref } from 'vue'

const theme = ref('dark')
provide('theme', theme)
</script>
```

```html
<!-- 后代组件 -->
<script setup lang="ts">
import { inject } from 'vue'

const theme = inject('theme', 'light')  // 默认值为 'light'
</script>
```

## 八、插槽 slot

当组件标签内有内容时，会自动放在组件的 `<slot>` 标签内：

```html
<!-- 子组件 -->
<template>
  <div class="card">
    <slot></slot>
  </div>
</template>
```

```html
<!-- 父组件 -->
<Card>这段内容会渲染到 slot 位置</Card>
```

具名插槽：

```html
<!-- 子组件 -->
<template>
  <header><slot name="header" /></header>
  <main><slot /></main>
  <footer><slot name="footer" /></footer>
</template>
```

```html
<!-- 父组件 -->
<Card>
  <template #header>标题</template>
  <p>默认插槽内容</p>
  <template #footer>底部</template>
</Card>
```

父组件想要访问子组件数据，需要在子组件用 `<slot>` 上声明 props：

```html
<!-- 子组件 -->
<template>
  <slot :user="user" />
</template>

<script setup lang="ts">
import { ref } from 'vue'
const user = ref({ name: '张三', age: 18 })
</script>
```

```html
<!-- 父组件 -->
<Child v-slot="{ user }">
  {{ user.name }} - {{ user.age }}
</Child>
```
