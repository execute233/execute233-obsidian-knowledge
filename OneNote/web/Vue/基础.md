# Vue 基础

## 快速上手

可以使用 Vite 直接创建一个 Vue 3 项目：

```bash
npm create vue@latest
cd <project-name>
npm install
npm run dev
```

也可以使用「在线演练」等工具在浏览器中体验 Vue。

## 创建一个组件

我们可以创建一个组件，这样使用（Vue 2 Options API）：

```html
<template>
  <div>{{ msg }}</div>
</template>

<script>
export default {
  data() {
    return { msg: 'Hello Vue' }
  }
}
</script>
```

## Vue 3 Composition API（拉开序幕的 `setup`）

```html
<template>
  <div>{{ msg }}</div>
</template>

<script setup lang="ts">
import { ref } from 'vue'

const msg = ref('Hello Vue 3')
</script>
```

> 右边是 `setup` 的简化写法（`<script setup>`）。

## 响应式数据

两种主要方式：`ref`（基本类型）和 `reactive`（对象类型）。

```html
<script setup lang="ts">
import { ref, reactive } from 'vue'

// 基本类型用 ref
const name = ref('张三')
const age  = ref(18)       // 响应式
const tel  = '111111'      // 注意：不是响应式

function showTel()   { alert(tel) }
function changeAge() { age.value += 1 }   // 在 JS 中修改需要 .value
</script>
```

```html
<script setup lang="ts">
import { reactive } from 'vue'

// 对象用 reactive
const person = reactive({ name: '张三', age: 18 })   // 响应式
const tel = '111111'                                 // 不是响应式

function showTel()   { alert(tel) }
function changeAge() { person.age += 1 }             // 对象直接 .age
</script>
```

要点：

- `setup` 中没有 `this`，是 `undefined`。
- 模板中使用 `ref` 不需要 `.value`。
- 如果要更新整个 `reactive` 对象，使用 `Object.assign(target, source)`，或者对 `ref` 重新赋值 `.value`。
- 解构 `reactive` 对象需要 `toRefs()`，使结果也保持响应式。

## computed 计算属性

```html
<script setup lang="ts">
import { ref, computed } from 'vue'

const firstName = ref('张')
const lastName  = ref('三')

// 计算属性：基于响应式数据派生
const fullName = computed(() => `${firstName.value}${lastName.value}`)
</script>
```

要点：

- `:value` 是变量单向流入视图层，**不能**反写回原变量。
- `v-model` 才是双向绑定。
- 模板插值 `{{ }}` 不宜过长，应使用计算属性。

## 引入外部 TS

接口、类需要写 `type` 并 `export`；变量则不需要：

```ts
// types.ts
export type User = { id: number; name: string }
export const defaultName = 'Guest'
```

```html
<script setup lang="ts">
import type { User } from './types'
import { defaultName } from './types'
</script>
```

## 模板传值

可以在模板标签里写自定义的 `key-value`，把组件内部的常量传给子组件：

```html
<!-- 父组件 -->
<UserCard :user="user" :show-actions="true" />

<!-- 子组件 -->
<script setup lang="ts">
defineProps<{ user: User; showActions?: boolean }>()
</script>
```

## 事件处理

一般使用 `@` 来监听 DOM 事件，事件名沿用 JS 原生名称。Vue 还提供了事件修饰符简化常见操作：

| 修饰符 | 作用 |
| --- | --- |
| `.stop` | 阻止事件冒泡，等价 `event.stopPropagation()` |
| `.prevent` | 阻止默认行为，等价 `event.preventDefault()` |
| `.once` | 只触发一次 |
| `.self` | 仅当事件在自身触发时执行 |

```html
<button @click.stop="handleClick">点我</button>
```

## 表单输入绑定

`v-model` 用于在表单元素与组件状态之间建立双向绑定：

```html
<input v-model="message" />
<textarea v-model="content"></textarea>

<!-- 自定义修饰符 -->
<input v-model.lazy="msg" />     <!-- change 事件触发 -->
<input v-model.number="age" />   <!-- 自动转数字 -->
<input v-model.trim="name" />    <!-- 自动去首尾空格 -->
```
