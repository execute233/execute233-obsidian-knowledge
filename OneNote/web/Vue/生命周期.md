# Vue 生命周期

## Vue 2

写在 `methods` 属性中：

| 阶段 | 钩子 |
| --- | --- |
| 创建 | `beforeCreate()` / `created()` |
| 挂载 | `beforeMount()` / `mounted()` |
| 更新 | `beforeUpdate()` / `updated()` |
| 销毁 | `beforeDestroy()` / `destroyed()` |

## Vue 3

`beforeCreate` / `created` 的逻辑对应 `setup()` 函数本身。

挂载、更新、卸载需要显式导入对应 hook：

```js
import {
  onBeforeMount,
  onMounted,
  onBeforeUpdate,
  onUpdated,
  onBeforeUnmount,
  onUnmounted,
} from 'vue'
```

| 阶段 | Hook |
| --- | --- |
| 挂载前 / 后 | `onBeforeMount` / `onMounted` |
| 更新前 / 后 | `onBeforeUpdate` / `onUpdated` |
| 卸载前 / 后 | `onBeforeUnmount` / `onUnmounted` |

## 整体流程

```
setup()
   │
   ▼
onBeforeMount ── 挂载前
   │
   ▼
   模板编译 / 渲染
   │
   ▼
onMounted ── 挂载完成（DOM 已就绪）
   │
   ▼
响应式数据变化
   │
   ▼
onBeforeUpdate ── 更新前
   │
   ▼
   DOM 更新
   │
   ▼
onUpdated ── 更新完成
   │
   ▼
组件卸载
   │
   ▼
onBeforeUnmount ── 卸载前（适合清理定时器 / 事件监听）
   │
   ▼
onUnmounted ── 卸载完成
```
