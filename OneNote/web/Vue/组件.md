## 组件基础

Vue 组件是把 UI 拆分成独立、可复用单元的核心机制。一个 `.vue` 文件通常包含：

```html
<template>
  <!-- 视图 -->
</template>

<script setup lang="ts">
// 逻辑
</script>

<style scoped>
/* 当前组件作用域的样式 */
</style>
```

## 注册方式

- **全局注册**：`app.component('MyComp', MyComp)`，任何地方可用。
- **局部注册**：在父组件里 `import` 后使用，作用域更可控。

```html
<script setup lang="ts">
import MyComp from './MyComp.vue'
</script>

<template>
  <MyComp />
</template>
```

## 关键能力

- `props` / `emits` 父子通信
- `slot` 插槽
- `defineExpose` 暴露给父组件访问的方法
- `provide` / `inject` 跨层级共享
