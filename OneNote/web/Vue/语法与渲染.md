# Vue 语法与渲染

## 模板语法

最基本的数据绑定形式是文本插值，使用双大括号：

```html
<span>Message: {{ msg }}</span>
```

要插入 HTML 需要使用 `v-html`：

```html
<div v-html="rawHtml"></div>
```

## 属性绑定

`v-bind` 用于动态绑定属性（可简写为 `:`）：

```html
<div v-bind:id="dynamicId"></div>
<div :id="dynamicId"></div>
```

布尔型属性可直接由 `true` / `false` 决定是否生效：

```html
<button :disabled="isButtonDisabled">Button</button>
```

动态绑定多个值到一个元素：

```js
const objectOfAttrs = {
  id: 'container',
  class: 'wrapper',
  style: 'background-color: green',
}
```

```html
<div v-bind="objectOfAttrs"></div>
```

## 条件渲染

```html
<h1 v-if="awesome">Vue is awesome!</h1>
<h1 v-else>Oh no 😢</h1>
<h1 v-else-if="ok">Meh</h1>
```

`v-show` 与 `v-if` 的区别：前者总是渲染节点，只切换 `display`；后者在不满足条件时不会渲染。

```html
<h1 v-show="visible">Hello</h1>
```

## 列表渲染

`v-for` 基于数组渲染列表，使用 `key` 保证唯一性以正确复用节点：

```html
<li v-for="item in items" :key="item.id">
  {{ item.message }}
</li>
```

数组添加新数据时采用就地更新，只更新新增项。

```html
<li v-for="(item, index) in items" :key="item.id">
  {{ index }} - {{ item.message }}
</li>
```

遍历对象：

```html
<li v-for="(value, key, index) in myObject">
  {{ index }}. {{ key }}: {{ value }}
</li>
```

也可以使用范围值：

```html
<span v-for="n in 10">{{ n }}</span>
```
