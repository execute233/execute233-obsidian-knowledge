# 第六课：文件路由与动态路由

### 6.1 文件即路由

| 文件 | URL |
|---|---|
| <code>src/pages/index.astro</code> | <code>/</code> |
| <code>src/pages/about.astro</code> | <code>/about</code> |
| <code>src/pages/blog/index.astro</code> | <code>/blog</code> |
| <code>src/pages/blog/[slug].astro</code> | <code>/blog/:slug</code> |
| <code>src/pages/docs/[...path].astro</code> | 任意深度 docs 路径 |

Astro 使用标准 <code>&lt;a&gt;</code> 导航，没有框架专属 Link 组件：

~~~astro
<a href="/about">关于</a>
~~~

### 6.2 静态动态路由

默认静态输出必须在构建时知道所有 URL：

~~~astro
<!-- src/pages/blog/[slug].astro -->
---
export function getStaticPaths() {
  return [
    {
      params: { slug: 'astro-islands' },
      props: { title: '理解 Astro Islands' },
    },
    {
      params: { slug: 'tailwind-v4' },
      props: { title: 'Tailwind v4 主题系统' },
    },
  ];
}

interface Props {
  title: string;
}

const { slug } = Astro.params;
const { title } = Astro.props;
---

<h1>{title}</h1>
<p>当前 slug：{slug}</p>
~~~

<code>params</code> 决定 URL，<code>props</code> 把对应数据直接交给页面。

### 6.3 按需动态路由

页面按请求渲染时，不使用 <code>getStaticPaths()</code>：

~~~astro
<!-- src/pages/products/[id].astro -->
---
export const prerender = false;

const { id } = Astro.params;
const product = await getProduct(id);

if (!product) {
  return Astro.rewrite('/404');
}
---

<h1>{product.name}</h1>
~~~

需要先安装对应部署平台的 Adapter。第 12 课会系统讲解。

### 6.4 Rest 参数

文件：

~~~text
src/pages/docs/[...path].astro
~~~

可匹配：

~~~text
/docs
/docs/astro
/docs/astro/islands
~~~

在 SSG 的 <code>getStaticPaths()</code> 中将 rest 参数设为 <code>undefined</code>，可以匹配顶层路径。

### 6.5 Redirect 与 Rewrite

- redirect：浏览器 URL 改变，通常产生 3xx。
- rewrite：显示另一个路由的内容，浏览器 URL 保持不变。

~~~astro
---
if (!Astro.cookies.has('session')) {
  return Astro.redirect('/login');
}
---
~~~

配置固定重定向：

~~~js
export default defineConfig({
  redirects: {
    '/old-blog': '/blog',
  },
});
~~~

### 6.6 路由优先级

具体静态路由通常优先于动态路由，命名参数优先于 rest 参数。不要设计彼此难以辨别的大量通配路由。
