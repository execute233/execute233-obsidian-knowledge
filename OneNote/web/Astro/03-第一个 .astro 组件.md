# 第三课：第一个 .astro 组件

### 3.1 文件结构

~~~astro
---
// Component Script / frontmatter
interface Props {
  title: string;
  featured?: boolean;
}

const { title, featured = false } = Astro.props;
const tags = ['Astro', 'TypeScript', 'Vue'];
---

<!-- Component Template -->
<article class:list={['card', { featured }]}>
  <h2>{title}</h2>

  {featured && <span>精选</span>}

  <ul>
    {tags.map((tag) => <li>{tag}</li>)}
  </ul>
</article>

<style>
  .card {
    border: 1px solid #ddd;
    padding: 1rem;
  }

  .featured {
    border-color: rebeccapurple;
  }
</style>
~~~

frontmatter 中可以：

- 导入组件、数据和样式；
- 调用 API、数据库或文件系统；
- 使用 TypeScript；
- 使用顶层 <code>await</code>；
- 处理 <code>Astro.props</code>、<code>Astro.params</code>、cookies 等。

它不会作为组件运行时代码发送到浏览器。

官方依据：[Astro components](https://docs.astro.build/en/basics/astro-components/) · [Template syntax](https://docs.astro.build/en/reference/astro-syntax/)

### 3.2 表达式规则

~~~astro
---
const user = { name: 'Momo', role: 'author' };
const posts = [
  { id: 'astro', title: '学习 Astro' },
  { id: 'tailwind', title: '学习 Tailwind' },
];
const showRole = true;
---

<h1>Hello, {user.name}</h1>

{showRole ? <p>身份：{user.role}</p> : <p>未登录</p>}

<ul>
  {posts.map((post) => (
    <li>
      <a href={'/blog/' + post.id}>{post.title}</a>
    </li>
  ))}
</ul>
~~~

> [!warning] 和 Vue 模板不同
> Astro 模板中不使用 <code>v-if</code>、<code>v-for</code>、<code>:href</code> 或 <code>@click</code>。它更接近 HTML + JSX 表达式。事件处理要使用浏览器脚本或框架 Island。

### 3.3 动态 class

~~~astro
---
const { active = false, class: className, ...rest } = Astro.props;
---

<a
  class:list={['nav-link', className, { active }]}
  {...rest}
>
  <slot />
</a>
~~~

<code>class:list</code> 接收字符串、数组、对象以及嵌套组合，并过滤 falsy 值。

### 3.4 set:html 的安全边界

~~~astro
---
const trustedHtml = '<strong>已消毒的 HTML</strong>';
---

<div set:html={trustedHtml}></div>
~~~

> [!danger]
> <code>set:html</code> 不会替你消毒内容。永远不要直接渲染不可信用户输入，否则可能产生 XSS。纯文本优先使用普通表达式或 <code>set:text</code>。

### 3.5 Astro 7 的严格 HTML

Astro 7 使用 Rust 编译器，对未闭合标签和不合法嵌套更严格：

~~~astro
<!-- 正确 -->
<section>
  <p>内容</p>
</section>
~~~

不要依赖旧版编译器自动修正：

~~~astro
<!-- 错误示意：未闭合 -->
<section>
  <p>内容
~~~

Astro 7 默认采用 JSX 风格的空白处理。两个内联元素间需要可见空格时，显式写出：

~~~astro
<span>Hello</span>{' '}<strong>Astro</strong>
~~~
