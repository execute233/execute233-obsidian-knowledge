# 第二课：安装、命令与项目结构

### 2.1 环境要求

Astro 7 当前官方要求：

- Node.js 22.12.0 或更高；
- 不支持 Node 23 这类奇数版本；
- Astro 应安装在项目本地，不应全局安装。

官方依据：[Install Astro](https://docs.astro.build/en/install-and-setup/)

### 2.2 创建项目

本课程统一使用 pnpm：

~~~bash
pnpm create astro@latest
~~~

建议向导选择：

- 模板：Empty；
- TypeScript：Strict 或 Strictest；
- 安装依赖：Yes；
- Git：Yes。

进入项目并启动：

~~~bash
cd my-astro-site
pnpm dev
~~~

默认开发地址通常是 <http://localhost:4321>。

### 2.3 常用命令

| 命令 | 用途 |
|---|---|
| <code>pnpm dev</code> | 启动开发服务器 |
| <code>pnpm build</code> | 生产构建 |
| <code>pnpm preview</code> | 本地预览生产构建 |
| <code>pnpm astro check</code> | 检查 Astro 与 TypeScript |
| <code>pnpm astro add vue</code> | 添加 Vue 集成 |
| <code>pnpm astro add tailwind</code> | 添加 Tailwind v4 |
| <code>pnpm astro add mdx</code> | 添加 MDX |
| <code>pnpm astro sync</code> | 更新 Astro 生成的类型 |

> [!tip]
> <code>preview</code> 不是部署服务器。它用于在本机检查构建产物。

### 2.4 项目结构

~~~text
my-astro-site/
├── public/
│   ├── favicon.svg
│   └── robots.txt
├── src/
│   ├── assets/
│   ├── components/
│   ├── layouts/
│   ├── pages/
│   ├── styles/
│   ├── content.config.ts
│   ├── env.d.ts
│   ├── middleware.ts
│   └── fetch.ts
├── astro.config.mjs
├── package.json
└── tsconfig.json
~~~

只有 <code>src/pages/</code> 是创建页面路由所必需的保留目录。其他目录大多是社区约定。Astro 7 中，<code>src/fetch.ts</code> 也是 Advanced Routing 的特殊入口，不要把普通请求工具随意命名为这个文件。

官方依据：[Project structure](https://docs.astro.build/en/basics/project-structure/) · [Astro 7 Advanced Routing](https://docs.astro.build/en/guides/routing/#advanced-routing)

### 2.5 src 与 public

| 位置 | Astro 会处理吗 | 典型内容 |
|---|---|---|
| <code>src/</code> | 会编译、优化、打包 | 组件、样式、图片、TypeScript |
| <code>public/</code> | 不处理，原样复制 | favicon、robots.txt、必须保留原名的文件 |

本地图片优先放 <code>src/assets/</code>，这样 Astro 才能优化。只在确实需要原样公开 URL 时放进 <code>public/</code>。

### 2.6 配置文件

~~~js
// astro.config.mjs
import { defineConfig } from 'astro/config';

export default defineConfig({
  site: 'https://example.com',
});
~~~

~~~json
{
  "extends": "astro/tsconfigs/strictest",
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["src/*"]
    }
  }
}
~~~
