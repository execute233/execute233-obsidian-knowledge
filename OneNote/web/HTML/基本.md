# HTML 基本

## meta 元属性

`<meta>` 用于设置 HTML 文档的元数据（编码、作者、视口、关键字等）。详见 [MDN：meta 元素](https://developer.mozilla.org/zh-CN/docs/Web/HTML/Reference/Elements/meta)。

## 文本相关标签

| 标签 | 含义 |
| --- | --- |
| `h1` ~ `h6` | 标题系列，数字指定级别 |
| `p` | 段落 |
| `hr` | 用水平线分隔段落 |
| `em` | 斜体，强调 |

## 特殊符号（HTML 实体）

| 实体 | 显示 |
| --- | --- |
| `&nbsp;` | 空格 |
| `&amp;` | `&` |
| `&lt;` | `<` |
| `&gt;` | `>` |
| `&quot;` | 英文双引号 |

更多实体参考 [MDN：Entity](https://developer.mozilla.org/zh-CN/docs/Glossary/Entity)。

## 行内元素与块级元素

- 块级元素：`p`、`hr`、`h1` 等，独占一行，可设置宽高。
- 行内元素：`b`、`i`、`sup`、`sub`、`u`、`s` 等，不独占一行，宽高由内容决定。
- 无语义容器：`div`（块级）、`span`（行内）。

## img 图片标签

```html
<img src="./logo.png" alt="Logo" width="100" height="50">
```

- `src`：图片路径
- `alt`：图片无法显示时的替代文本（鼠标悬浮时也会显示）
- `width` / `height`：图片宽高

## a 链接标签

```html
<a href="https://example.com" target="_blank">打开示例</a>
```

- `href`：跳转路径
- `target`：打开方式，`_blank` 新窗口，`_self`（默认）当前窗口

## video 视频标签

```html
<video src="./video.mp4" type="video/mp4" controls width="640" height="360"
       autoplay loop muted poster="./cover.jpg">
  <track src="./cn.vtt" kind="subtitles" srclang="zh" label="中文">
</video>
```

- `controls`：显示浏览器自带控制条
- `autoplay`：自动播放（通常需要 `muted`）
- `loop`：循环播放
- `muted`：静音播放
- `poster`：海报图，地址使用 URL
- `track`：字幕轨（`kind="subtitles"`）

## 列表

```html
<!-- 有序列表 -->
<ol>
  <li>第一项</li>
  <li>第二项</li>
</ol>

<!-- 无序列表 -->
<ul>
  <li>一</li>
  <li>二</li>
</ul>

<!-- 定义列表 -->
<dl>
  <dt>HTML</dt>
  <dd>超文本标记语言</dd>
</dl>
```

## 表格

```html
<table>
  <thead>
    <tr><th>姓名</th><th>年龄</th></tr>
  </thead>
  <tbody>
    <tr><td>张三</td><td>20</td></tr>
    <tr><td rowspan="2">李四</td><td>22</td></tr>
    <tr><td>23</td></tr>
  </tbody>
  <tfoot>
    <tr><td colspan="2">合计 2 人</td></tr>
  </tfoot>
</table>
```

- `thead` / `tbody` / `tfoot`：表头 / 表体 / 表尾。
- `rowspan`：跨行合并单元格。
- `colspan`：跨列合并单元格。

## iframe 嵌入框架

```html
<iframe src="https://example.com" target="_top"></iframe>
```

`target` 取值：

| 取值 | 含义 |
| --- | --- |
| `_blank` | 打开新窗口 |
| `_parent` | 在父窗口打开 |
| `_top` | 在最外层窗口打开 |

## 语义化标签
