# React 配置

## 快速创建开发环境

推荐使用 Vite 或官方脚手架 `create-react-app` 创建一个 React 项目：

```bash
# Vite 方式（推荐）
npm create vite@latest my-app -- --template react-ts
cd my-app
npm install
npm run dev

# 经典 CRA 方式
npx create-react-app my-app
```

更多创建方式可参考 [创建一个 React 应用](https://zh-hans.react.dev/learn/creating-a-react-app)。

官方学习文档：[快速入门](https://zh-hans.react.dev/learn)
API 参考：[React 参考总览](https://zh-hans.react.dev/reference/react)

## 初始代码

```jsx
// src/index.jsx
import React from 'react'
import ReactDOM from 'react-dom/client'
import App from './App'

ReactDOM.createRoot(document.getElementById('root')).render(<App />)
```

```jsx
// src/App.jsx
function App() {
  return <h1>Hello React</h1>
}

export default App
```

## 配置别名路径 `@`

使用 `craco` 配合 `craco.config.js` 可以让 `@` 指向 `src` 目录：

```bash
npm install -D @craco/craco
```

```js
// craco.config.js
const path = require('path')

module.exports = {
  webpack: {
    alias: {
      '@': path.resolve(__dirname, 'src'),
    },
  },
}
```

修改 `package.json`：

```json
{
  "scripts": {
    "start": "craco start",
    "build": "craco build"
  }
}
```

## 联想路径配置

`craco.config.js` 同样支持配置 `tsconfig.json` 的 `paths`，让 IDE 与打包器都认 `@`：

```json
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["src/*"]
    }
  }
}
```
