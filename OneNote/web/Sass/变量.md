# Sass 变量

变量一般放在文件开头，使用 `$name: 值;` 语法定义。

变量可以存储：

- 字符串
- 数组
- 颜色值
- 布尔值
- 列表
- null

使用变量时直接写 `$name` 即可。

```scss
$primary-color: #4287f5;
$font-stack: 'Helvetica', sans-serif;
$max-width: 960px;

body {
  color: $primary-color;
  font-family: $font-stack;
  max-width: $max-width;
}
```
