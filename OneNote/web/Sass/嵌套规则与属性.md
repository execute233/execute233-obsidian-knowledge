# Sass 嵌套规则与属性

## 嵌套 CSS 选择器

Sass 的嵌套语法类似 HTML 的嵌套结构。例如一个导航栏样式可以写成：

```scss
nav {
  ul {
    margin: 0;
    padding: 0;
    list-style: none;
  }
  li {
    display: inline-block;
  }
  a {
    display: block;
    padding: 6px 12px;
    text-decoration: none;
  }
}
```

## 嵌套属性

很多 CSS 属性有共同前缀，例如：

- `font-family`、`font-size`、`font-weight`
- `text-align`、`text-transform`、`text-overflow`

可以用嵌套写法让代码更紧凑：

```scss
font: {
  family: Helvetica, sans-serif;
  size: 18px;
  weight: bold;
}

text: {
  align: center;
  transform: lowercase;
  overflow: hidden;
}
```
