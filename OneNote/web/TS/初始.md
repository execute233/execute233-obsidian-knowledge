# TypeScript 初始

## 类型声明

与 Python 类似，但写在变量名后：

```ts
let str: string
```

方法需要同时声明参数类型与返回值类型：

```ts
function count(x: number, y: number): number {
  // ...
}
```

可选参数用 `?`：

```ts
function count(x: number, y?: number): number {
  // ...
}
```

## 数据类型

JS 自带的类型：

- `string`
- `number`
- `boolean`
- `null`
- `undefined`
- `bigint`
- `symbol`
- `object`（含 `Array`、`Function`、`Date`、`Error` 等）

TS 新增的类型：

| 类型 | 说明 |
| --- | --- |
| `any` | 任意类型，等于放弃检查；可赋值给任意类型 |
| `unknown` | 类型安全的 `any`，不能直接赋值给其他变量；需用 `typeof` 收窄或 `as` 断言 |
| `never` | 不能有任何值 |
| `void` | 一般用于函数返回值，表示不返回任何东西 |
| `object` | 较少用，不能存原始类型 |
| `tuple` | 固定长度与每个元素类型的数组 |
| `enum` | 类似 Java 的枚举 |
| `type` | 类型别名，相当于 `typedef` |
| `interface` | 接口，用于描述对象结构 |

```ts
let arr: [string, number]
let arr2: [string, ...number[]]

type Status = number | string
type Gender = '男' | '女'

// 交叉类型：合并两个对象属性
type Stu = Person & Kid
```

## 函数类型

可以定义指定参数签名的函数变量：

```ts
let count: (a: number, b: number) => number
count = (x, y) => { return x + y }
```

## 面向对象

对象定义有简写方式。TS 与 JS 类似，支持：

- `public` / `protected` / `private` / `readonly` 访问修饰符
- 抽象类与抽象方法（与 Java 一致）

```ts
class Person {
  public name: string = '张三'

  private say(): void {
    console.log('hello')
  }
}
```

## 泛型

定义方式与 Java 类似：

```ts
function test<T>(data: T) { /* ... */ }
```

## 类型声明文件

用于让 TS 引用外部 JS 文件，文件名一般为 `服务的ts文件名.d.ts`，例如 `jquery.d.ts`：

```ts
declare module 'jquery' {
  export function $(selector: string): any
}
```
