# CSS 字体与文本

## 字体样式

```css
font-family: 'Helvetica', 'Arial', sans-serif;
```

可以同时声明多个备选字体，浏览器按顺序匹配。还可以使用通用族关键字在不同系统上统一风格：

| 关键字 | 含义 |
| --- | --- |
| `serif` | 衬线字体 |
| `sans-serif` | 无衬线字体 |
| `monospace` | 等宽字体 |
| `cursive` | 手写字体 |
| `fantasy` | 奇幻字体 |

需要使用自定义字体时，可以用 `@font-face`：

```css
@font-face {
  font-family: genshin;
  src: url('./fonts/genshin.woff2');
}
```

### font-size

| 单位 | 说明 |
| --- | --- |
| `px` | 像素大小 |
| 预设值 | `small` / `medium` / `large` 等 |
| `em` | 相对父元素字体大小 |
| `rem` | 相对根元素（html）字体大小 |

### font-weight

字重（粗细）：

- 关键字：`lighter`、`normal`、`bold`、`bolder`
- 数字：`100` ~ `900`，常规为 `400`

### font-style

- `normal`（正常）
- `italic`（斜体）
- `oblique`（倾斜体，可加角度，如 `oblique 30deg`）

### font-color

```css
color: red;                   /* 关键字 */
color: rgb(255, 255, 255);    /* rgb */
color: #FFFFFF;               /* 16 进制 */
color: rgba(255, 255, 255, 1); /* 含 alpha 通道 */
color: #FFFFFFFF;             /* 16 进制含 alpha */
```

`rgba` 的最后一个值 `1` 表示不透明，越接近 `0` 越透明。

## 文本样式

| 属性 | 说明 |
| --- | --- |
| `text-indent` | 首行缩进，常用 `em` 表示多少字 |
| `text-align` | 对齐方式：`center` / `left` / `right` / `start` / `end` / `justify` |
| `text-decoration` | 文本修饰（可复合颜色、样式、宽度） |
| `text-transform` | 将文本转为大写或小写 |
| `line-height` | 行高，建议 `1.5` 或 `1.8`（等同 em） |
| `letter-spacing` | 字符间距 |
| `word-spacing` | 单词间距 |
| `word-break` | 换行策略，`normal` 保留单词，`break-all` 强制拆词 |
| `text-wrap` | 控制如何换行 |
| `white-space` | 空格处理策略 |

### text-decoration 组合写法

```css
text-decoration: underline wavy red 2px;
/*        线条类型    样式  颜色  粗细  */
```

线条样式可选：`dashed`（虚线）、`wavy`（波浪线）、`dotted`、`double`（双实线）。

### white-space 取值

| 取值 | 说明 |
| --- | --- |
| `pre` | 保留全部空格与换行 |
| `pre-wrap` | 同上，但超出宽度会换行 |
| `pre-line` | 不保留空格序列，但保留源代码换行与 `<br>` |
