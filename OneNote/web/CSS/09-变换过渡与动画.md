# 变换过渡与动画

## 二维变换 transform

```css
transform: translate(50px, 100px);  /* 沿 X / Y 轴移动，仅视觉移动，不影响文档流 */
transform: scale(1.5, 0.8);         /* 放大缩小，可分别控制横纵向 */
transform: rotate(45deg);           /* 旋转 */
transform: skew(20deg, 10deg);      /* 倾斜 */
```

## 原点变换 transform-origin

设置旋转、缩放等变换的原点位置，默认是元素中心：

```css
transform-origin: 0 0;        /* 左上角 */
transform-origin: center;     /* 居中 */
transform-origin: 50% 100%;   /* 底部居中 */
```

## 组合变换

可以同时叠加多个变换函数，函数之间用空格分隔，**从左到右依次应用**：

```css
transform: translate(100px, 0) rotate(45deg) scale(1.2);
```

## 三维变换

引入 `Z` 轴（垂直屏幕向外）：

```css
transform: rotateZ(45deg);                 /* 绕 Z 轴旋转 */
transform: rotateX(45deg) rotateY(30deg);  /* 绕 X / Y 轴旋转 */
transform: translateZ(50px);               /* 沿 Z 轴位移 */
```

给父元素设置 `perspective` 增加景深，让 3D 旋转更有立体感：

```css
.parent {
  perspective: 1000px;
}
```

## 透明效果

```css
opacity: 0.5;  /* 整个元素透明度，0 完全透明，1 不透明 */
```

## 过渡 transition

过渡让属性值变化时平滑渐变，需指定**过渡属性**与**时长**（否则不生效）：

```css
.box {
  transition-property: background-color;     /* 要过渡的属性，all 表示全部 */
  transition-duration: 0.3s;                /* 过渡时长 */
  transition-timing-function: ease;         /* 速度曲线 */
  transition-delay: 0s;                     /* 延迟开始 */
}
```

### 速度曲线

| 取值 | 含义 |
| --- | --- |
| `linear` | 匀速 |
| `ease` | 慢-快-慢（默认） |
| `ease-in` | 慢-快 |
| `ease-out` | 快-慢 |
| `ease-in-out` | 慢-快-慢，更平缓 |
| `cubic-bezier(...)` | 自定义贝塞尔曲线 |

简写：

```css
.box {
  transition: background-color 0.3s ease 0s;
}
```

## 动画 animation

动画用 `@keyframes` 定义关键帧，再用 `animation` 属性播放，可自定义多阶段变化。

### 定义关键帧

```css
@keyframes myfirst {
  from { background: red; }
  to   { background: yellow; }
}

@keyframes myfirst {
  0%   { background: red; }
  50%  { background: blue; }
  100% { background: green; }
}
```

### 绑定到元素

必须指定**动画名称**和**时长**，缺省时长为 0 则动画不运行：

```css
.box {
  animation-name: myfirst;
  animation-duration: 5s;
  animation-timing-function: linear;
  animation-delay: 2s;
  animation-iteration-count: infinite;   /* 播放次数，infinite 无限循环 */
  animation-direction: alternate;        /* normal / reverse / alternate 交替反向 */
  animation-fill-mode: both;             /* 动画前后应用起始/结束样式 */
}
```

### 简写

```css
.box {
  animation: myfirst 5s linear 2s infinite alternate;
  /*          名称   时长  曲线 延迟  次数   方向  */
}
```

常见循环动画示例：

```css
.spin {
  animation: rotate 2s linear infinite;
}

@keyframes rotate {
  from { transform: rotate(0deg); }
  to   { transform: rotate(360deg); }
}
```
