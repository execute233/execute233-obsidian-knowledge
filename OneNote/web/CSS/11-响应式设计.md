# 响应式设计

响应式设计让同一套页面在不同屏幕尺寸（手机 / 平板 / 桌面）上都能友好展示，核心是 viewport + 媒体查询 + 弹性布局。

## viewport 视区

手机浏览器默认把页面放在一个比屏幕宽的「虚拟窗口」中，导致页面被缩小显示。设置 viewport meta 让页面宽度等于设备宽度：

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```

| 参数 | 说明 |
| --- | --- |
| `width` | 视区宽度，`device-width` 为设备宽度 |
| `initial-scale` | 初始缩放比例，`1.0` 为 100% |
| `maximum-scale` / `minimum-scale` | 允许的最大 / 最小缩放 |
| `user-scalable` | 是否允许用户手动缩放 |

## 媒体查询 @media

`@media` 可针对不同媒体类型 / 屏幕尺寸定义不同样式：

```css
@media only screen and (max-width: 500px) {
  body {
    background-color: lightblue;
  }
}
```

### 断点写法

- `min-width`：大于等于该宽度时生效（**移动端优先**写法）
- `max-width`：小于等于该宽度时生效（**桌面优先**写法）

移动端优先示例：

```css
/* 默认：移动端 */
[class*="col-"] {
  width: 100%;
}

/* ≥768px：桌面端 */
@media only screen and (min-width: 768px) {
  .col-3 { width: 25%; }
  .col-6 { width: 50%; }
  .col-12 { width: 100%; }
}
```

常用断点：手机 `< 600px`，平板 `600px ~ 768px`，桌面 `> 768px`。

### 横屏 / 竖屏

```css
@media only screen and (orientation: landscape) {
  body { background-color: lightblue; }
}
```

`orientation` 取值：`portrait`（竖屏）/ `landscape`（横屏）。

## 响应式布局

### 弹性网格

用百分比宽度 + flex / grid 实现自适布局：

```css
.row {
  display: flex;
  flex-wrap: wrap;
}
.col {
  flex: 1;
}
```

或结合媒体查询切换列数：

```css
.grid {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
}

@media (max-width: 768px) {
  .grid {
    grid-template-columns: repeat(2, 1fr);
  }
}
```

## 响应式图片

让图片宽度不超过容器，避免溢出：

```css
img {
  max-width: 100%;
  height: auto;
}
```

按屏幕加载不同尺寸图片可用 `srcset` / `<picture>`：

```html
<img src="small.jpg" srcset="large.jpg 1024w, small.jpg 640w">
```

## 响应式视频

```css
video, iframe {
  max-width: 100%;
}
```

## 无障碍与偏好媒体特性

媒体查询还能检测用户偏好，实现无障碍优化：

```css
/* 深色模式 */
@media (prefers-color-scheme: dark) {
  body {
    background-color: #222;
    color: #eee;
  }
}

/* 用户偏好减少动效时关闭动画 */
@media (prefers-reduced-motion: reduce) {
  * {
    animation: none;
    transition: none;
  }
}
```

- `prefers-color-scheme`：检测深色 / 浅色偏好，实现暗色模式。
- `prefers-reduced-motion`：检测用户是否减少动效，可关闭动画 / 过渡。
