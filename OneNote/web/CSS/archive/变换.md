# CSS 变换

## 二维变换 transform

```css
transform: translate(50px, 100px);  /* 沿 X / Y 轴移动，仅视觉 */
transform: scale(1.5, 0.8);         /* 放大缩小，可分别控制横纵向 */
transform: rotate(45deg);           /* 旋转 */
transform: skew(20deg, 10deg);      /* 倾斜 */
```

## 原点变换 transform-origin

设置旋转、缩放等变换的原点位置，默认是元素中心。

```css
transform-origin: 0 0;        /* 左上角 */
transform-origin: center;     /* 居中 */
transform-origin: 50% 100%;   /* 底部居中 */
```

## 组合变换

可以同时叠加多个变换函数，函数之间用空格分隔，从左到右依次应用：

```css
transform: translate(100px, 0) rotate(45deg) scale(1.2);
```

## 三维变换

引入 `Z` 轴（垂直屏幕向外）：

```css
transform: rotateZ(45deg);                 /* 绕 Z 轴旋转 */
transform: rotateX(45deg) rotateY(30deg);  /* 绕 X / Y 轴旋转 */
```

给父元素设置 `perspective` 增加景深，让 3D 旋转更有立体感：

```css
.parent {
  perspective: 1000px;
}
```

## 透明效果

```css
opacity: 0.5;  /* 设置整个元素的透明度（0 完全透明，1 不透明） */
```

## 过渡效果

```css
.box {
  transition-property: background-color;     /* 要过渡的属性 */
  transition-duration: 0.3s;                /* 过渡时长 */
  transition-timing-function: ease;         /* 速度曲线 */
}
```

### 速度曲线

| 取值 | 含义 |
| --- | --- |
| `linear` | 匀速 |
| `ease` | 慢-快-慢（默认） |
| `ease-in` | 慢-快 |
| `ease-out` | 快-慢 |
| `ease-in-out` | 慢-快-慢，更平缓 |
