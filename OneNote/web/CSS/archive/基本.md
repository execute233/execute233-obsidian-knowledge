# CSS 基本

## 引入方式

CSS 一共有三种引入方式：

### 1. 行内样式

直接写在标签的 `style` 属性中：

```html
<p style="color: red">内容</p>
```

### 2. 内部样式

通过 `<style>` 标签写在 HTML 中：

```html
<style>
  p {
    color: red;
  }
</style>
```

### 3. 外部样式

通过 `<link>` 引入独立的 CSS 文件：

```html
<link rel="stylesheet" href="./style/index.css">
```

## CSS 选择器

### 基本选择器

| 选择器 | 语法 |
| --- | --- |
| 标签选择器 | `标签名 {}` |
| 类选择器（可重复） | `.类名 {}` |
| ID 选择器（不可重复） | `#id {}` |
| 通配符选择器（选中所有元素） | `* {}` |

### 交集选择器

```css
p.class_name {}                /* 选择 p 标签中指定 class 的 */
p.class_name#id {}             /* 同时指定 class 与 id */
```

### 并集选择器

一次选中多个选择器：

```css
p, div, .class_name {}
```

### 高级选择器

| 选择器 | 语法 | 说明 |
| --- | --- | --- |
| 后代选择器 | `p .class_name {}` | 选择 p 内部所有后代 |
| 子选择器 | `p > .class_name {}` | 只选嵌套一级的子元素 |
| 相邻兄弟选择器 | `p + p {}` | 选中相邻的下一个兄弟 |
| 通用兄弟选择器 | `p ~ p {}` | 选中后面所有兄弟 |

### 属性选择器

```css
[herf="xxx"] {}                /* 选择带有特定属性值的元素 */
a[herf] {}                     /* 选择带有该属性的元素 */
```

## 选择器优先级

```
行内样式 > id 选择器 > 类选择器 / 属性选择器 / 伪类 > 元素选择器 / 伪元素
```

可以使用 `!important` 强制提升优先级：

```css
text {
  color: red !important;
}
```

## 伪类选择器

依赖元素特定状态的选择器：

| 伪类 | 含义 |
| --- | --- |
| `:link` | 未访问的链接 |
| `:visited` | 已访问的链接 |
| `:hover` | 鼠标悬停时 |
| `:active` | 元素被激活（按下未松开） |
| `:focus` | 元素获得焦点 |

### 结构类伪类

| 伪类 | 含义 |
| --- | --- |
| `:first-child` | 第一个子元素 |
| `:first-of-type` | 同类型第一个子元素 |
| `:last-child` | 最后一个子元素 |
| `:nth-child(n)` | 第 n 个子元素，可用数学公式 |
| `:only-child` | 唯一的子元素 |

## 伪元素选择器

| 伪元素 | 含义 |
| --- | --- |
| `::before` | 在元素前插入内容，配合 `content` 设置 |
| `::after` | 在元素之后插入内容 |
| `::first-letter` | 控制首字母 |
| `::selection` | 文本被选中时的样式（默认蓝色） |

## 继承

子元素默认继承父级的部分样式（如文字颜色、字体）。要取消继承可以显式覆盖，或使用 `initial` 回到初始值。
