# 列表与表格样式

## 列表样式

### list-style-type 标记类型

`list-style-type` 指定列表项标记：

```css
ul.a { list-style-type: circle; }        /* 无序：disc / circle / square */
ol.c { list-style-type: upper-roman; }   /* 有序：decimal / lower-alpha / upper-roman 等 */
```

### list-style-image 图片标记

用图片作列表项标记（跨浏览器表现不一）：

```css
ul {
  list-style-image: url('./marker.png');
}
```

跨浏览器兼容做法：去掉默认标记，改用背景图定位：

```css
ul {
  list-style-type: none;
  margin: 0;
  padding: 0;
}
ul li {
  background-image: url('./marker.png');
  background-repeat: no-repeat;
  background-position: 0 5px;
  padding-left: 14px;
}
```

### 移除默认标记

导航类列表常需去除小黑点，同时清除默认内外边距：

```css
ul {
  list-style-type: none;
  margin: 0;
  padding: 0;
}
```

### list-style 简写

```css
ul {
  list-style: square url('./marker.png') inside;
  /*            type        image            position */
}
```

`list-style-position` 控制标记位置：`outside`（默认，标记在列表外）/ `inside`（标记在文本内）。

## 表格样式

### 合并边框 border-collapse

默认表格单元格间有双线边框，`border-collapse: collapse` 合并为单线：

```css
table {
  border-collapse: collapse;
  width: 100%;
}
```

### 单元格内边距与文本对齐

```css
th, td {
  padding: 8px 12px;
  text-align: left;
  border: 1px solid #ddd;
}
```

### 其他常用属性

| 属性 | 说明 |
| --- | --- |
| `border-spacing` | 单元格间距（仅 `border-collapse: separate` 时生效） |
| `caption-side` | 标题 `caption` 的位置：`top` / `bottom` |
| `vertical-align` | 单元格内容垂直对齐：`top` / `middle` / `bottom` |

### 斑马纹表格

交替行背景色，提升可读性：

```css
tbody tr:nth-child(odd) {
  background-color: #f2f2f2;
}
```
