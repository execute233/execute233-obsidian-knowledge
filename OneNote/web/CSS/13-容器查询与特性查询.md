# 容器查询与特性查询

## 容器查询 Container Queries

容器查询根据**元素容器的大小**应用样式（媒体查询根据视口大小），使组件可在不同容器中复用，无需知道放置位置。

### 创建容器上下文

在元素上声明 `container-type`，浏览器即可查询该容器的尺寸：

```css
.post {
  container-type: inline-size;   /* 基于容器行向尺寸查询 */
}
```

| 取值 | 说明 |
| --- | --- |
| `size` | 基于容器行向与块向尺度查询 |
| `inline-size` | 基于容器行向（inline）尺度查询 |
| `normal` | 不是尺寸查询容器（仍可做样式查询） |

### @container 查询

```css
.card h2 {
  font-size: 1em;   /* 默认样式 */
}

@container (min-width: 700px) {
  .card h2 {
    font-size: 2em;  /* 容器宽于 700px 时 */
  }
}
```

### 命名容器

用 `container-name` 命名后，`@container` 可指定查询哪个容器：

```css
.post {
  container-type: inline-size;
  container-name: sidebar;
}

@container sidebar (min-width: 700px) {
  .card {
    font-size: 2em;
  }
}
```

### container 简写

```css
.post {
  container: sidebar / inline-size;
  /*          名称      类型      */
}
```

### 容器查询长度单位

相对于查询容器的尺寸：

| 单位 | 含义 |
| --- | --- |
| `cqw` | 容器宽度的 1% |
| `cqh` | 容器高度的 1% |
| `cqi` | 容器行向尺寸的 1% |
| `cqb` | 容器块向尺寸的 1% |
| `cqmin` | `cqi` 与 `cqb` 中较小者 |
| `cqmax` | `cqi` 与 `cqb` 中较大者 |

```css
@container (min-width: 700px) {
  .card h2 {
    font-size: max(1.5em, 1.23em + 2cqi);
  }
}
```

### 回退方案

不支持容器查询的浏览器可用 grid/flex 实现相近效果，再用媒体查询兜底：

```css
.card {
  display: grid;
  grid-template-columns: 2fr 1fr;
}

@media (max-width: 700px) {
  .card {
    grid-template-columns: 1fr;
  }
}
```

## 特性查询 @supports

`@supports` 检测浏览器是否支持某 CSS 特性，再决定是否应用样式：

```css
@supports (display: grid) {
  .container {
    display: grid;
  }
}

@supports not (display: grid) {
  .container {
    display: flex;   /* 不支持 grid 时回退 */
  }
}
```

常用于渐进增强：新特性 + 特性查询兜底。
