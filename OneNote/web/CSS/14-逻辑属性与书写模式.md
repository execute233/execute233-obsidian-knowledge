# 逻辑属性与书写模式

## 为什么需要逻辑属性

传统 CSS 使用**实体尺度**：`width` / `height`、`top` / `left`、`margin-left` 等都是固定的物理方向。一旦改变书写模式（如竖排日文、从右到左的阿拉伯文），这些属性不会跟着文本流向变化，布局就会错乱。

**逻辑属性**把「宽/高」「左/右」「上/下」换成相对于文本流向的「行向 / 块向 / start / end」，使布局随书写模式自动适配。

## 块向与行向

- **行向（inline）**：一行文本延伸的方向。横排书写模式中为水平方向，竖排中为竖直方向。
- **块向（block）**：块（段落等）依次排列的方向，与行向垂直。

```
横排书写模式：行向 → 水平，块向 ↓ 垂直
竖排书写模式：行向 ↓ 垂直，块向 → 水平
```

## 逻辑属性映射

| 物理属性 | 逻辑属性（横排从左到右时等效） |
| --- | --- |
| `width` | `inline-size` |
| `height` | `block-size` |
| `margin-left` / `margin-right` | `margin-inline-start` / `margin-inline-end` |
| `margin-top` / `margin-bottom` | `margin-block-start` / `margin-block-end` |
| `padding-left` / `padding-right` | `padding-inline-*` |
| `padding-top` / `padding-bottom` | `padding-block-*` |
| `border-left` / `border-right` | `border-inline-*` |
| `border-top` / `border-bottom` | `border-block-*` |
| `top` / `right` / `bottom` / `left` | `inset-block-start` / `inset-inline-end` 等 |

简写：`margin-inline` / `margin-block` / `padding-inline` / `padding-block` / `inset-inline` / `inset-block` 一次设置两个方向。

### 示例

```css
.box {
  inline-size: 400px;       /* 逻辑宽度，随书写模式变化 */
  margin-inline: auto;      /* 水平居中，等价于 margin-left/right: auto */
  padding-block: 1em;       /* 上下内边距 */
  border-inline-start: 2px solid blue;   /* 起始方向边框 */
}
```

网格 / flex 对齐中的 `start` / `end` 也是相对流的：`justify-self: start` 对齐到行首。

## 书写模式

`writing-mode` 定义文本与块流的排布方向：

| 取值 | 说明 |
| --- | --- |
| `horizontal-tb` | 横排，块自上而下（默认） |
| `vertical-rl` | 竖排，块自右向左 |
| `vertical-lr` | 竖排，块自左向右 |

`direction` 控制文本方向：`ltr`（左到右，默认）/ `rtl`（右到左）。

```css
.vertical {
  writing-mode: vertical-rl;
  direction: rtl;
}
```

配合逻辑属性使用，同一套样式可在任意书写模式下正确显示。
