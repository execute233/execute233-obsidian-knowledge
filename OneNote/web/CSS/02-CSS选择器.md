# CSS 选择器

选择器用于选中需要设置样式的 HTML 元素，是 CSS 规则的第一部分。

## 基本选择器

| 选择器 | 语法 | 说明 |
| --- | --- | --- |
| 标签（元素）选择器 | `p {}` | 选中所有指定标签 |
| 类选择器 | `.center {}` | 选中所有 `class`，可重复用于多个元素 |
| ID 选择器 | `#para1 {}` | 选中指定 `id`，每个 id 页面内唯一 |
| 通配符选择器 | `* {}` | 选中所有元素 |

注意：`id` 与 `class` 名称**不能以数字开头**（在部分浏览器中不生效）。

### 类选择器进阶

类名可以指定到特定元素，也可同时使用多个类：

```css
p.center { text-align: center; }   /* 仅 class 为 center 的 p 元素 */
```

```html
<p class="center color">同时应用两个类的样式</p>
```

## 交集与并集选择器

```css
p.class_name {}              /* 交集：同时满足是 p 且带指定 class */
p.class_name#id {}           /* 同时指定 class 与 id */
p, div, .class_name {}       /* 并集：一次选中多个选择器，逗号分隔 */
```

## 组合选择符（关系选择器）

CSS3 包含四种组合方式，说明两个选择器之间的关系：

| 选择器 | 语法 | 说明 |
| --- | --- | --- |
| 后代选择器 | `div p {}` | 选中 div 内部**所有层级**的 p |
| 子选择器 | `div > p {}` | 只选 div 的**直接子元素** p |
| 相邻兄弟选择器 | `div + p {}` | 选中紧跟在 div 后、同父级的**第一个** p |
| 通用兄弟选择器 | `div ~ p {}` | 选中 div 之后**所有**同父级兄弟 p |

## 属性选择器

根据元素的属性及属性值选中：

```css
a[href] {}               /* 带有 href 属性的 a */
[href="xxx"] {}          /* 属性值完全等于 xxx */
[title^="http"] {}       /* 属性值以 http 开头（^=） */
[title$=".pdf"] {}       /* 属性值以 .pdf 结尾（$=） */
[title*="runoob"] {}     /* 属性值包含 runoob（*=） */
```

## 伪类选择器

依赖元素**特定状态**的选择器，单冒号 `:`：

| 伪类 | 含义 |
| --- | --- |
| `:link` | 未访问的链接 |
| `:visited` | 已访问的链接 |
| `:hover` | 鼠标悬停时 |
| `:active` | 元素被激活（按下未松开） |
| `:focus` | 元素获得焦点 |

### 结构类伪类

| 伪类 | 含义 |
| --- | --- |
| `:first-child` | 第一个子元素 |
| `:first-of-type` | 同类型第一个子元素 |
| `:last-child` | 最后一个子元素 |
| `:nth-child(n)` | 第 n 个子元素，可用数学公式如 `2n`、`odd` |
| `:only-child` | 唯一的子元素 |

## 伪元素选择器

用于选中元素的特定部分或在内容前后插入，双冒号 `::`：

| 伪元素 | 含义 |
| --- | --- |
| `::before` | 在元素内容前插入内容，配合 `content` 使用 |
| `::after` | 在元素内容之后插入内容 |
| `::first-letter` | 控制首字母样式 |
| `::selection` | 文本被选中时的样式（默认蓝色） |

## 选择器优先级

优先级由选择器类型决定，从高到低：

```
行内样式 > id 选择器 > 类/属性/伪类选择器 > 元素/伪元素选择器 > 通配符
```

权重参考：行内样式 1000，id 100，类/属性/伪类 10，元素/伪元素 1。权重相等时，**后出现的声明**优先；创作（作者）样式高于浏览器默认样式。

可以使用 `!important` 强制提升某条声明的优先级，但应谨慎使用，优先靠选择器本身解决：

```css
p {
  color: red !important;
}
```

## 继承

子元素默认继承父级的**部分**样式（如文字颜色、字体、文本对齐），但盒模型类属性（margin、padding、border、width/height）不继承。取消继承可显式覆盖，或使用 `initial` 回到初始值、`inherit` 强制继承：

```css
p {
  color: initial;   /* 恢复默认颜色 */
  border: inherit;  /* 强制继承父级边框 */
}
```
