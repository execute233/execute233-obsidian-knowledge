# 多列布局与滚动吸附

## 多列布局 Multicol

多列布局把内容（含所有后代）分割到一组列框中，类似报纸排版。给元素设置 `column-count` 或 `column-width` 即可成为多列容器。

### columns 定义

```css
.container {
  column-count: 3;        /* 固定 3 列 */
}

.container {
  column-width: 200px;    /* 每列最佳宽度，浏览器按容器算列数，列可能更宽 */
}

.container {
  columns: 2 200px;       /* 简写：最大 2 列，每列至少 200px */
}
```

- `column-count`：指定列数，浏览器分配空间。
- `column-width`：每列最佳宽度（视为最小宽度），可用空间多则列更宽。
- 两者同时设置时 `column-count` 为**最大列数**。

### 其他列属性

```css
.container {
  column-gap: 2em;                /* 列间距 */
  column-rule: 1px solid #ccc;    /* 列间分隔线（颜色 样式 宽度） */
  column-span: all;               /* 元素跨所有列（如标题通栏） */
  column-fill: balance;           /* 列内容平衡分配 / auto */
}
```

注意：多列容器会创建新的**块格式化上下文（BFC）**，子元素外边距不会与容器外边距合并。

## 滚动吸附 Scroll Snap

滚动吸附让滚动容器在滚动结束后停在（吸附到）指定位置，常用于轮播、横向卡片列表。

### 基础用法

在滚动容器上启用吸附，在子元素上定义吸附点：

```css
.scroller {
  height: 300px;
  overflow-y: scroll;
  scroll-snap-type: y mandatory;   /* x / y / inline / block / both */
}

.scroller section {
  scroll-snap-align: start;        /* start / end / center / none */
}
```

### scroll-snap-type

| 取值 | 说明 |
| --- | --- |
| `x` / `y` / `inline` / `block` / `both` | 吸附发生的轴 |
| `mandatory` | 必须吸附到每个点，滚动体验一致 |
| `proximity` | 靠近吸附点时吸附，距离由浏览器决定 |

**`mandatory` 慎用**：若子元素内容溢出容器，用户可能无法滚动查看全部内容。

### 偏移与停止

```css
.scroller {
  scroll-snap-type: y mandatory;
  scroll-padding: 50px;    /* 容器上：吸附偏移，为固定导航栏留空间 */
}

.scroller section {
  scroll-snap-align: start;
  scroll-margin: 40px;     /* 子元素上：吸附外边距，可为不同子元素设不同值 */
  scroll-snap-stop: normal; /* normal 可跳过 / always 必须停在此点 */
}
```

- `scroll-padding`：在容器上设置，吸附点相对容器边缘的偏移。
- `scroll-margin`：在子元素上设置，各子元素可有不同空间。
- `scroll-snap-stop`：`normal`（可越过）或 `always`（必须吸附停下）。`always` 保证用户不会错过内容，但会阻碍快速滚动。
