# 微信小程序 核心 - 布局

## 尺寸单位 rpx

由于不同手机的屏幕宽度不一样，小程序统一了以下单位：

- **`rpx`**：responsive pixel，手机宽度恒为 `750rpx`
- 没有统一的高度单位（因为内容可上下滑动）

样式上：

- `app.wxss`：全局 CSS 样式
- `xxx.wxss`：局部、当前页面的样式

## 常用组件

小程序没有 HTML 标签，组件均内置。详见 [微信开放文档 / 组件](https://developers.weixin.qq.com/miniprogram/dev/component/)。

| 组件 | 含义 | 参考 |
| --- | --- | --- |
| `text` | 行内文本（相当于 `span`，不能换行） | [text](https://developers.weixin.qq.com/miniprogram/dev/component/text.html) |
| `view` | 视图容器（相当于 `div`） | [view](https://developers.weixin.qq.com/miniprogram/dev/component/view.html) |
| `image` | 媒体组件 | [image](https://developers.weixin.qq.com/miniprogram/dev/component/image.html) |
| `icon` | 内置图标 | [icon](https://developers.weixin.qq.com/miniprogram/dev/component/icon.html) |
| `button` | 按钮 | - |
| `swiper` | 滑块视图容器，内部只能放 `swiper-item` | - |

```html
<text>我是首页</text>

<image src="/images/index.png" style="width: 100rpx; height: 100rpx;"></image>

<icon type="success" color="green"></icon>

<button size="mini" type="primary" plain>I'm button</button>

<swiper>
  <swiper-item>1</swiper-item>
  <swiper-item>2</swiper-item>
</swiper>
```

## flex 布局

flex 与小程序没有必然联系，传统的盒模型布局依赖 `display` / `position` / `float`，对垂直居中之类的特殊布局不友好。flex（弹性布局）正是为这种场景设计的。

- 采用 flex 布局的元素称为**容器（container）**，它的所有子元素自动称为**项目（item）**。
- 存在水平的主轴（main axis）与垂直的交叉轴（cross axis）。
- 主轴的开始位置（与边框的交点）叫 `main start`，结束位置叫 `main end`；交叉轴同理有 `cross start` / `cross end`。
- 项目默认沿主轴排列，单个项目占据的主轴空间为 `main size`，交叉轴空间为 `cross size`。

### 容器属性

#### flex-direction：决定主轴方向

| 取值 | 含义 |
| --- | --- |
| `row`（默认） | 主轴水平，起点在左 |
| `row-reverse` | 主轴水平，起点在右 |
| `column` | 主轴垂直，起点在上 |
| `column-reverse` | 主轴垂直，起点在下 |

#### flex-wrap：一条轴线排不下时如何换行

| 取值 | 含义 |
| --- | --- |
| `nowrap`（默认） | 不换行 |
| `wrap` | 换行 |
| `wrap-reverse` | 换行，第一行在下方 |

#### flex-flow

`flex-direction` 与 `flex-wrap` 的简写。

#### justify-content：项目在主轴上的排序方式

| 取值 | 含义 |
| --- | --- |
| `flex-start`（默认） | 左对齐 |
| `flex-end` | 右对齐 |
| `center` | 居中 |
| `space-between` | 两端对齐，项目之间的间隔相等 |
| `space-around` | 每个项目两侧的间隔相等 |
| `space-evenly` | 项目与项目、项目与边框的间隔都相等 |

#### align-items：项目在交叉轴上的对齐

| 取值 | 含义 |
| --- | --- |
| `flex-start` | 交叉轴起点对齐 |
| `flex-end` | 交叉轴终点对齐 |
| `center` | 交叉轴中点对齐 |
| `baseline` | 项目的第一行文字基线对齐 |
| `stretch`（默认） | 未设高度则占满整个容器 |

#### align-content：多根轴线的对齐方式（单根不起作用）

使用 `align-content` 时必须配合 `flex-wrap`。

| 取值 | 含义 |
| --- | --- |
| `flex-start` | 与交叉轴起点对齐 |
| `flex-end` | 与交叉轴终点对齐 |
| `center` | 与交叉轴中点对齐 |
| `space-between` | 与交叉轴两端对齐，轴线均匀分布 |
| `space-around` | 每根轴线两侧间隔都相等 |
| `stretch`（默认） | 轴线占满整个交叉轴 |

### 项目属性

| 属性 | 含义 |
| --- | --- |
| `order` | 排序，越小越靠前，默认 `0` |
| `flex-grow` | 相对放大比例（默认 `1`） |
| `flex-shrink` | 相对缩小比例；设为 `0` 时不缩 |
| `flex-basis` | 分配多余空间前项目占据的主轴空间 |
| `flex` | `flex-grow` / `flex-shrink` / `flex-basis` 的简写（建议优先使用） |
| `align-self` | 覆盖父容器 `align-items`，允许单个项目有不同对齐 |

`align-self` 取值：`auto` / `flex-start` / `flex-end` / `center` / `baseline` / `stretch`。

## 小程序里的实际例子

### 菜单布局

```html
<view class="menu">
  <view class="menu-item">
    <image src="/images/icon/home.png" class="img" />
    <text class="title">首页</text>
  </view>
  <view class="menu-item">
    <image src="/images/icon/home_selected.png" class="img" />
    <text class="title">首页</text>
  </view>
  <view class="menu-item">
    <image src="/images/icon/index.png" class="img" />
    <text class="title">索引</text>
  </view>
  <view class="menu-item">
    <image src="/images/icon/index_selected.png" class="img" />
    <text class="title">索引</text>
  </view>
</view>
```

```css
.menu {
  display: flex;
  justify-content: space-between;
  padding: 16rpx;
  border-radius: 10rpx;
  flex-wrap: wrap;
}

.menu-item {
  display: flex;
  flex-direction: column;
  justify-content: center;
  align-items: center;
  width: 150rpx;
  height: 200rpx;
  border: rgb(192, 251, 255) solid 1rpx;
  margin: 1rpx;
  background-color: powderblue;
}

.img {
  width: 88rpx;
  height: 88rpx;
  border-radius: 10rpx;
}

.title {
  margin-top: 12rpx;
}
```

### 通知布局

```html
<view class="notice">
  <image src="/images/icon/home.png" mode="aspectFit" style="width: 40rpx; height: 40rpx;" />
  <text>通知公告</text>
</view>
```

```css
.notice {
  display: flex;
  justify-content: flex-start;
  margin-top: 20rpx;
  margin-bottom: 20rpx;
}

.notice > text {
  flex-grow: 1;
}
```

### 底部布局

```html
<view class="bottom">
  <view><image src="/images/icon/home.png" mode="scaleToFill" /></view>
  <view><image src="/images/icon/home_selected.png" mode="scaleToFill" /></view>
  <view><image src="/images/icon/index.png" mode="scaleToFill" /></view>
  <view><image src="/images/icon/index_selected.png" mode="scaleToFill" /></view>
</view>
```

```css
.bottom {
  display: flex;
  justify-content: space-between;
  flex-wrap: wrap;
}

.bottom > view > image {
  width: 345rpx;
  height: 345rpx;
  padding: 10rpx;
}
```

## tabBar 配置

类似于底部的菜单栏，在 `app.json` 中配置：

```json
{
  "tabBar": {
    "selectedColor": "black",
    "position": "bottom",
    "list": [
      {
        "pagePath": "pages/index/index",
        "text": "首页",
        "iconPath": "images/home.png",
        "selectedIconPath": "images/home_selected.png"
      },
      {
        "pagePath": "pages/me/me",
        "text": "我的",
        "iconPath": "images/me.png",
        "selectedIconPath": "images/me_selected.png"
      }
    ]
  }
}
```
