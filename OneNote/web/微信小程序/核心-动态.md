# 微信小程序 核心 - 动态

## 事件

### 事件绑定

在标签上使用 `bind:事件名` 绑定方法（方法写在当前页面 JS 的 `Page` 对象里）：

```html
<button type="primary" size="mini" bind:tap="handleClick">点我</button>
```

```js
Page({
  handleClick() {
    console.log('hello')
  },
})
```

### 事件冒泡

如果父组件套了子组件，两个组件上都有事件，那么点击子组件事件触发后，父组件也会触发。把子组件的 `bind` 换成 `catch` 即可阻止冒泡：

```html
<view class="tips" bind:tap="handleParent">
  <button type="primary" size="default" catch:tap="handleChild">我是按钮</button>
</view>
```

### 事件对象与传参

绑定事件后会默认收到一个事件对象 `event`。不能直接写 `handleChild(1)` 这样传参，可以用：

- 在组件上定义 `data-xxx="xxx"`，会自动封装到 `event.target.dataset = { xxx: xxx }`。
- 也可以用 `mark:xxx="xxx"`，从 `event.mark = { xxx: xxx }` 读取。

`event` 下有两个关键字段：

| 字段 | 含义 |
| --- | --- |
| `currentTarget` | 事件**绑定**者 |
| `target` | 事件**触发**者 |

二者都有 `dataset`，事件冒泡时两个 `dataset` 不一样。

## 页面跳转

### 声明式导航

```html
<navigator url="/pages/mine/mine">
  <button type="primary" size="default">点我去我的界面</button>
</navigator>
```

| 跳转方式 | 含义 |
| --- | --- |
| `navigate`（默认） | 保留当前页面，跳转到应用内某页，不能跳到 tabbar |
| `redirect` | 关闭当前页面，跳转到应用内某页，不能跳到 tabbar |
| `switchTab` | 跳转到 tabbar 页面，并关闭其他所有非 tabbar 页面 |
| `reLaunch` | 关闭所有页面，打开应用内某页 |
| `navigateBack` | 关闭当前页面，返回上一页或多级页面 |

携带参数：直接在 url 后面用 `?xxx=xxx&xxx=xxx`，在 `onLoad(options)` 里接收。

### 编程式导航

```js
wx.navigateTo({ url: '/pages/detail/detail' })
wx.redirectTo({ url: '/pages/detail/detail' })
wx.switchTab({ url: '/pages/index/index' })
wx.reLaunch({ url: '/pages/login/login' })
wx.navigateBack()
```

## WXML 语法

### 模板语法

`{{ }}` 可以显示变量、算数运算、三元运算、逻辑判断，但不能显示 `js` 语句或方法。

```html
<button type="primary" size="default">name: {{ name }}</button>
```

```js
Page({
  data: {
    name: 'hello',
  },
})
```

更新页面数据要使用 `setData`：

```html
<button type="primary" size="default" bind:tap="onclick">age: {{ age }}</button>
```

```js
Page({
  data: { age: 12 },
  onclick() {
    this.setData({ age: this.data.age + 1 })
  },
})
```

对象类型需要用引号包裹：

```js
this.setData({ 'user.age': 12 })
```

### 列表渲染

```html
<view wx:for="{{ elements }}" wx:key="*this">{{ item }}</view>
```

`wx:key` 必须唯一，遍历出来的元素叫 `item`，索引叫 `index`。

更新数据示例：

```js
// 方式 1：先 push 再 setData
this.data.elements.push('item1')
this.setData({ elements: this.data.elements })

// 方式 2：用扩展运算符生成新数组
const newElements = [...this.data.elements, 'item2']
this.setData({ elements: newElements })

// 改值
this.setData({ 'elements[0]': 'item3' })

// 删除（用 slice 触发响应式）
this.setData({ elements: this.data.elements.slice(0) })
```

### 条件渲染

```html
<input type="text" model:value="{{ score }}" style="border: 1rpx;" />

<view wx:if="{{ score >= 90 && score <= 100 }}">优秀</view>
<view wx:elif="{{ score >= 80 && score < 90 }}">良好</view>
<view wx:elif="{{ score >= 60 && score < 80 }}">及格</view>
<view wx:else>不及格</view>
```

> 也可以使用 `hidden="{{ bool }}"` 切换显示，但 `hidden` 只是 CSS 隐藏，节点仍存在。

## 网络请求

注意：发送网络请求的域名必须先在微信公众平台配置：

「开发管理 → 开发设置 → 服务器域名」

```js
// 显示加载圈与透明蒙层
wx.showLoading({ title: 'Loading...', mask: true })

wx.request({
  url: 'https://example.com/api',
  method: 'GET',
  data: {},
  header: {},
  timeout: 1000,
  success: (res) => { /* 成功 */ },
  fail: (error) => { /* 失败 */ },
  complete: () => {
    // 无论成功与否都会执行
    wx.hideLoading()
  },
})
```
