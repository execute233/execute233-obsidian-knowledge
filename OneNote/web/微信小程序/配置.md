# 微信小程序 配置

## 本地开发支持 HTTP 请求

在「详情 → 本地设置」里勾选「不校验合法域名」即可。

## 修改默认启动显示页面

方式一：在 `app.json` 的 `pages` 数组中调整顺序，**第一个就是默认**。

方式二：在 `app.json` 添加 `entryPagePath` 字段。

方式三：在编辑器的「添加编译模式」中设置。

## 基础库设置

版本参考 [基础库版本分布](https://developers.weixin.qq.com/miniprogram/dev/framework/client-lib/version.html)。

在「设置 → 项目设置 → 本地设置」中找到「调试基础库」进行切换。

## 渲染方式

如果**不使用 skyline 而是 webview** 渲染，需要在 `app.json` 中把下面这段配置删除：

```json
{
  "renderer": "skyline",
  "rendererOptions": {
    "skyline": {
      "defaultDisplayBlock": true,
      "defaultContentBox": true,
      "tagNameStyleIsolation": "legacy",
      "disableABTest": true,
      "sdkVersionBegin": "3.0.0",
      "sdkVersionEnd": "15.255.255"
    }
  },
  "componentFramework": "glass-easel"
}
```
