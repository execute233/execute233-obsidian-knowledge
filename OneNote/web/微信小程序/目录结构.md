# 微信小程序 目录结构

## 项目目录

```
project-root/
├── app.js                # 小程序入口文件
├── app.json              # 小程序配置
├── app.wxss              # 小程序的全局样式
├── pages/                # 小程序页面，一个页面一个文件夹
│   ├── index/
│   │   ├── index.js      # 页面逻辑（JS 控制）
│   │   ├── index.wxml    # 页面结构（布局，类似 HTML）
│   │   ├── index.json    # 页面配置（导航栏颜色、标题等）
│   │   └── index.wxss    # 当前页面样式
│   ├── login/
│   └── register/
├── components/           # 组件文件夹，每个组件放一个文件夹
│   └── navigation-bar/
│       ├── navigation-bar.js
│       ├── navigation-bar.json
│       ├── navigation-bar.wxml
│       └── navigation-bar.wxss
├── .eslintrc.js          # 语法检查
├── project.config.json   # 开发工具默认配置
├── project.private.config.json   # 开发工具用户配置，优先用这个，可以删除
└── sitemap.json          # 微信收录页面，用于搜索
```

## 配置文件说明

| 配置文件 | 用途 | 参考 |
| --- | --- | --- |
| `app.json` | 全局配置：页面、窗口、tabBar 等 | [小程序配置](https://developers.weixin.qq.com/miniprogram/dev/reference/configuration/app.html) |
| `project.config.json` | 项目级配置：appid、编译选项等 | [项目配置](https://developers.weixin.qq.com/miniprogram/dev/devtools/projectconfig.html) |
| `sitemap.json` | 搜索收录相关 | [sitemap 配置](https://developers.weixin.qq.com/miniprogram/dev/reference/configuration/sitemap.html) |
| `xxx.json` | 单页配置（会覆盖 `app.json` 中相同字段） | [页面配置](https://developers.weixin.qq.com/miniprogram/dev/reference/configuration/page.html) |

### `app.json` 常用字段

| 字段 | 含义 |
| --- | --- |
| `entryPagePath` | 小程序默认启动首页 |
| `pages` | 页面路径列表 |
| `window` | 全局默认窗口表现 |

### 页面 `xxx.json` 常用字段

| 字段 | 含义 |
| --- | --- |
| `navigationBarBackgroundColor` | 导航栏背景颜色 |
| `navigationBarTextStyle` | 导航栏标题、状态颜色 |
| `navigationBarTitleText` | 导航栏标题文字内容 |

## 新建页面方式

- 在 `pages` 文件夹上右键 → 新建文件夹 `xxx` → 新建 Page `xxx` → `index` 即可。
- 也可以在 `app.json` 手动添加一项，保存后会自动生成对应文件。
