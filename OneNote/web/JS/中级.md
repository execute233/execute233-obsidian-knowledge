# JavaScript 中级

## 数字包装对象 Number

`new Number(10)` 可以包装一个数字对象，也可传入字符串。

常用方法：

| 方法 | 说明 |
| --- | --- |
| `n.toFixed(d)` | 四舍五入保留 `d` 位小数 |
| `n.toString(radix)` | 转为指定进制字符串 |
| `n.toLocaleString()` | 按千分位分隔 |
| `n.toExponential()` | 科学计数法 |

静态判断：

- `Number.isNaN(x)` / `Number.isInteger(x)` / `Number.isFinite(x)`
- `Number.parseInt()` / `Number.parseFloat()`：把字符串解析为数字

## 大整数 BigInt

```js
const big = 900719925474099199999n
const big2 = BigInt('900719925474099199999')

BigInt.asIntN(bits, value)    // 转为指定位数的有符号整数
BigInt.asUintN(bits, value)   // 不考虑符号位
```

## 字符串

字符串在需要时会自动包装成 `String` 对象。

| 方法 | 说明 |
| --- | --- |
| `s.at(i)` | 取第 `i` 个字符（支持负数） |
| `s.charCodeAt(i)` | 取第 `i` 个字符的码点 |
| `s[i]` | 类数组下标访问 |
| `s.indexOf(sub)` | 子串首次出现位置 |
| `s.lastIndexOf(sub)` | 子串最后一次出现位置 |
| `s.includes(sub)` | 是否包含子串 |
| `s.startsWith(sub)` / `s.endsWith(sub)` | 是否以子串开头 / 结尾 |
| `s.substring(start, end)` / `s.slice(start, end)` | 截取子串 |
| `s.replace(pat, new)` | 只替换第一个匹配 |
| `s.replaceAll(pat, new)` | 替换全部匹配 |
| `s.trim()` | 去除两端空白 |
| `s.padStart(len, pad)` / `s.padEnd(len, pad)` | 在开头 / 结尾补齐到指定长度 |
| `s.toUpperCase()` / `s.toLowerCase()` | 大小写转换 |
| `s.split(sep)` / `s.concat(other)` | 分割 / 拼接 |
| `s.repeat(n)` | 重复 `n` 次 |

## 数组

数组可使用 `[]` 或 `new Array()` 创建。访问 `arr[i]`，越界返回 `undefined`。类似 Java 的 `ArrayList`：

- 给元素到更大索引会自动扩容
- 修改 `length` 也能缩容
- 遍历方式：`for`、`for...of`、`arr.forEach((item, index, array) => {})`

### 增删改查

| 方法 | 说明 |
| --- | --- |
| `push(...items)` | 尾部追加元素，返回新长度 |
| `pop()` | 删除最后一个元素 |
| `unshift(...items)` | 头部插入元素 |
| `shift()` | 删除第一个元素 |
| `delete arr[i]` | 删除指定索引的元素（位置保留，值为 `undefined`） |
| `indexOf(item)` / `lastIndexOf(item)` | 查找元素位置（严格相等） |
| `find(fn)` | 按自定义规则查找 |
| `includes(item)` | 是否包含 |
| `every(fn)` / `some(fn)` | 是否全部 / 至少一个满足条件 |

### 其他常用方法

| 方法 | 说明 |
| --- | --- |
| `splice(start, deleteCount, ...items)` | 在指定索引删除并插入，返回被删除的元素组成的新数组 |
| `toSpliced(start, deleteCount, ...items)` | 同 `splice`，但返回新数组不修改原数组 |
| `with(i, value)` | 把下标 `i` 的元素改为 `value`，返回新数组 |
| `copyWithin(target, start, end)` | 把 `start ~ end` 区间的元素复制到 `target` |
| `sort(fn)` | 排序；`fn(a, b) > 0` 表示 `a` 大于 `b` |
| `reverse()` | 翻转顺序 |
| `concat(...arrs)` | 拼接多个数组 |
| `join(sep)` | 用 `sep` 把元素拼接成字符串 |
| `slice(start, end)` | 截取一段返回新数组 |
| `Object.groupBy(arr, fn)` | 按 `fn` 返回值分组，结果是 `{ key: [...] }` |

## 函数进阶

### 立即调用函数 IIFE

```js
;(function (text) {
  console.log(`Hello World! ${text}`)
})('You')
```

### 箭头函数

省略 `function` 关键字；返回对象字面量时需要用 `()` 包住 `{}`。箭头函数没有自己的 `this`，内部的 `this` 指向外层非箭头函数的 `this`。

```js
const add = (a, b) => a + b
const makeUser = (name, age) => ({ name, age })
```

### 解构

```js
const [a, b, c] = arr                    // 数组解构，可设默认值
const { name, age } = person              // 对象解构，按名字解构
const { name, ...others } = obj           // 剩余属性封装成对象
function printUser({ name, age }) { ... } // 函数参数解构
```

### 展开语法

```js
const arr5 = [...arr1, ...arr2, ...arr3, ...arr4]
const arr2 = [...arr1]                    // 浅拷贝
const obj2 = { ...obj1, age: 20 }         // 对象属性展开
```

### 生成器

```js
function* gen() {
  yield 1
  yield 2
  yield 3
}

const it = gen()
it.next()   // { value: 1, done: false }
it.next()   // { value: 2, done: false }
```

## 对象进阶

### 继承（原型链模拟）

```js
function Student(name, age) {
  this.name = name
  this.age = age
}
Student.prototype.sayHi = function () { console.log('hi') }

function ArtStudent(name, age, level) {
  Student.call(this, name, age)
  this.level = level
}

ArtStudent.prototype = Object.create(Student.prototype)
ArtStudent.prototype.constructor = ArtStudent   // 修正 constructor 指向
```

### class 语法

ES6 的 `class` 本质仍是原型链，写法更直观：

```ts
class ArtStudent extends Student {
  level: number

  constructor(name: string, age: number, level: number) {
    super(name, age)
    this.level = level
  }

  sayHi() {
    console.log('hi')
  }
}
```

### 私有属性

- 旧约定：以 `_xxx` 开头表示「请勿访问」。
- 现代语法：在字段前加 `#`，例如 `#balance`。

```js
class Bank {
  #balance = 0
  deposit(amount) { this.#balance += amount }
}
```

私有字段不会被 `Object.keys` / `for...in` 枚举。

## 常用对象与函数

### 日期对象 Date

```js
const d = new Date('2026-02-08')              // 标准时间字符串
const d2 = new Date('2026-02-08 18:09:50')    // 也可以带上具体时间
const now = new Date()                        // 当前时间

d.getFullYear()      // 年份
d.getMonth()         // 月份（0-11）
d.getDate()          // 日期（1-31）
d.getHours()         // 时（0-23）
d.getMinutes()       // 分（0-59）
d.getSeconds()       // 秒（0-59）
d.getMilliseconds()  // 毫秒（0-999）
d.getDay()           // 星期（0 = 周日，6 = 周六）
```

### 数学对象 Math

```js
Math.abs(-3)        // 3
Math.max(1, 2, 3)   // 3
Math.floor(3.7)     // 3
Math.random()       // 0-1 之间的随机小数
```

### 正则表达式

```js
const reg = /abc/
reg.test('abc')     // true
```

### JSON

```js
JSON.stringify(obj)   // 对象序列化为 JSON 字符串
JSON.parse(str)       // JSON 字符串反序列化为对象
```

### eval

```js
eval("console.log('Hello')")
```

> [!warning] 注意
> `eval` 会执行任意代码，存在安全与性能问题，生产环境尽量避免使用。

### 定时器

```js
setTimeout(fn, ms)        // 延迟执行一次
setInterval(fn, ms)       // 按固定间隔重复执行
clearTimeout(id)          // 取消
clearInterval(id)         // 取消
```
