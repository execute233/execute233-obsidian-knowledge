# JavaScript 高级

## 错误处理

JS 中所有错误都继承自统一的 `Error` 类，内置常见类型：

| 类型 | 含义 |
| --- | --- |
| `ReferenceError` | 引用错误（变量不存在） |
| `TypeError` | 类型错误（对值进行了不合法操作） |
| `SyntaxError` | 语法错误（代码本身写错） |
| `RangeError` | 范围错误（值超出合法范围） |

抛出 / 捕获：

```js
throw new Error('出错了')

try {
  // ...
} catch (err) {
  console.error(err)
} finally {
  // 无论是否异常都会执行
}
```

```js
const m = new Map()             // 键值都可以是任意类型

```

## Promise

Promise 是一个表示「尚未完成、但将来一定会有结果」的对象，有三种状态：

- `pending`（进行中）
- `fulfilled`（已成功）
- `rejected`（已失败）

```js
const p = new Promise((resolve, reject) => {
  // 执行异步操作
  // resolve(value)   成功
  // reject(reason)   失败
})
```

### then / catch / finally

```js
p.then(data => {
  console.log(`第一次 then 收到: ${data}`)
  return 6666
}).then(data => {
  console.log(`第二次 then 收到: ${data}`)
}).catch(err => {
  console.error(err)
}).finally(() => {
  console.log('结束')
})
```

`then` 的返回值会传给下一个 `then`；`catch` 处理链上任意一步的失败；`finally` 不论成功失败都会执行。

### 并发控制

```js
Promise.all([p1, p2]).then(res => {
  console.log(res)   // ['一号结束', '二号结束']
})
```

`Promise.all` 在任一 Promise 失败时整体失败。

`Promise.any` 在至少一个 Promise 成功时即完成。

## async / await

```js
async function fn() {
  return Promise.resolve('任务完成了')
}

// async 函数的返回值自动包装为 Promise
fn().then(data => console.log(data))
```

`await` 会暂停 async 函数的执行，等待 Promise 完成后再继续：

```js
async function fn() {
  const result = await new Promise(resolve => {
    setTimeout(() => resolve('任务完成了'), 1000)
  })
  return result
}
```

要点：

- `await` 后面的值若不是 Promise，会被自动包装为已成功的 Promise。
- `await` 只能在 async 函数内部使用。

## 模块化（ES Module）

只要文件里使用了 `import` 或 `export`，该文件就被视为 ES Module。

### 命名导出 / 导入

```js
// a.js
const a = 1
const b = 2
export { a, b }
```

```js
// b.js
import { a, b } from './a.js'
```

### 默认导出 / 导入

每个模块只能有一个默认导出：

```js
// a.js
export default function () {
  console.log('default')
}
```

```js
// b.js
import test from './a.js'        // 默认导出可以随意命名
import test, { a } from './a.js' // 默认 + 命名混合导入
```
