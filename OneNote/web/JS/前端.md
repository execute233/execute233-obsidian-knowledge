# JavaScript 前端 (DOM / BOM)

## DOM 元素与属性

### 获取元素

```js
const box = document.getElementById('box')
```

HTML 中所有元素类型都是 `Node` 的子类，继承关系如下：

```
EventTarget              ← 顶层基类（拥有 addEventListener 等事件能力）
   └── Node              ← DOM 树中所有节点（标签、文本、注释等）
         └── Element     ← 标签节点（提供 Attribute 操作）
               └── HTMLElement        ← HTML 元素共有属性（id, className, style）
                     └── HTMLDivElement 等 ← 具体标签的专属属性
```

让 JS 延迟到 DOM 树构建完成后再执行：

```html
<script defer src="js/script.js"></script>
```

按标签名批量获取：

```js
const items = document.getElementsByTagName('li')   // HTMLCollection
items.namedItem('foo')                              // 按 name / id 快速查找
```

使用 CSS 选择器：

```js
const first = document.querySelector('.item')       // 单个
const all   = document.querySelectorAll('.item')    // NodeList
```

### HTML 属性（Attribute）

```js
element.getAttribute('id')          // 读取
element.setAttribute('class', '666') // 设置，不存在则新增
element.hasAttribute('title')       // 是否存在
element.removeAttribute('title')    // 删除
```

### DOM 属性（Property）

浏览器为每个元素维护的 JavaScript 对象属性：

```js
input.value
input.type
input.disabled
input.checked
input.placeholder
```

非标准 HTML 属性可以挂在 `dataset` 上：

```js
box.dataset.role = 'guest'
```

类名与内联样式：

```js
box.className = 'crazy item'
box.classList.add('crazy', 'thursday')
box.classList.remove('crazy')

box.style.color = 'white'   // 等价于 style="color: white;"
```

### 元素内容

```js
box.innerHTML      // 获取或设置元素内部的 HTML 结构
box.innerText      // 获取或设置「人眼能看到的文本」
box.textContent    // 获取或设置原始文本
```

### 创建和操作元素

```js
const div = document.createElement('div')
div.textContent = '我是新创建的元素'

box.appendChild(div)            // 添加为子节点（重复添加 = 移动）
box.append(div, other, text)    // 支持一次性插入多个

// 一次性插入多个节点：先放进 DocumentFragment
const fragment = document.createDocumentFragment()
fragment.appendChild(a)
fragment.appendChild(b)
box.append(fragment)

// 在指定元素前插入
parent.insertBefore(newNode, refNode)
```

如果元素原本就在页面中，`appendChild` 等同于把它移动到新位置，而不是复制。

### 元素关系

```js
box.firstChild                   // 第一个子节点（含文本 / 注释）
box.lastChild
box.firstElementChild            // 第一个 Element 子节点
box.lastElementChild
box.previousSibling              // 上一个兄弟节点
box.nextSibling
box.previousElementSibling       // 上一个 Element 兄弟
box.nextElementSibling
```

### 元素位置和滚动

```js
// offset 系列：相对于页面布局的位置与尺寸
element.offsetWidth              // 元素宽度
element.offsetHeight             // 元素高度
element.offsetLeft               // 元素 X 坐标
element.offsetTop                // 元素 Y 坐标

// client 系列：可视区域，与滚动条相关
element.clientWidth
element.clientHeight
element.clientLeft               // 左边框大小
element.clientTop                // 上边框大小

// scroll 系列：实际滚动区域
element.scrollWidth              // 实际滚动宽度
element.scrollHeight             // 实际滚动高度
element.scrollTop                // 内容顶部滚动位置
element.scrollLeft               // 内容左侧滚动位置

// 控制滚动
box.scroll(0, 0)                            // 滚动到 (0, 0)
box.scroll({ top: 0, behavior: 'smooth' })  // 平滑滚动
box.scrollBy(0, 1000)                       // 相对滚动
box.scrollIntoView()                        // 滚动到指定元素可见
```

## 事件

事件可拆解为三部分：

- **事件源（Event Target）**：谁触发了事件？如 `<button>`。
- **事件类型（Event Type）**：发生了什么？如 `click`、`keydown`。
- **事件处理程序（Event Handler）**：发生之后做什么？通常是 JS 函数。

### 注册方式

```html
<!-- 内联事件 -->
<button onclick="alert('你点击了按钮')">点我</button>
```

```js
btn.addEventListener('click', (event) => {
  console.log('我是测试')
  alert('你点击了按钮')
})
```

### 事件流（捕获 / 冒泡）

```js
btn.addEventListener('click', (event) => {
  console.log('2')
}, {
  capture: true   // 在捕获阶段执行；不写默认在冒泡阶段
})
```

### 阻止默认行为

```js
a.addEventListener('click', (event) => {
  event.preventDefault()
})

// 拦截右键菜单
document.documentElement.addEventListener('contextmenu', (event) => {
  event.preventDefault()
})
```

### 常用事件类型

**鼠标事件**

| 事件 | 含义 |
| --- | --- |
| `click` | 单击 |
| `dblclick` | 双击 |
| `mousedown` / `mouseup` | 鼠标按下 / 抬起 |
| `mousemove` | 鼠标移动 |
| `mouseenter` / `mouseleave` | 鼠标进入 / 离开（不冒泡） |
| `mouseover` / `mouseout` | 鼠标进入 / 离开（会冒泡） |
| `contextmenu` | 右键菜单 |

```js
console.log(e.clientX)   // 相对视口 X 坐标
console.log(e.clientY)
console.log(e.pageX)     // 相对页面 X 坐标
console.log(e.pageY)
console.log(e.button)    // 按下的是哪个鼠标键
```

**键盘事件**

| 事件 | 含义 |
| --- | --- |
| `keydown` | 键按下 |
| `keyup` | 键抬起 |
| `keypress` | 键按下（不含控制键，不推荐） |

```js
e.key       // 按下的字符
e.code      // 键盘物理位置
e.ctrlKey   // 是否按住 Ctrl
e.shiftKey
e.altKey
e.metaKey   // Mac 键位专用
```

**表单事件**

| 事件 | 含义 |
| --- | --- |
| `submit` | 表单提交 |
| `input` | 输入时触发（每输入一字符都触发，包括删除、粘贴） |
| `change` | 失去焦点后触发 |
| `focus` | 获得焦点 |
| `blur` | 失去焦点 |
| `reset` | 表单重置 |

实时校验邮箱格式：

```js
input.addEventListener('input', () => {
  const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/
  console.log('是否是邮箱：', emailRegex.test(input.value))
})
```

**页面事件**

```js
// DOM 树构建完成
document.addEventListener('DOMContentLoaded', () => {
  console.log('DOM 结构已经构建完成')
})

// 整个页面加载完成
window.addEventListener('load', () => {
  console.log('页面完全加载完成')
})

// 窗口大小变化
window.addEventListener('resize', (evt) => console.log(evt))

// 页面滚动
window.addEventListener('scroll', (evt) => console.log(evt))

// 页面可见性变化
window.addEventListener('visibilitychange', () => {
  console.log(document.visibilityState)
})
```

## 常用 Web API

### window 对象

| 属性 / 方法 | 说明 |
| --- | --- |
| `window.document` | 当前文档对象 |
| `window.location` | URL 信息，可读取或修改以跳转页面 |
| `window.navigator` | 浏览器信息（版本、平台、语言） |
| `window.console` | 开发者工具相关 |
| `window.history` | 浏览器历史记录 |
| `window.innerWidth` / `window.innerHeight` | 视口宽 / 高 |
| `window.outerWidth` / `window.outerHeight` | 整个浏览器窗口宽 / 高 |
| `window.localStorage` / `window.sessionStorage` | 本地 / 会话存储 |
| `window.scrollY` | 滚动条位置 |
| `window.alert()` / `confirm()` / `prompt()` | 弹窗 |
| `window.open()` / `close()` | 打开 / 关闭窗口 |

### window.location

`location` 指向一个包含当前文档 URL 信息的对象：

| 属性 | 含义 | 示例 |
| --- | --- | --- |
| `protocol` | 协议（含冒号） | `https:` |
| `host` | 主机名 + 端口号 | `www.example.com:8080` |
| `hostname` | 主机名 | `www.example.com` |
| `port` | 端口号 | `8080` |
| `pathname` | 路径（含斜杠） | `/path/page.html` |
| `search` | 查询参数（含问号） | `?name=test&age=18` |
| `hash` | 锚点（含井号） | `#section1` |
| `origin` | 协议 + 主机 + 端口（只读） | `https://www.example.com:8080` |

修改 `location.href` 即可跳转页面。

### window.history

```js
console.log(history.length)   // 栈长度

history.back()                // 后退
history.forward()             // 前进
history.go(n)                 // 跳转到第 n 条历史记录
// n=1 前进 1 步；n=-1 后退 1 步；n=0 刷新
```

### window.navigator

用于获取当前浏览器与设备环境信息。

### 数据存储对比

| 方式 | 大小 | 生命周期 | 自动随请求发送 | 典型用途 |
| --- | --- | --- | --- | --- |
| Cookie | ~4 KB | 可设置 | ✅ 是 | 登录状态 |
| localStorage | 5~10 MB | 永久 | ❌ 否 | 本地缓存 |
| sessionStorage | ~5 MB | 会话级，关闭标签页消失 | ❌ 否 | 临时状态 |
| IndexedDB | 很大 | 永久 | ❌ 否 | 大型数据 |
| Cache Storage | 很大 | 永久 | ❌ 否 | PWA 缓存 |
| 内存变量 | 小 | 页面刷新即消失 | ❌ 否 | 临时变量 |

### localStorage / sessionStorage

> 键值需要以字符串形式存放；建议把对象用 `JSON.stringify` 序列化。

```js
localStorage.setItem('AAA', '111')
localStorage.getItem('AAA')
localStorage.key(0)                  // 按下标取 key
localStorage.removeItem('AAA')
localStorage.length                  // 键值对数量
localStorage.clear()                 // 清空

// sessionStorage 用法相同，但仅在当前标签页内共享
```

### Cookie

浏览器提供的小型文本数据存储，用于在客户端保存少量数据，并在之后的请求中自动携带给服务器，使用 `cookieStore` 调用：

```
name=value; expires=时间; path=/; domain=xxx; secure; HttpOnly; SameSite
```

设置 Cookie 的两种方式：

1. 服务器通过 `Set-Cookie` 响应头添加。
2. 通过 `cookieStore` 手动添加。
