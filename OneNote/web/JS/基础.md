# JavaScript 基础

## 引入方式

```html
<!-- 内联 -->
<script>
  console.log('hello')
</script>

<!-- 外部文件 -->
<script src="./main.js"></script>
```

## 变量与常量

- 局部变量用 `let`，全局变量用 `var`。
- 常量用 `const`。
- JS 允许不写分号换行。

## 基本类型

| 类型 | 说明 |
| --- | --- |
| 数字 | 64 位双精度浮点数；含 `Infinity`、`NaN` |
| 字符串 | `""` / `''`，模板字符串 `` `hello ${name}` `` |
| boolean | `true` / `false` |
| undefined | 未定义 |

## 运算

优先级与其他语言类似，但与字符串运算时自动转为字符串。要点：

- 布尔值自动转数字：`true → 1`，`false → 0`
- `undefined` 自动转为 `NaN`
- `null` 被当作 `0`
- 对象 / 数组会先调用 `valueOf()` / `toString()` 转原始值
- 指数运算符是 `**`

### 比较运算符

| 运算符 | 含义 |
| --- | --- |
| `==` | 宽松（自动转换）比较 |
| `===` | 严格（值与类型都相等）比较 |
| `!=` | 宽松不等 |
| `!==` | 严格不等 |

### 类型运算符

```js
typeof a === 'number'
```

## 函数

- 函数声明：`function foo() {}`
- 函数表达式：`const foo = function () {}`
- 函数变量也可以用 `call()` / `apply()` 调用。对象方法调用时，第一个参数即 `this`。

## 对象

### 定义与访问

```js
const obj = {
  name: '张三',
  say() {
    console.log('hello')
  },
}

obj.name          // 属性访问
obj['name']       // 字符串键访问
obj.say()         // 方法调用
obj?.notExist     // 可选链，访问 null 时返回 undefined
```

### 构造函数

```js
function Person(name) {
  this.name = name
  this.say = function () {
    console.log('hello')
  }
}

const p1 = new Person('张三')
```

> 注意：构造函数里每次都会创建新的匿名函数，浪费内存；常用 `prototype` 共享方法。

### 遍历属性

```js
for (let key in obj) {
  console.log(key, obj[key])
}
```

### 原型链

每个函数都自带 `prototype`（原型对象）。`new` 出来的对象基于 `prototype`，访问属性 / 方法不存在时会沿着原型链向上查找。

```
实例 ──> 构造函数的 prototype ──> Object.prototype ──> null
```

注意：通过实例对原型链上的属性赋值时，并不会覆盖原型上的值，而是在实例自身新增一个同名属性（原型上的值仍只读）。因此可以把共享方法挂到 `Person.prototype` 上避免重复创建。

### Object 实例方法

| 方法 | 说明 |
| --- | --- |
| `hasOwnProperty(key)` | 查询自身是否拥有该属性（不沿原型链） |
| `'key' in obj` | 沿原型链判断是否存在该属性 |
| `propertyIsEnumerable(key)` | 判断是否自身且可枚举的属性 |
| `isPrototypeOf(obj)` | 当前对象是否是 obj 的原型 |

### Object 静态方法

| 方法 | 说明 |
| --- | --- |
| `Object.keys(obj)` | 获取可枚举属性名列表 |
| `Object.getOwnPropertyNames(obj)` | 获取所有自身属性名（含不可枚举） |
| `Object.getOwnPropertySymbols(obj)` | 获取符号属性 |
| `Object.values(obj)` | 获取属性值列表 |
| `Object.entries(obj)` | 获取 `[key, value]` 列表 |
| `Object.assign(target, ...sources)` | 把 sources 的属性浅拷贝到 target |
| `Object.is(a, b)` | 类似 `===`，但能处理 `NaN` 等特殊值 |
| `Object.freeze(obj)` | 冻结对象，不可修改 / 删除属性 |
| `Object.preventExtensions(obj)` | 禁止新增属性，但允许修改 / 删除 |

## 类型判断

```js
typeof a === 'string'         // 基本类型
stu instanceof Student         // 对象：判断左侧原型链上是否存在右侧
```
