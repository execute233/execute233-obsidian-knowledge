> [!success] 下一步
> 不要继续阅读更多“类名大全”。从第二课创建项目，按 14 天路线完成每个练习。遇到生僻 CSS 属性时，在官方文档左侧按原生 CSS 属性名查找。完成综合项目后，再把 Tailwind 接入 Astro，会比边学 Astro 边猜 utility 顺畅得多。
