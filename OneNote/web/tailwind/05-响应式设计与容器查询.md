# 响应式设计与容器查询

## 5.1 默认断点

Tailwind 默认使用 mobile-first 的 min-width 断点。[官方响应式文档](https://tailwindcss.com/docs/responsive-design)列出的默认值是：

| 前缀 | 最小宽度 | CSS |
|---|---:|---|
| <code>sm</code> | 40rem / 640px | <code>width >= 40rem</code> |
| <code>md</code> | 48rem / 768px | <code>width >= 48rem</code> |
| <code>lg</code> | 64rem / 1024px | <code>width >= 64rem</code> |
| <code>xl</code> | 80rem / 1280px | <code>width >= 80rem</code> |
| <code>2xl</code> | 96rem / 1536px | <code>width >= 96rem</code> |

无前缀 utility 对所有尺寸生效；带 <code>md:</code> 的 utility 从 md 开始覆盖。

~~~html
<div class="text-center md:text-left">
  手机居中，md 及以上左对齐
</div>
~~~

> [!danger] 高频误区
> <code>sm:</code> 不是“只在小屏幕”。它表示“从 40rem 开始”。手机默认样式应该写成无前缀 utility，再逐级增强。

## 5.2 范围与单个断点

从 md 开始：

~~~html
<div class="md:flex"></div>
~~~

只在 md 到 lg 之间：

~~~html
<div class="md:max-lg:flex"></div>
~~~

小于 md：

~~~html
<div class="max-md:hidden"></div>
~~~

一次性自定义断点：

~~~html
<div class="min-[900px]:grid-cols-3 max-[500px]:px-2"></div>
~~~

项目级断点应进入主题：

~~~css
@theme {
  --breakpoint-3xl: 120rem;
}
~~~

之后可写 <code>3xl:grid-cols-6</code>。

## 5.3 不按设备名设计

不要把 <code>md</code> 机械等同于“平板”，把 <code>lg</code> 等同于“桌面”。更稳的方法是：

1. 先写内容自然可用的窄布局。
2. 缓慢拉宽窗口。
3. 在布局开始难看或空间足够时选择断点。
4. 让内容决定断点，而不是猜设备型号。

## 5.4 Container Queries

视口响应式回答“浏览器多宽”；容器查询回答“组件所在容器多宽”。对于可被放进主栏、侧栏、弹窗的复用组件，后者更准确。

~~~html
<section class="@container">
  <article class="flex flex-col gap-4 @md:flex-row @md:items-center">
    <img class="aspect-video w-full object-cover @md:w-48" src="..." alt="..." />
    <div>...</div>
  </article>
</section>
~~~

命名容器：

~~~html
<main class="@container/main">
  <article class="grid @lg/main:grid-cols-2">
    ...
  </article>
</main>
~~~

范围：

~~~html
<div class="@container">
  <div class="@sm:@max-lg:grid @max-sm:block">...</div>
</div>
~~~

v4.3 还提供 <code>@container-size</code>，在确实需要同时依据 inline size 和 block size、或使用 <code>cqb</code> 等单位时使用：

~~~html
<div class="@container-size">
  <div class="h-[50cqb]">...</div>
</div>
~~~

来源：[Responsive design：Container queries](https://tailwindcss.com/docs/responsive-design#container-queries)。

## 5.5 选择 viewport 还是 container

| 问题 | 选择 |
|---|---|
| 整页导航何时折叠 | viewport breakpoint |
| 页面侧栏何时出现 | viewport breakpoint |
| 卡片内部何时横排 | container query |
| 同一组件在主栏与侧栏表现不同 | container query |
| 全站字号层级随大屏增强 | viewport breakpoint |
