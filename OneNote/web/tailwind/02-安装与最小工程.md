# 第二课：安装与最小工程

## 2.1 推荐路线：Vue 3 + TypeScript + Vite

你已经学过 Vue，因此后续练习直接使用 Vue + Vite。官方将 Vite 插件作为 v4 的第一方集成方式；安装步骤见[官方 Vite 指南](https://tailwindcss.com/docs/installation/using-vite)。

~~~bash
npm create vite@latest tailwind-v4-course -- --template vue-ts
cd tailwind-v4-course
npm install
npm install tailwindcss @tailwindcss/vite
~~~

修改 <code>vite.config.ts</code>：

~~~ts
import { defineConfig } from "vite"
import vue from "@vitejs/plugin-vue"
import tailwindcss from "@tailwindcss/vite"

export default defineConfig({
  plugins: [
    vue(),
    tailwindcss(),
  ],
})
~~~

在 <code>src/style.css</code> 中保留：

~~~css
@import "tailwindcss";
~~~

确认 <code>src/main.ts</code> 导入全局样式：

~~~ts
import { createApp } from "vue"
import "./style.css"
import App from "./App.vue"

createApp(App).mount("#app")
~~~

用最小页面验证：

~~~vue
<template>
  <main class="grid min-h-dvh place-items-center bg-slate-950 text-white">
    <h1 class="text-4xl font-bold tracking-tight text-sky-400">
      Tailwind v4 已运行
    </h1>
  </main>
</template>
~~~

~~~bash
npm run dev
~~~

如果页面居中、背景深色、标题为天蓝色，则集成成功。

## 2.2 为什么这里没有 tailwind.config.js

v4 默认采用 CSS-first configuration。基础项目通常只需要：

~~~css
@import "tailwindcss";
~~~

需要主题时再直接写：

~~~css
@import "tailwindcss";

@theme {
  --color-brand-500: oklch(0.68 0.16 238);
  --font-display: "Inter", sans-serif;
}
~~~

JavaScript 配置仍可通过兼容指令加载，但那是迁移旧项目时的路线，不是新项目主线。

## 2.3 纯 HTML 练习的 CLI 方案

如果你只想单独练 HTML，不想启动 Vue，可使用[官方 CLI](https://tailwindcss.com/docs/installation/tailwind-cli)：

~~~bash
npm install tailwindcss @tailwindcss/cli
~~~

<code>src/input.css</code>：

~~~css
@import "tailwindcss";
~~~

启动监听：

~~~bash
npx @tailwindcss/cli -i ./src/input.css -o ./src/output.css --watch
~~~

然后在 HTML 中引入 <code>output.css</code>。

## 2.4 Play CDN 只用于试验

[Play CDN](https://tailwindcss.com/docs/installation/play-cdn)可以免构建体验 v4，但官方明确说明它只适合开发试验，不适合生产：

~~~html
<script src="https://cdn.jsdelivr.net/npm/@tailwindcss/browser@4"></script>
~~~

学习项目优先用 Vite，因为源码检测、构建结果和实际工程体验都更接近生产。

## 2.5 编辑器

VS Code 建议安装官方 Tailwind CSS IntelliSense，它理解 <code>@theme</code>、<code>@source</code> 等自定义语法并提供补全、hover 预览和诊断。参考[官方编辑器配置](https://tailwindcss.com/docs/editor-setup)。

可选安装官方 Prettier 插件来统一类名顺序：

~~~bash
npm install -D prettier prettier-plugin-tailwindcss
~~~

<code>prettier.config.mjs</code>：

~~~js
export default {
  plugins: ["prettier-plugin-tailwindcss"],
}
~~~

类名排序只改善可读性，不决定冲突结果。CSS 中谁胜出取决于生成样式表的规则顺序和 specificity，而不是 <code>class</code> 属性中谁写在后面。

## 2.6 浏览器兼容性

Tailwind v4 的核心功能面向现代浏览器，官方测试基线为：

| 浏览器 | 最低版本 |
|---|---:|
| Chrome | 111 |
| Safari | 16.4 |
| Firefox | 128 |

若项目必须支持更旧浏览器，官方建议继续使用 v3.4。部分单独的现代 utility 依赖更晚的 Web Platform 特性，应按项目目标浏览器再次检查。来源：[Compatibility](https://tailwindcss.com/docs/compatibility)。
