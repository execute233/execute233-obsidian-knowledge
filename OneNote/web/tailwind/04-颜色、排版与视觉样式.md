# 第四课：颜色、排版与视觉样式

## 4.1 颜色系统

颜色 utility 的结构通常是：

~~~text
属性-色系-阶梯

bg-sky-600
text-slate-950
border-emerald-300
fill-violet-500
stroke-rose-600
~~~

官方默认调色板通常使用从 50 到 950 的 11 个阶梯，并在 v4 中以 OKLCH 为基础。所有颜色都以 theme variables 暴露。参考[官方颜色文档](https://tailwindcss.com/docs/colors)。

颜色透明度使用斜杠：

~~~html
<div class="bg-black/50"></div>
<div class="border-white/10"></div>
<p class="text-slate-950/70"></p>
~~~

设计时不要机械理解为“500 就一定适合主色”。背景、文字、边框、深色模式和可访问性需要分别检查对比度。

## 4.2 排版

高频排版 utility：

| 目标 | 示例 |
|---|---|
| 字体族 | <code>font-sans</code>、<code>font-mono</code> |
| 字号 | <code>text-sm</code>、<code>text-xl</code>、<code>text-4xl</code> |
| 字重 | <code>font-medium</code>、<code>font-semibold</code>、<code>font-bold</code> |
| 行高 | <code>leading-6</code>、<code>leading-tight</code> |
| 字间距 | <code>tracking-tight</code>、<code>tracking-wide</code> |
| 对齐 | <code>text-left</code>、<code>text-center</code> |
| 溢出 | <code>truncate</code>、<code>line-clamp-3</code> |
| 换行策略 | <code>text-balance</code>、<code>text-pretty</code> |

字号和行高可合并：

~~~html
<p class="text-base/7">正文拥有 1.75rem 行高</p>
<h1 class="text-4xl/none font-bold tracking-tight">紧凑标题</h1>
~~~

推荐把排版看成层级，而不是零散属性：

~~~html
<section class="mx-auto max-w-3xl">
  <p class="text-sm font-semibold tracking-wide text-sky-600 uppercase">
    Tailwind CSS v4
  </p>
  <h1 class="mt-3 text-4xl font-bold tracking-tight text-balance text-slate-950">
    用设计约束构建一致的界面
  </h1>
  <p class="mt-5 text-lg/8 text-pretty text-slate-600">
    Utility class 的意义不只是少写 CSS，而是让取值和状态拥有一致的语言。
  </p>
</section>
~~~

## 4.3 边框、圆角、ring 与 outline

~~~html
<input
  class="
    rounded-lg border border-slate-300 px-3 py-2
    outline-none
    focus-visible:border-sky-500
    focus-visible:ring-3 focus-visible:ring-sky-500/20
  "
/>
~~~

区分：

- <code>border</code> 参与盒模型。
- <code>ring</code> 适合强调状态，不占布局空间。
- <code>outline</code> 是原生轮廓机制，尤其要考虑键盘焦点和 forced colors。

> [!warning] v4 的 ring 默认宽度
> v4 中不带数字的 <code>ring</code> 默认是 1px，而 v3 曾是 3px。想明确得到 3px 就写 <code>ring-3</code>。不要为了“界面干净”直接移除焦点指示；应使用清晰的 <code>focus-visible</code> 样式。

## 4.4 阴影、滤镜与背景

~~~html
<div class="rounded-2xl bg-white shadow-xl shadow-slate-900/10"></div>
<div class="bg-white/70 backdrop-blur-xl"></div>
<img class="grayscale transition hover:grayscale-0" src="..." alt="..." />
~~~

组合渐变时，v4 主线语法是 <code>bg-linear-*</code>：

~~~html
<div class="bg-linear-to-r from-cyan-500 via-blue-500 to-violet-600"></div>
<div class="bg-radial from-white to-slate-950"></div>
<div class="bg-conic from-red-500 via-yellow-400 to-red-500"></div>
~~~

旧教程中的 <code>bg-gradient-to-r</code> 属于 v3 写法，迁移时应注意。
