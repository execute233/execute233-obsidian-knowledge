# 过渡、变换和动画

## 10.1 过渡

最小组合：

~~~html
<button class="transition-colors duration-200 hover:bg-sky-700">
  保存
</button>
~~~

常见组成：

| utility | 作用 |
|---|---|
| <code>transition</code> | 过渡一组常见属性 |
| <code>transition-colors</code> | 颜色相关属性 |
| <code>transition-opacity</code> | opacity |
| <code>transition-transform</code> | transform 相关属性 |
| <code>duration-200</code> | 持续时间 |
| <code>ease-out</code> | timing function |
| <code>delay-75</code> | 延迟 |

不要习惯性使用 <code>transition-all</code>。明确过渡范围通常更可控，也避免尺寸、位置等无意参与动画。

## 10.2 变换

~~~html
<article
  class="
    transition-[translate,box-shadow] duration-200 ease-out
    hover:-translate-y-1 hover:shadow-xl
  "
>
  ...
</article>
~~~

~~~html
<button class="transition-transform active:scale-95">按下</button>
<div class="rotate-3 hover:rotate-0"></div>
~~~

v4 的 <code>translate-*</code>、<code>scale-*</code>、<code>rotate-*</code> 基于独立 CSS transform properties。若要重置，应分别使用 <code>translate-none</code>、<code>scale-none</code>、<code>rotate-none</code>，不要假设旧式 <code>transform-none</code> 会清除一切。参考[升级指南](https://tailwindcss.com/docs/upgrade-guide#individual-transform-properties)。

## 10.3 内置动画

~~~html
<span class="inline-block size-5 animate-spin rounded-full border-2 border-current border-r-transparent"></span>
<div class="animate-pulse rounded-xl bg-slate-200"></div>
<span class="relative flex size-3">
  <span class="absolute inline-flex size-full animate-ping rounded-full bg-sky-400 opacity-75"></span>
  <span class="relative inline-flex size-3 rounded-full bg-sky-500"></span>
</span>
~~~

动画应解释状态，而不是仅仅“让页面更炫”。加载、连接状态、进入/退出和空间关系是较合理的场景。

## 10.4 自定义动画

在 v4 中，可将动画 token 和 keyframes 定义在 <code>@theme</code>：

~~~css
@theme {
  --animate-fade-in-up: fade-in-up 300ms ease-out;

  @keyframes fade-in-up {
    from {
      opacity: 0;
      transform: translateY(0.5rem);
    }

    to {
      opacity: 1;
      transform: translateY(0);
    }
  }
}
~~~

使用：

~~~html
<div class="animate-fade-in-up">...</div>
~~~

## 10.5 尊重减少动态效果偏好

~~~html
<article
  class="
    transition-transform duration-300 hover:-translate-y-1
    motion-reduce:translate-none motion-reduce:transition-none
  "
>
  ...
</article>
~~~

如果动效不是理解内容所必需，就让 <code>prefers-reduced-motion</code> 用户可以关闭它。对于循环、缩放、视差和大幅位移尤其重要。

## 10.6 一个完整动效卡片

~~~vue
<template>
  <a
    href="#"
    class="
      group block overflow-hidden rounded-2xl bg-white
      shadow-md shadow-slate-900/5 ring-1 ring-slate-950/5
      transition-[translate,box-shadow] duration-200 ease-out
      hover:-translate-y-1 hover:shadow-xl
      focus-visible:outline-3 focus-visible:outline-offset-4
      focus-visible:outline-sky-600
      motion-reduce:translate-none motion-reduce:transition-none
    "
  >
    <div class="overflow-hidden">
      <img
        class="
          aspect-video w-full object-cover
          transition-transform duration-300
          group-hover:scale-105 motion-reduce:transition-none
        "
        src="/course.jpg"
        alt=""
      />
    </div>
    <div class="p-5">
      <h2 class="font-semibold text-slate-950 group-hover:text-sky-700">
        Tailwind CSS v4
      </h2>
      <p class="mt-2 text-sm/6 text-slate-600">
        系统掌握 utility、variants 与 design tokens。
      </p>
    </div>
  </a>
</template>
~~~
