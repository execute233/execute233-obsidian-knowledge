# 综合项目——学习控制台

## 14.1 项目目标

构建一个响应式“学习控制台”，不要照着截图机械临摹。你需要自己完成设计决策，并让每项决策能对应到本课程知识。

功能区域：

- 导航与主题
- 学习进度
- 课程列表
- 最近活动

建议文件：

~~~text
src/
├── components/
│   ├── AppSidebar.vue
│   ├── BaseButton.vue
│   ├── CourseCard.vue
│   ├── ProgressCard.vue
│   ├── StatCard.vue
│   └── ThemeSwitcher.vue
├── composables/
│   └── useTheme.ts
├── data/
│   └── courses.ts
├── App.vue
├── main.ts
└── style.css
~~~

## 14.2 硬性要求

### 布局

- 窄屏为单列。
- 大屏显示侧栏与主内容。
- 课程列表使用 Grid。
- CourseCard 内部使用 container query，而不是依赖页面断点。
- 不允许出现意外横向滚动。

### 状态

- 按钮有 hover、active、focus-visible、disabled、loading。
- 当前导航项通过 <code>aria-current="page"</code> 和对应 variant 表示。
- 表单错误不只依靠颜色。
- 支持 reduced motion。

### 主题

- light / dark / system 三态。
- 刷新不丢失显式选择。
- 尽量避免主题闪烁。
- 至少有 brand、surface、content、line、danger 语义 token。

### Vue 组件

- props 使用 TypeScript。
- 不动态拼接 Tailwind 类名。
- 重复结构通过组件或循环处理。
- 组件视觉变化优先暴露语义 props。

### 工程

- 使用 Tailwind v4 的 Vite 插件。
- CSS 入口使用 <code>@import "tailwindcss";</code>。
- 主题使用 <code>@theme</code>。
- 至少创建一个合理的 custom utility 或 custom variant。
- 生产构建成功。

## 14.3 分阶段实施

### 阶段 1：静态结构

只完成语义 HTML 和 Vue 组件，不做精细视觉。确认：

- heading 层级正确。
- button、nav、aside、main 使用恰当。
- 图片有正确 alt；装饰图 alt 为空。
- 表单有 label。

### 阶段 2：窄屏基础样式

只写无前缀 utility：

- 建立 spacing rhythm。
- 完成文字层级。
- 确保点击目标与内容可用。
- 让长文本与图片不会破坏布局。

### 阶段 3：逐级响应式

按内容需要添加 <code>sm</code>、<code>md</code>、<code>lg</code>、<code>xl</code>。每加一个断点都问：

> 这个变化为什么必须在这里发生？

### 阶段 4：组件容器查询

把 CourseCard 同时放到：

- 主内容宽容器。
- 侧栏窄容器。
- 弹窗中等容器。

组件应根据自身空间调整，不要求父页面告诉它“现在是桌面端”。

### 阶段 5：交互状态与主题

补齐状态矩阵：

### 阶段 6：设计系统收敛

搜索项目中的：

- 重复任意颜色。
- 重复阴影。
- 重复圆角。
- 重复过渡曲线。
- 重复的语义组件变体。

将真正的系统值提升到 <code>@theme</code>，一次性布局细节保持局部。

### 阶段 7：调试与测试

至少测试宽度：

- 360px。
- 768px。
- 1024px。
- 1440px。

至少测试环境：

- 键盘导航。
- 深色模式。
- 系统主题切换。
- reduced motion。
- 200% 页面缩放。
- 超长中文与英文内容。
- 图片加载失败。
