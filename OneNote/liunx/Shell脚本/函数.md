# 函数

变量传参见 [[liunx/Shell脚本/变量|变量]];控制流调用见 [[liunx/Shell脚本/流程控制|流程控制]];跨文件包含见 [[liunx/Shell脚本/文件包含|文件包含]]。

直接使用下面那样定义(注意函数要在调用语句前面定义):

```bash
函数名 () {
    command1
    …
    return xxx   # 返回语句可以没有
}
```

直接用函数名来调用函数，可以使用 `$?` 获得函数的返回值（只能返回数字），如：

```bash
函数名
echo "$?"
```

在函数里，可以使用 `$1 $2 …` 等获取参数，调用就是：

```bash
函数名 参数1 参数2 …
```
