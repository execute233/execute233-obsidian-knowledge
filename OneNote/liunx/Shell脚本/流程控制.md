# 流程控制

变量基础见 [[liunx/Shell脚本/变量|变量]];条件表达式见 [[liunx/Shell脚本/运算符|运算符]];控制流调用见 [[liunx/Shell脚本/函数|函数]];跨文件复用见 [[liunx/Shell脚本/文件包含|文件包含]]。

## 条件判断

```bash
if [ 条件判断式 ]
then
    语句
fi
```

或：

```bash
if [ 条件判断式 ]
then
    语句
else
    语句
fi
```

或：

```bash
if [ 条件判断式 ]
then
    command1
elif condition
then
    command2
…
else
    command
fi
```

## 条件匹配

```bash
case expression in
    pattern1)
        statement1
        ;;
    pattern2)
        statement2
        ;;
    …
    *)
        statementn
esac
```

## 循环

### for 循环

```bash
for var in item1 item2 …
do
    command1
    …
done
```

或（C 语言风格）：

```bash
for (( 初始值; 循环控制; 变量变化 ))
do
    command1
    …
done
```

### while 循环

```bash
while condition
do
    command1
    …
done
```
