# 变量

Shell 脚本入口见 [[liunx/Shell脚本/前言]];变量常用于 [[liunx/Shell脚本/流程控制]];作为参数传入 [[liunx/Shell脚本/函数]];输出格式化见 [[liunx/Shell脚本/printf]]。

## 定义字符串变量

要尽量避免使用空格，可以像 Python 一样直接赋值：

```bash
your_name="name"
```

## 使用变量

只要在变量名前加 `$`：

```bash
$your_name
${your_name}
```

花括号这种写法可以在字符串里使用：

```bash
echo "your name is ${your_name}"
```

注意 `your_name = "name"` 这种带空格的写法是错的。

## 常量

使用 `readonly` 关键字在前面，类似于语句：

```bash
readonly your_name
```

## 删除变量

使用 `unset` 语句：

```bash
unset your_name
```

## 整数变量

```bash
declare -i 变量名=值
```

## 数组变量

### 整数索引数组

```bash
变量名=(1 2 3 4)
```

### 关联数组（类似字典）

```bash
declare -A 变量名
declare -A 变量名=(["key1"]="value1" ["key2"]="value2" …)
```

## 环境变量

这些是由操作系统或用户设置的特殊变量，用于配置 Shell 的行为和影响其执行环境。例如 `PATH` 包含操作系统搜索可执行文件的路径：

```bash
echo $PATH
```

## 特殊变量

| 变量 | 含义 |
|------|------|
| `$0` | 脚本名称 |
| `$1`, `$2`, ... | 脚本参数 |
| `$#` | 传给脚本的参数数量 |
| `$?` | 上一个命令的退出状态，0 是没有错误，其他值表示有错误 |
| `$*` | 以一个单字符串显示所有向脚本传递的参数 |
| `$$` | 脚本当前运行的进程 ID 号 |
| `$!` | 后台运行的最后一个进程的 ID 号 |

## 字符串操作

### 获取字符串长度

```bash
${#字符串变量名}
```

### 提取字符串

```bash
${字符串名:开始截取的索引:截取字符的数量}
```

### 查找子字符串

```bash
`expr index ${字符串名称} 查找的字符`
```

## 数组定义

```bash
数组名称=(值1 值2 值3 …)
```

## 读取数组

```bash
${数组名称[下标]}
```

## 获取数组长度

```bash
${#数组名称[@]}
# 或
${#数组名称[*]}
```
