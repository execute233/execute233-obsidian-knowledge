# 软件安装

系统服务注册见 [[liunx/linux命令/系统操作相关|系统操作相关]];常用快速命令见 [[liunx/linux命令/快速命令|快速命令]];go 环境搭建与之相关,见 [[go/go基础/环境搭建|环境搭建]]。

> 建议切换到 root 安装。

## MySQL

```bash
apt update
apt install -y mysql-server   # 安装后会自动注册到服务并启动

mysql                          # 登录到 MySQL
ALTER USER 'root'@'localhost' IDENTIFIED WITH mysql_native_password BY 'your_password';   # 设置密码
exit                           # 退出
```

`mysql_secure_installation` 用于 MySQL 初始化，选项分别是：

- 是否开启密码增强
- 是否更改 root 密码
- 是否移除匿名用户
- 是否允许 root 远程登录
- 是否移除自带的测试数据库
- 是否刷新权限
