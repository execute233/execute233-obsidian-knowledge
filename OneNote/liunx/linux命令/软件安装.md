# 软件安装

建议切换到root安装
**Mysql**
```bash
apt update
apt install -y mysql-server //安装后会自动注册到服务并启动
mysql //登录到mysql
ALTER USER 'root'@'localhost' IDENTIFIED WITH mysql_native_password BY 'your_password' // 设置密码
exit // 退出
```
