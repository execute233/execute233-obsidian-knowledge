# 文件操作

**ls [-alrtAFR] [name...]** **列出当前工作目录文件**

|   |   |
|---|---|
|参数|说明|
|-a --all|显示所有文件（包括以 . 开头的隐藏文件）|
|-A --almst-all|显示除 . 和 .. 外的所有文件（包括隐藏文件）|
|-l|以长格式（详细信息）列出文件（权限、所有者、大小、修改时间等）|
|-h  <br>--human-readable|与 -l 一起使用时，以人类可读的格式显示文件大小（如 KB、MB）|
|-t|按修改时间排序（最新优先）|
|-r  <br>--reverse|反向排序|
|-S|按文件大小排序（大文件优先）|
|-R  <br>--recursive|递归列出子目录内容|
|-F  <br>--classify|在文件名后附加标识符（如 / 表示目录，* 表示可执行文件）|
|--color|彩色输出（通常默认启用，--color=auto）|
|-I --inode|显示文件的 inode 编号|
|-n  <br>--numeric-uid-gid|以数字形式显示 UID 和 GID（替代用户名和组名）|
|-d  <br>--directory|仅显示目录本身，而非其内容（常用于配合 -l）|
|-1|每行只显示一个文件（默认在终端宽度不足时自动启用）|
|-m|以逗号分隔的列表形式显示文件|
|-Q  <br>--quote-name|用引号括住文件名（适用于含空格的文件名）|
|--group-directories-first|先显示目录，后显示文件|
|--time-style=<格式>|自定义时间显示格式|

这些单个字符参数可以组合使用，如：
ls -lShr 按大小反向排序文件（大文件优先）
当文件名包含空格、特殊字符或者开始字符为破折号时，可以使用反斜杠（\）进行转义，或者使用引号将文件名括起来
ls 命令还可以使用通配符进行模式匹配，例如 * 表示匹配任意字符，？ 表示匹配一个字符，[...] 表示匹配指定范围内的字符
在使用 ls -l 命令时，第一列的字符表示文件或目录的类型和权限。其中第一个字符表示文件类型，例如：

- - 表示普通文件
- d 表示目录
- l 表示符号链接
- c 表示字符设备文件
- b 表示块设备文件
- s 表示套接字文件
- p 表示管道文件

在使用 ls -l 命令时，第一列的其余 9 个字符表示文件或目录的访问权限，分别对应三个字符一组的 rwx 权限。例如：

- r 表示读取权限
- w 表示写入权限
- x 表示执行权限
- - 表示没有对应权限

ll命令等同于ls -l
**文件上传与下载**
scp [option] [source_file] [dest_uri]
常用的选项
-r 递归复制整个目录
-P 指定ssh端口号
-p 保留文件修改 访问 权限
-v 显示调试信息
-C 启用压缩
从本地复制文件到远程主机示例：
scp example.txt user@remote_host：/home/user/
从远程主机复制文件到本地示例：
scp user@remote_host：/home/user/example.txt .
**压缩与解压**
tar [c v x f z C] option1 option2…
c 创建压缩文件，用于压缩模式
v 显示压缩/解压过程进度
x 解压模式
f 要创建/解压的文件，必须是最后一个选项
z gzip模式，不使用就是普通的tarball格式
C 选择解压的目的地，用于解压模式
常用的组合：
tar cvf test.tar 1.txt 2.txt 3.txt
将3个文件压缩到test.tar内
tar zcvf teat.tar.gz 1.txt 2.txt 3.txt
将3个文件压缩到test.tar内，使用gzip模式
tar xvf teat.tar [-C dir]
解压tar到当前目录或指定文件夹
tar zxvf test.tar.gz [-C dir]
解压gzip
```bash
tar [z]tvf test.tar[.gz] 列出内容
tar rvf test.tar dest_1 dest2… 添加文件
zip [-r] option1 option2…
zip [-r] xxx.zip dest_1 dest2… 添加到压缩包,如果有文件夹需要-r
unzip target_zip [-d] option
```
解压压缩包，带-d指定解压到的位置
**mv [options] source dest** **移动文件或文件夹**
-b 目标存在时会创建备份
-i 询问是否覆盖（如果有）
-f 直接覆盖
-n 不要覆盖
-u 源文件比较新或目标不存在才移动
**rm 删除文件**
使用空格隔开指定多个文件
-r 删除文件夹
-f 强制删除
**find [ 路径 ] [ 匹配条件 ] [ 动作 ]** **查找文件**
匹配条件 中可使用的选项有二三十个之多，以下列出最常用的部分：

- -name pattern：按文件名查找，支持使用通配符 * 和 ？。
- -type type：按文件类型查找，可以是 f（普通文件）、d（目录）、l（符号链接）等。
- -size [+-]size[cwbkMG]：按文件大小查找，支持使用 + 或 - 表示大于或小于指定大小，单位可以是 c（字节）、w（字数）、b（块数）、k（KB）、M（MB）或 G（GB）。
- -mtime days：按修改时间查找，支持使用 + 或 - 表示在指定天数前或后，days 是一个整数表示天数。
- -user username：按文件所有者查找。
- -group groupname：按文件所属组查找。

动作 用于对匹配到的文件执行操作，比如删除、复制等

- -amin n：查找在 n 分钟内被访问过的文件。
- -atime n：查找在 n*24 小时内被访问过的文件。
- -cmin n：查找在 n 分钟内状态发生变化的文件（例如权限）。
- -ctime n：查找在 n*24 小时内状态发生变化的文件（例如权限）。
- -mmin n：查找在 n 分钟内被修改过的文件。
- -mtime n：查找在 n*24 小时内被修改过的文件。

关于时间 n 参数的说明：
+n：查找比 n 天前更早的文件或目录。
-n：查找在 n 天内更改过属性的文件或目录。
n：查找在 n 天前（指定那一天）更改过属性的文件或目录。
**grep [options] pattern [files]**
常用选项：
-i 忽略大小写
-v 反向查找，打印不匹配的行
-n 显示所有匹配的行号
-r 递归查找子目录中的文件
-l 只打印匹配的文件名
-c 只打印匹配的行数
**tail [ 参数 ] [ 文件 ]** **显示文件尾部内容**
常用参数如下：
-f 循环读取
-q 不显示处理信息
-v 显示详细的处理信息
-c<数目> 显示的字节数
-n<行数> 显示文件的尾部 n 行内容
```text
--pid=PID 与-f合用,表示在进程ID,PID死掉之后结束
-q, --quiet, --silent 从不输出给出文件名的首部
-s, --sleep-interval=S 与-f合用,表示在每次反复的间隔休眠S秒
```
