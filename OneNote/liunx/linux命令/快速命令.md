# 快速命令

## 常用的命令

| 命令 | 说明 |
|------|------|
| `pwd` | 输出当前工作目录 |
| `mkdir` | 创建目录，使用 `-p` 可一次性创建多层目录 |
| `touch` | 创建文件 |
| `more` | 查看文件，但支持翻页 |
| `cp [-r] 参数1 参数2` | 复制文件，使用 `-r` 则会复制整个文件夹 |
| `mv` | 移动文件 / 文件夹 |
| `which` | 查找命令是存放在哪里的 |
| `find 起始路径 -name 文件名` | 查找文件 |
| `grep [-n] 关键字 文件路径` | 过滤文件行 |
| `wc [-c -m -l -w]` | 统计文件的 bytes、字符、行、单词 等数量 |
| `echo 输出内容` | 输出东西到命令行，可以用 `""` 包住输出的东西 |

## 快捷操作

- `history` 可以查看历史输入的命令。
- `!前缀字符串` 执行查找上一次指定前缀的命令。
- `Ctrl+r` 输入内容匹配历史命令，左右键可以得到命令（不执行）。
- `Ctrl+a | Ctrl+e` 光标移动到命令开始或结束。
- `Ctrl+l` 清空终端内容。
