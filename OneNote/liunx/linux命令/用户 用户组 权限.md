以下操作都需root用户执行  
**用户组相关**  
groupadd usename 创建用户组  
groupdel usename 删除用户组  
getent group 查看系统中有哪些组,输出的信息是：  
组名称:组认证(x):组id  
**用户相关**  
useradd [-g -d] username 创建用户  
-g 指定用户组，不指定会自动创建同名组并自动加入，指定的组要存在  
-d 指定用户的home路径  
userdel [-r] username 删除用户  
-r 删除用户的home目录  
id username 查看用户所属的组，未指定则查看自身  
usermod -aG groupname username 将指定用户加入指定组  
getent passwd 查看当前系统的所有用户,输出的信息是：  
用户名:密码(x):用户id:组id:描述信息:HOME目录:执行终端

chmod [-R] modify fileOrDir 修改文件的权限,带-R就是应用里面所有文件  
例如 chmod u=rwx,g=rx,o=x hello.txt 即是修改权限为rwxr-x--x  
我们也可以使用数字代表，其每单个数字就是各用户/组的权限二进制，如  
chmod 775 file 等同于chmod u=rwx,g=rwx,o=rx  
chown [-R] [user][:][group] 修改文件的所属用户和用户组,带-R就是应用里面所有文件
