**日期时间相关**
date [-d] [格式化字符串] 查看系统时间
日期格式有以下：

- %Y 年
- %y 年后两位数字
- %m 月份（01）
- %d 日（01）
- %H 小时（00-23）
- %M 分钟（00-59）
- %S 秒（00-60）
- %s 自1970-01-01 00:00:00 UTC 到现在的秒数

-d 可以计算时间，如：date -d "+1 day"
修改时区
rm -f /etc/localtime
sudo ln -s /user/share/zoneinfo/Asia/Shanghai /etc/localtime

**进程管理**
ps [-e -f] 查看进程信息
-e 显示全部进程
-f 以完全格式化的形式输出信息
输出信息从左到右分别是：
UID：进程所属的用户ID
PID：进程的ID号
PPID：进程的父进程ID
C：CPU占比
STIME：启动时间
TTY：启动此进程的终端序号
TIME：占用CPU时间
CMD：启动命令
kill [-9] 进程ID
选项-9表示强制关闭进程
top 查看系统资源占用
支持的参数选项：
-p 只显示某个进程的信息
-d 刷新时间
-c 显示产生进程的完整命令
-n 指定刷新次数
-b 批次执行top，一般配合-n指定输出几次统计信息，并重定向输出
-i 不显示任何闲置/无用进程
-u 查找特定用户启动的进程
df 磁盘使用情况
iostat [-x] [flush_time] [flush_count] 查看CPU 磁盘的相关信息
sar -n DEV [flush_time] [flush_count] 查看网络相关统计
