# 系统操作相关

## systemctl 命令

控制软件（类似于服务）：

```bash
systemctl start|stop|status|enable|disable serviceName
```

`enable` / `disable` 用于开机自启设置。

系统有很多内置的服务，例如：

- `NetworkManager` 主网络服务
- `network` 副网络服务
- `firewalld` 防火墙
- `sshd`，SSH 服务

## 创建软链接

```bash
ln -s source dest
```

## 日期时间相关

`date [-d] [格式化字符串]` 查看系统时间。

日期格式有以下：

| 格式 | 说明 |
|------|------|
| `%Y` | 年 |
| `%y` | 年后两位数字 |
| `%m` | 月份（01） |
| `%d` | 日（01） |
| `%H` | 小时（00-23） |
| `%M` | 分钟（00-59） |
| `%S` | 秒（00-60） |
| `%s` | 自 1970-01-01 00:00:00 UTC 到现在的秒数 |

`-d` 可以计算时间，例如 `date -d "+1 day"`。

### 修改时区

```bash
rm -f /etc/localtime
sudo ln -s /user/share/zoneinfo/Asia/Shanghai /etc/localtime
```

### ntp 时间同步

自己安装 ntp，服务名是 `ntpd`：

```bash
ntpdate -u ntp.aliyun.com   # 立马同步指定的 ntp 服务器
```

## 进程管理

`ps [-e -f]` 查看进程信息：

| 选项 | 说明 |
|------|------|
| `-e` | 显示全部进程 |
| `-f` | 以完全格式化的形式输出信息 |

输出信息从左到右分别是：

- `UID`：进程所属的用户 ID
- `PID`：进程的 ID 号
- `PPID`：进程的父进程 ID
- `C`：CPU 占比
- `STIME`：启动时间
- `TTY`：启动此进程的终端序号
- `TIME`：占用 CPU 时间
- `CMD`：启动命令

`kill [-9] 进程ID`，选项 `-9` 表示强制关闭进程。

### top 查看系统资源占用

支持的参数选项：

| 选项 | 说明 |
|------|------|
| `-p` | 只显示某个进程的信息 |
| `-d` | 刷新时间 |
| `-c` | 显示产生进程的完整命令 |
| `-n` | 指定刷新次数 |
| `-b` | 批次执行 top，一般配合 `-n` 指定输出几次统计信息，并重定向输出 |
| `-i` | 不显示任何闲置/无用进程 |
| `-u` | 查找特定用户启动的进程 |

`df` 查看磁盘使用情况。

```text
iostat [-x] [flush_time] [flush_count]   # 查看 CPU 磁盘的相关信息
sar -n DEV [flush_time] [flush_count]   # 查看网络相关统计
```

## 环境变量

临时生效：

```bash
export name=$PATH:value
```

永久生效：

- 针对用户：`~/.bashrc` 配置
- 针对所有用户：`/etc/profile` 配置后

```bash
source 配置文件   # 使配置立刻生效
```
