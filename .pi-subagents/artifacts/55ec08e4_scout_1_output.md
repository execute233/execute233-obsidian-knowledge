## 偏离清单
### 高优
- **全目录缺少 Markdown 标题层级与 Frontmatter**：19 篇均未发现 `---` frontmatter；仅 `Shell脚本/echo.md:7,9` 和 `Shell脚本/流程控制.md:44` 出现代码注释形式的 `#`，其余内容大多用裸文本或 `**粗体**` 模拟章节标题。代表性文件：`linux命令/文件操作.md:1,47,59,82,88,92,115,123,133`、`linux命令/系统操作相关.md:1,11-12,32,35,41,68`、`linux命令/快速命令.md:1,17`。建议建立 H1 文档标题、H2/H3 章节层级；代码中的 shebang/注释不应误改为标题。
- **表格结构不完整**：`linux命令/快速命令.md:3-15` 与 `linux命令/文件操作.md:3-23` 的首行是空表头 `|   |   |`，缺少明确列名；后者多行单元格含 `<br>`（见中优），两表列数虽基本一致但可读性和渲染语义不稳定。需人工确定列名（如“命令/说明”“参数/说明”）。
- **结构性“目录”未转为标题/列表**：`Shell脚本/echo.md:1-6`、`Shell脚本/变量.md:1-15`、`Shell脚本/流程控制.md:1-3`、`Shell脚本/运算符.md:1-8`、`第三方命令/curl 网络传输.md:8-12` 使用手写编号；同一文件后续正文又使用裸文本，导致导航、层级和列表语义丢失。

### 中优
- **列表风格混杂**：`Shell脚本/变量.md:1-15` 顶层为手写 `1.`，嵌套项为 4 空格缩进编号；`Shell脚本/echo.md:4-6` 使用裸参数行与无统一列表；`linux命令/系统操作相关.md:6-9,16-23`、`基础知识/文件系统.md:5-16` 等使用 `-` 列表，但命令参数章节大量裸行（如 `linux命令/文件操作.md:48-80`）。需按“概念列表/命令示例/参数表格”分别统一，不能机械全局转换。
- **HTML 残留**：`linux命令/文件操作.md:9,11,13-14,17-18,21` 含 `<br>`，应改为单元格内 `<br>` 的统一替代方案（拆行、分隔符或代码换行）；这是已清理项之外的 HTML 残留。
- **强调风格与语法异常**：大量章节使用 `**标题**` 而非标题；`linux命令/系统操作相关.md:1` 为 `**systemctl** **命令控制软件****(****类似于服务****)**`，存在连续/嵌套粗体标记；`linux命令/文件操作.md:92,123` 的 `**[****路径****]...**` 同样是嵌套粗体噪声。建议标题语义改 H2，命令参数用反引号，正文强调只保留必要 `**...**`。
- **中文/英文标点及空格不统一**：`第三方命令/curl 网络传输.md:14-57` 混用英文逗号、冒号、括号、句号与中文引号（如 `:`, `(`, `;`），并有 `http`、`url` 等大小写不一致；`Shell脚本/变量.md:1-7,24,30-41` 同时使用中英文括号/逗号，且 `变量名={1， 2， 3， 4 }` 含不一致空格；`linux命令/用户 用户组 权限.md:5-26` 也混用逗号和句号。技术命令语法中的 ASCII 标点应保留，说明文字需人工统一。
- **代码/正文边界不清**：多篇文件将命令、代码和说明全部作为普通段落（如 `Shell脚本/流程控制.md:5-45`、`linux命令/系统操作相关.md:13-73`），缺少 fenced code block 或行内代码，影响渲染和复制使用；需人工按示例边界补围栏，不能仅依赖正则。

- **可疑特殊残留/内容质量（非纯格式）**：`基础知识/文件系统.md:5,9,11,16` 有明显疑似错字（“=些”“sbing”“设蚤”“绐”）；`linux命令/文件操作.md:7` 的 `--almst-all` 疑似命令拼写；`linux命令/系统操作相关.md:1` 的 `enble` 疑似 `enable`。这些应单独人工核实，不作为自动格式修复。
