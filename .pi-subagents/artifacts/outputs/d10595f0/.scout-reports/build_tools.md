## 偏离清单

### 高优 (影响渲染/可读性)

1. **Git/使用.md:45 — 强调语法损坏** (`**强制让分支指向另一个提交`)
   - 只有开头 `**`,无闭合标记。后续 `git branch -f main HEAD~3` 不再被加粗,语义断裂。
   - 推测意图是加粗作为子节标题,因缺标题层级整篇只靠加粗划分。

2. **IDEA/快捷键操作.md — 表格表头为空** (line 1)
   - `|              |            |             |             |` 4 列均无标题文本,读者无法判断"列 1 是快捷键/中文说明/英文说明/类别"中的哪一种。
   - 列宽与内容对齐不严格(列 1 实际内容 `Ctrl+Shift+U` 13 字符,分隔符仅 12 个 `-`)。

3. **Git/安装 配置 初始化.md:3-4 — 伪链接**
   - `git config --global http.proxy "[http://127.0.0.1:8080](http://127.0.0.1:8080)"`
   - 显示文本与目标 URL 完全相同,渲染为冗余链接;本意大概率是代码片段,应用反引号 `` ` `` 包裹或纯文本。

### 中优 (结构/语义缺陷)

4. **全部 5 篇文件 — 标题层级缺失**
   - `^#` 在全目录 grep 结果为 0,除 maven/依赖管理.md 的 `1. 依赖作用域` 编号项外无任何标题。
   - Git/使用.md 长达 94 行无章节,仅靠空行分隔,难以导航。

5. **全部 5 篇文件 — Frontmatter 缺失**
   - 无 `---` 包围的 YAML 头部,无法添加 tags/aliases/created 等元数据。

6. **全部 5 篇文件 — 列表风格不一致/缺失**
   - Git/使用.md 共 94 行,逻辑上是"标题 + 命令"对照清单,但无 `-`/`1.` 列表标记。
   - Git/安装 配置 初始化.md 同上。
   - maven/依赖管理.md 唯一一个 `1.` 编号项孤立存在(应改为标题或保持无序列表)。

7. **Git/使用.md — 内容疑似截断**
   - 第 94 行 `多人协作` 后无任何内容,与前文"标签"等同等篇幅的章节不匹配。
   - 无法判定是格式问题还是内容缺失,需人工确认。

8. **Git/安装 配置 初始化.md — 文件名含空格**
   - `安装 配置 初始化.md` 含 3 个 ASCII 空格,与全目录其他文件的命名风格不一致。

### 低优 (标点/风格细节)

9. **Git/安装 配置 初始化.md:9, 14 — ASCII 箭头 `->`**
   - `github -> setting -> developer settings -> personal access tokens -> classic令牌`
   - 中文环境下建议替换为 `→`;若保留代码语义则用 `` `->` `` 包裹。

10. **Git/使用.md:68 — 中文内嵌逗号**
    - `head是当前提交,也可以head~数字,` 句中及句末均使用 ASCII 逗号 `,`,中文语境建议 `,` / `,`。

11. **Git/使用.md — 大量裸尖括号占位符**
    - `<name>`, `<branch-name>`, `<commit>`, `<ref>`, `<冲突文件>`, `<tag>`, `<numCommits>`, `<hash>` 等 20+ 处。
    - 非 HTML 标签,但裸尖括号在部分渲染器中会被尝试解析;建议改用反引号或 `<placeholder>` 风格统一。

12. **maven/操作.md — 纯图片流,无文字上下文**
    - 4 行全为 `![[...]]`,无任何标题/说明/分组,读者无法理解每张图的主题。

## 自动修复可行性

### 完全可自动 (机械替换,无歧义)
- **ASCII 箭头 `->` → `→`**:2 处 (Git/安装 配置 初始化.md)
- **文件名空格 → `-`**:1 处 (Git/安装 配置 初始化.md)
- **裸占位符 `<x>` → `` `<x>` ``**:Git/使用.md 20+ 处 (纯正则)
- **中文内逗号 `,` → `,`**:Git/使用.md:68 (单行替换)

### 需人工判断 (语义相关)
- **添加章节标题层级**:5 篇均需补充,但章节切分依赖用户对内容的认知
- **Git/使用.md:45 补充闭合 `**`**:是"加粗"还是"标题"或"删除"需用户决定
- **IDEA/快捷键操作.md 表头补全**:需用户给出每列的实际含义(快捷键/功能/类别?)
- **Git/安装 配置 初始化.md 伪链接改写**:代码 vs 纯文本 vs 真实链接三种方案
- **maven/依赖管理.md `1.` 编号项改造**:标题 vs 项目符号列表
- **Git/使用.md 末尾 `多人协作` 章节补全**:格式问题还是内容缺失
- **maven/操作.md 补充文字说明**:是否要添加分组/标题

### 不可自动 (需要原创内容/用户决策)
- 章节标题文本本身(取决于用户对笔记的认知)
- IDEA 表格列语义建模
- maven/操作.md 各图片的主题说明
