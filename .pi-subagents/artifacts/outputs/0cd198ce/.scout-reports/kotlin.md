- `[变量名称] / [值] / [函数参数1]` 这类方括号占位符会触发某些 Markdown 解析器的"未闭合链接"警告

## 自动修复可行性

### 完全可自动
- **H4 表格残留空行**: 检测 `^\| *\|? *\|? *$` 与 `^\| *$\n^\|\|...` 即可删除
- **M3 HTML `&nbsp;`**: 1 处替换为空格或 `\,`(数学间隔)
- **M1 加粗相邻**: 文本替换 `\*\*X\*\*\*\*Y\*\*` → `\*\*X\*\* \*\*Y\*\*`,机械规则可覆盖
- **L3 拼写错误**: `vaule` → `value` (1 处)
- **L1 占位符转义**: 对裸 `[xxx]` 形式统一前置反斜杠 `\[xxx\]`

### 需人工判断
- **H1 标题层级补齐**: 需要人决定每个"代码块标题"应升级为 `##` 还是 `###`,是否保留原编号列表
- **H2 代码块标题转换**: 删 ```kotlin/**...**/``` 三行换 `##` 还是保留代码块高亮,要按笔记语义判断
- **M2 编号跳号**: 是故意还是漏写,需人工核对原大纲(目录外无依据)
- **M5 文件名中文标点**: 是否重命名为 `封装_继承和多态.md` 或 `封装、继承和多态.md` (Obsidian 友好但跨平台仍敏感)
- **M4 LaTeX 与表格混排**: 是否转纯文本 `-2^31`、改用 unicode 上标,或保留 `$...$` 接受渲染差异

### 不可自动
- **H3 表格内嵌代码块**: 渲染层无法解析,必须人工拆表:把每个单元格里 ```kotlin 内容提取为独立代码块并拆出多张表
- **M6 特殊类型.md L1 畸形代码块**: 需逐行重排
- **L2 中英标点统一**: 半角 `,`、`.`、`:` 在代码内是合法,在中文叙述句中可能意图中文标点;语义级判断不可机械完成
- **L5 列表/段落边界**: 是否在列表项后插空行取决于渲染器目标,需选型后再批量插入

1. **H3 表格嵌代码块** — 影响最大、需先拆表,否则后续标题转换在表格上下文中判断困难

4. **H1 标题层级补齐** — 在 H2 基础上确认 H1(文件名)→ H2(原"代码块标题")→ H3(原编号子项)层级
5. **H4 表格残留空行/空单元格** — 删空表头行 `|   |   |   |`,合并 Float/Double 空值列
6. **M1 加粗相邻缺空格** — 文本替换 4 处
7. **M3 HTML `&nbsp;`** — 1 处替换
8. **L3 拼写错误** — `vaule` → `value`
9. **L4 Frontmatter** — 决定是否引入(本仓库其他目录需先对齐)
10. **M2 编号跳号 / M5 文件名 / M4 LaTeX / L1 占位符 / L2 中英标点 / L5 段落边界** — 留待人工或与全仓风格统一时一并处理
