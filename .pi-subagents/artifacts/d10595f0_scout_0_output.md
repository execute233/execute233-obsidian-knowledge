- 审阅方式: 只读逐篇检查；未修改源笔记
- 总体判断: 主要偏离是缺少真正的 Markdown 标题、命令未放入代码块而被误解析成标题、编号列表断号，以及 OneNote 远程图片残留。7 篇均无 frontmatter，但目录内表现一致；在没有仓库级模板要求的前提下，将其记为一致性观察，而非单独判错。

## 偏离清单

### 高优
- **命令注释被误解析为一级标题**：`OneNote/python/conda/包管理.md:12,14,16,18` 与 `OneNote/python/conda/环境管理.md:16,19` 的命令及注释未置于代码围栏，其中以 `# ` 开头的注释会渲染为 H1，造成伪标题并切断文档结构；相邻 `conda ...` 命令也只是普通段落。严重度：高。
- **整组笔记缺少文档标题/章节标题**：7 篇均没有以 `#` 开始的真实文档标题；内容主要依赖有序列表或粗体充当章节。`基础/基础.md:1,11,41`、`基础/字符串相关.md:1,92,129,147` 尤其明显，章节语义无法进入大纲。严重度：高。
- **OneNote Graph 远程图片残留**：`OneNote/python/基础/字符串相关.md:161-162` 仍有两条 `graph.microsoft.com/.../onenote/resources/.../$value` 图片引用。这类 URL 通常依赖账户鉴权，迁移后极易失效；同文件 `:160` 已有本地 wikilink，三图是否重复需人工核对。严重度：高。

### 中优
- **有序列表断号且被用作章节编号**：`基础/基础.md:1,11,41` 从 1 跳到 3、6；`基础/字符串相关.md:92,129,147` 从 1 跳到 4、6，且 `:123` 出现孤立的 `12.`。Markdown 渲染器可能自动重排，源文含义与显示序号可能不一致。严重度：中。
- **粗体代替标题，且存在异常强调串**：`基础/字符串相关.md:1,92,129,147` 用粗体作为章节名；`基础/基础.md:1,11,41,85` 同样如此。`基础/类.md:3` 的 `**object****特殊方法**` 是两个无间隔粗体片段，视觉上粘连且语义不清。严重度：中。
- **围栏代码块承载标题/说明文本**：`基础/基础.md:21,25,39,43,47,51` 等把“列表/元组/字典/集合”粗体标题和中文说明放进 `python` 代码块，粗体不会生效且说明被当作代码；`conda/管理conda.md:9-11` 也将“查看某个命令的帮助”放入 `python` 代码块。严重度：中。
- **表格表头为空、语义不足**：`基础/字符串相关.md:151-159` 的两列表格首行是空表头 `|   |   |`，虽可解析，但缺少列名；内容实际是“格式项/含义”，建议人工确认表头命名。严重度：中。
- **链接写在 shell 代码中却使用 Markdown 链接语法**：`conda/管理conda.md:16-19` 的 `conda config --add channels [URL](URL)` 位于 `bash` 围栏内，复制执行时方括号和圆括号会导致命令无效。应在命令中保留裸 URL；这是链接格式与代码可用性的交叉问题。严重度：中。
- **图片风格混杂**：`基础/字符串相关.md:160-162` 同时使用本地嵌入 wikilink 与远程 Markdown 图片；`基础/类.md:1,5-6,10` 则均为本地 wikilink。建议以本地资源为唯一规范，并核验远程图是否已有本地副本。严重度：中。
- **中英文标点与空格不统一**：例如 `conda/管理conda.md:1` 混用中文句号与英文括号，`基础/基础.md:4-8`、`基础/字符串相关.md:153-159` 大量中英文术语紧贴中文，逗号/冒号也混用半角与全角。此项分布广，但自动统一可能破坏代码、API 名和命令，仅建议对正文做受限处理。严重度：中偏低。
- **文档内容呈“清单 + 裸代码”而非稳定章节结构**：`conda/包管理.md:1-8`、`conda/环境管理.md:1-9` 先列操作清单，随后 `:9-22` / `:10-21` 平铺命令，列表项与对应命令没有明确绑定。`基础/内置函数.md:1-6` 仅两项且第二项无说明。严重度：中。

## 自动修复可行性
- 完全可自动: 2 类
  - 将 `conda/包管理.md`、`conda/环境管理.md` 的连续命令区整体包入 `bash` 代码围栏，消除伪 H1。
  - 将 bash 围栏内 `[URL](URL)` 机械还原为裸 URL。
- 需人工判断: 7 类
  - 补文档标题与章节层级（需确定标题命名和拆分边界）。
  - 修正断号列表（需判断是重排、保留章节号，还是改为标题）。
  - 把代码围栏内的说明/粗体标题移出（需区分示例代码与解释）。
  - 为表格补表头。
  - 统一粗体章节、异常强调和正文强调规范。
  - 统一正文中英文标点与空格，但避开代码/API。
  - 决定 frontmatter 模板及是否补齐。
- 不可自动: 1 类
  - 核验并迁移 OneNote Graph 鉴权图片、判断其与本地图片是否重复；需要访问权限和人工看图确认。

## 推荐处理顺序
1. 先修复 `conda/包管理.md`、`conda/环境管理.md` 的裸命令区，避免 `#` 注释继续污染标题大纲。
2. 核验 `基础/字符串相关.md:161-162` 两张 Graph 图片，能访问时下载到本地资源目录；确认与 `:160` 是否重复后再删除远程引用。
3. 为 7 篇补统一的 H1，并将粗体章节转换为 H2/H3；同时处理 `基础/类.md:3` 的异常强调串。
4. 人工梳理 `基础/基础.md` 与 `基础/字符串相关.md` 的断号列表，将章节编号改为标题或连续列表。
5. 将说明文字移出代码围栏，修正 bash 代码中的 Markdown URL。
6. 为格式化字符串表格补语义表头，并统一正文标点/空格。
7. 最后根据知识库全局规范决定是否批量添加 frontmatter。
